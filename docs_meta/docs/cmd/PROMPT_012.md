| 改什么 | 从 | 到 |

行原文写「命令只保一份」，这就是那一份。

要做三件事，按顺序：

3. 汇总。全绿印 `ALL PASS`，任一红印 `FAILED`，`exit` 非零。

跟八本同一套写法：`#!/usr/bin/env bash`、`cd "$(dirname "$0")/../.."`、`fail=0` 累计、
