### 3. `workflow.md` 新开一节：补卡

**位置在「退卡」那一节之后、「闸与闸之间」之前。** 补卡和退卡是一族——
两个都是一整刀的进退，不是刀内的动作。

标题：`## 补卡：拿新的一刀去修已经结案的那一刀`

**开头三句定死是什么，别的都从这三句推**（人 2026-09-10 裁，出处写本刀卡名）：

- 补卡的对象是**已经结案**的那一刀，不是在办的这一张。
- 补卡自己是**完整的一刀**：自己的 TODO 行、自己的卡号、自己的审卡、闸一、验收、结案。
- 所以「冻结之后怎么合法追加」的答案是**不追加**。走完这一刀，另开一张。

**紧跟一句理由，不许只写规矩**（`paradigm.md` §10：不带理由的规矩，下一个人会当成税删掉）：

> **为的是一事一结，整个历史是清晰的。**
> 往在办的卡上追加，等于让一张卡结两件事——那一行、那一份 `cmd/`、那一次结案，
> 从此都指着两件东西；翻历史的人看得见「结了」，看不见结的是哪一件。
> 另开一张，两件各自有行、有卡、有印、有结案日期。

**这一句是这一节的承重墙，不是修辞。** 它一没，补卡就只剩「多一道手续」，
下一个人第一个想省的就是它。

**扣上的两条要点名**：一份 `cmd/` 在待办页只有一个落点、行外不另起一段；
概要和细则是两份独立记录、靠互相校验对账（`paradigm.md` §5）。
**追加会把这两条一起破掉。**

**这里不许点名「已办一条只许占两行」那一条。** 第二版草稿点了，撤掉——
那个数字不是人裁的，是检查脚本自己加的（见「只报不改」第 1 条）。
**通则里写一个代理编出来的上限，比留在卡上严重得多**：换一张桌读到的就是「这是规矩」。

**三种用途**，写清楚免得下一个人当成万能口子：

| 用途 | 什么意思 |
|---|---|
| 纠错 | 上一刀做错了 |
| 完善 | 上一刀做对了，但没做够 |
| 补充 | 上一刀该做没做、或当时不该由它做的那一件 |

**刀内发现要动卡外的东西，分两种，不许混：**

| 情形 | 走哪条 |
|---|---|
| 这一刀非动它不可，不动就走不下去 | **退卡。** 「超出卡片」那一条一个字不改 |
| 这一刀走得完，只是顺带看见了别的 | **照走完。** 那件事写进收口对账「没做的」那一栏，人在结案时裁开不开补卡 |

**这是「已知偏离」那个写法的出口，理由要跟规矩一起写**（不带理由的规矩，下一个人会当成税删掉）：
现在卡上没地方放「看见了但不该我做」，只好在抬头写「已知偏离」；
而「偏离」是 §9 的词，意思是违反了自己写的规矩。**把一件正当的后续叫成偏离，是把 §9 写脏。**

**四条边界，一条都不许省：**

- **立案仍是人的那一爪。** 代理看见了只能报，不能自己开补卡。
- **补卡不松判据。** 拿新的一刀去放宽老刀的判据，是松判据换了个壳，那是人的那一爪。
  这一句照「退卡不是松判据的后门」那句的写法写，两处要对得上。
- **补卡不改老卡一个字。** 卡结案之后只增不删。补卡是新的一份，不是老卡的修订版。
- **指针只从新往旧指。** 补卡那一行点名它修的是哪一刀；老行在已办区冻着，不回头改。
  **代价照写**：翻已办区看不出某一行后来被补过，要顺着新行才找得到。

**退卡的卡没有补卡。** 退卡的卡不留，没有对象可补；那条路是缩小卡片重开，不是补卡。
