### 为什么这不是上一刀刚否掉的那张清单

上一刀写死了：「要索引就 `grep -n` 现算，**不存盘**」——因为一份派生的
「已定条目清单」和正文迟早不一致，且不一致时没人知道该信哪个。
本刀反过来要**存**一份已办索引。表面上打架，实际不打架，但**判据必须写出来**：

> **能从别处现算出来的，不存；两份独立产生、可互校的，存——并装一条检查逼它们对上。**

- 「已定清单」是**纯派生**：内容全在 `paradigm.md` 里，`grep` 一跑就有。
  存一份只会腐烂，且它腐烂时**没有第三方能发现**。
- 已办行**有独立来源**：那句话是**人在立案时写的措辞**，写在卡片存在之前。
  它不是 `cmd/` 的影子，是 `cmd/` 的**上游**。

**两份独立记录能互相校验，一份派生副本只能腐烂。** 这就是「对账」和「第二真相」的分界。
这条判据比「不删行」本身值钱，**它要落进合同层**（§10 或 §5，实现席选一处，说明理由）。
