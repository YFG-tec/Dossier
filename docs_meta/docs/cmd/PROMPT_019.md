只动这两份，只动**已有 `##` 节的正文**：

| 文件 | 动哪一节 | 加什么 |

| `docs_meta/src/cursor.md` | `## 目标文件` 那个代码块 | 一行 `.cursor/rules/switches.mdc`，说明：本桌开关的唯一现态；`alwaysApply: true`；**两席共用，不是规划席专属** |

## 缺口，照记不补

- **产物侧没有一只手。** 四只手的射程加起来不含根 `CLAUDE.md`、`.claude/`、`.cursor/`，所以第 2 件只能靠领班代落。**这是结构上的洞，不是本刀的疏忽**，补它要新开一只手或者扩 `roles.md`，都是另一刀。本卡把它写在这里，不顺手补。
- **换根之后不会红。** 人裁过不配哨兵。残余两条：一、搬新平台跳过编译，盘上不红；二、厂商改机制，产物静默失准，盘上也不红。第二条更难办——什么都没做它就已经不准了。代偿只有一样：`.claude/host.md` 那几格读数带日期。
- **手改规则不提醒。** 人明着不收这个口子（原话：「默认不收这个口子」）。人自己下场改规则之后会话里不会有任何提示。**不许下一只手拿它当缺陷回头补。**
- **历史卡里的行号会悬空。** `PROMPT_016`、`PROMPT_018`、`SESSION.md` 横线以下写着 `.claude/config.md:9`，搬完那个行号指向不存在的文件。历史只增不删，**本刀不回头改，也不加勘误页**。
- **第十三本查不到「人有没有真把档拧对」。** 它只查「现值只有一处」，查不了那一处写的值对不对。值是人拧的，没有源码出处可对。
