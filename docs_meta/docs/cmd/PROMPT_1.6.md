## 独立审查

**派。** 一条理由，不是惯例：

**本刀在改七条不变量之一，而改的那一条正是「什么事只有人能做」。**
写卡、实现、测试三只手全是代理——**代理在改「代理不准做什么」的条文**。
这是全库利害关系最直接的一处，比上一刀那个「立规矩的手按新规矩重写自己」更近一层。

审查回答三条，**都不问做法**：

1. **有没有扩权？** 新条文比旧条文宽。逐处比对现状 3 那张表：
   宽出来的两样（发授权、松判据）是不是那六处 `workflow.md` 原文的忠实归纳？
   **有任何一个字是这六处之外新长出来的，点名。** 归纳可以，发明不行。
2. **原句有没有被抽象掉？** 「代理不准自己勾 TODO」必须还在，且仍读得出**禁令语气**。
   机检 B 只认「勾」和「TODO」两个词共现，认不出「语气被磨平成描述句」——**这一条要人眼。**
3. **方向差是不是写成了例外？** 逐字看。它该是**射程说明**（收紧本来就不在这三样里），
   不该出现「不在此列」「除…之外」「唯一例外」「不适用」。**出现任何一处例外，整刀退。**

**审查不必回答「这条内容配不配当已定」**——本刀不加标记，那是闸二的加法。
