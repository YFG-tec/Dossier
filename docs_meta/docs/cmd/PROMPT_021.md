**第 1、2、3、4 件在那一印之下落到了盘上，并且逐条自验过**，读数记在 `SESSION.md` 横线以上那张进度表里。
第 5 件一步没跑——**漏了 `mkdir` 的正是它**，所以这一次退回闸一。

**盘上落着的那四件不撤，理由照记：**

通则给的收摊路是退卡（`workflow.md`「退卡」那张分层表：卡片自相矛盾 → 删卡 → 号留空档）。
**人裁的不是退卡**，是「指令里漏了一个」——同 `PROMPT_017` 那一次的形状：一处漏写，不是卡片自相矛盾。
撤回那四件要动 `git restore`，那一爪既在本席权限面之外，也不是人下的。

**代价照记**：这一版红印落下的时候，盘上已经带着上一印的四件成果，
所以第 2 版红印不是从零起跑的印，是**从第 5 件起跑的印**。验收第 14 格的「恰好 10」
正是照这个状态写的——那十行里有四行是上一印落的，三行是人自己中途动的，
**第 2 版这一趟新落的是零行**，第 5 件跑完也该还是零行（它只往 `.tmp/` 写，`.tmp/` 不进 `git status`）。

**红印进到第 2 版之前，第 5 件不许开跑，别的格也不许再动一个字。**
