## 裁定（卡上定死）

采纳反馈三条**分拆版**：

1. **领班格「只许动」补路径**：`派角色、跑收口验收、对人说话` → `派角色、跑收口验收、对人说话；docs/reports/ 的报告正文（收口后）`——对账内容只有领班有，报告正文归领班（36 桌口头推翻的事故形状就此销）。
2. **「通过」那个词仍不归领班**：报告正文里「通过」只许引卡上判据与日志（verify.md 既有条款照旧），阶段结论的签认在人——在「谁决定什么」节末补一句：「**报告的正文归领班，报告里『通过』的断言只许转述判据与日志**——写新的结论性判词仍是人那一爪。」
3. **落点图补领班行**：`docs/reports/ ← 领班收口后由规划席写` 改为 `docs/reports/ ← 领班收口后写正文；规划席可另写阶段叙述；实现席不擅自写「通过」`。
