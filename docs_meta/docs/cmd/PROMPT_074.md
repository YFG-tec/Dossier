## 裁定

**人 2026-10-03 原话**：「我在其他项目实践的时候，试过一个功能，todo除了"已办"以外，还有另一个池子叫"废除"」

**法条三件**：

1. **todo 头部规矩句补**：「作废的行同样不删，搬进「废除」——开放行数从此只数真活」（接在「勾完不删，搬进页末『已办』」后）。
2. **新「## 废除」节**（已办节后），形同已办两行式：行搬入时原句整行保留，细则行改注「**废除**（人 YYYY-MM-DD 裁，原话逐字：『…』）——一句话为什么」。**存量迁移**：4.5（本次作废）与 5.1（2026-10-02 作废）两行迁入，原话逐字随行。
3. **close_cut 加 `--void`**：`close_cut.py <行号> <卡号> --void "人原话"`（不接 --review/--queue）：搬行入废除节（两行式：原行保留＋废除注记）、SESSION 状态格写「已废除（日期）：人裁，原话逐字」、放锁。**只接受人行**（废除=人裁；代理建议废除走断点呈报，不代笔）。`--help` 同步。

**边界**：废除池只收「人裁作废」的行；「撤销/退卡」（如 1.20）仍走退卡留档节——两池不同命，不混流。
