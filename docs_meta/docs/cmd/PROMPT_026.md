### 查到了什么

**Spec Kit（`specify init`，代理范式那一族）。** 它是四家里唯一和我们同类的：
铺的是给 AI 代理用的骨架，不是某种语言的工程模板。它把「新建」「已有仓库」两档收在同一个动词下，
用 `.` 或 `--here` 指当前目录，目录非空时要 `--force` 才往下走。
它自称幂等，允许重跑来刷新基础设施。

值得记下来的是它那个公开的 bug：有人报 `specify init --here --force` 不更新已经存在的
`.specify/scripts/` 和 `.specify/templates/`，因为安装那一步对已存在的文件一律跳过，
`--force` 也不管用，于是上游修的脚本永远到不了已经初始化过的项目。
另一处文档描述的是更细的做法：`--force` 走的是按清单哈希比对的覆盖，
哈希对得上（用户没动过）才覆盖，对不上就当成用户的改动保留并警告。

**`copier`（模板铺开那一族）。** `copier update` 不是「只补缺的」，是三路合并。
它要一份 `.copier-answers.yml`、要模板带版本 tag、要 Jinja 后缀。
合并撞车时按 `--conflict inline` 往文件里写冲突标记，或按 `--conflict rej` 另生成 `.rej` 文件。
非交互要 `--defaults`，答不上来的问题会直接抛错而不是挂住。

**`cookiecutter`。** 只管生成那一刻，模板后来改了没有任何办法同步到已经生成的项目。
要升级得另装 `cruft`，靠一份 `.cruft.json` 记住模板的 git 哈希。

**`degit`。** 只是不带历史地取一份下来，没有「已经有了怎么办」这一档。

### 抄谁

抄 Spec Kit 那一族的**规范**，不抄模板铺开那一族的**机制**。

抄过来的是三样：动词就叫 `init`（这个 `2.8b` 已经落定了）；
`--here` 和位置参数两种指靶子的写法；以及「已存在的一律跳过、只装缺的」这条语义。

不抄 `copier` 的三路合并。理由不是它不好，是它和我们铺的东西对不上：
我们往宿主铺的是 `TODO.md` 和 `SESSION.md`，那里面装的是宿主的真活。
往一份真活里写冲突标记或者甩一个 `.rej` 出来，就是把活搞坏，正好撞上行里那条硬判据。
`cookiecutter` 和 `degit` 没有升级那一档，和「`init` 同时是升级路径」直接对不上。

### Spec Kit 那个 bug 咬不到我们，理由要写明

它那个 bug 的病根是：**母本自己拥有的文件也走 `init` 铺**。
既然走 `init` 铺，「已存在的一律不动」就把上游的修补堵在门外了，
所以它才要往清单哈希那个方向走。

我们的形态里那批文件根本不过 `init` 的手。
母本自己的东西躺在子模块里，升级走的是 `git submodule update --remote`（`form.md` 第 4 节两步那一段，材料）。
`init` 只往宿主铺宿主自己的活。**宿主自己的活，「一律不动」本来就是对的。**

所以「已存在的一律不动，只补缺的」这条在我们这儿不是将就，是正解。
清单哈希那一档本刀不采纳：它会覆盖某些已存在的文件，相对行里写死的判据是放松，
而松判据是人的那一爪。这一件另记进「缺口」。

护栏那句「抄不到才自己造，造了要写明查过哪些」，本刀的答复是：规范抄到了，所以不算自己造。

#### 命令行长什么样

```text

```

| 怎么给 | 靶子是 | 出处 |

#### 幂等怎么做

已存在的一律不动。目录已在就跳过；文件已在就**一个字节不写**，不比内容，不合并，不备份。

`--force` 的意思是「要求覆盖已存在的文件」。它不直接覆盖，先问一句，**默认否**，
回车等于否。这一条是行里写死的。

`--non-interactive` 的意思是「不问」。

两个旗子同时给的时候，「先问且默认否」在没有人可问的场合只能落到**否**：
照只补缺的走，`stdout` 印一行说明含「按默认否」四个字，退出码 `0`。
这样定的理由是，让 `--non-interactive` 把「默认否」绕过去，就等于给自己发了一次授权。

`--dry-run` 只算不写：印出靶子和每一件的去向，一个字节不落盘。
这个旗子不是顺手加的，是「默认靶子是宿主根」那一格唯一能安全验的办法——
真跑一趟会往 `D:\00_Works\` 铺东西。各家通用，`copier` 那边叫 `--pretend`。

#### 印什么

每一件一行，前缀两种，对齐无所谓，机器只数前缀和末行：

```text
靶子：<绝对路径>
+ docs/
+ docs/TODO.md
= docs/cmd/
...
建 N 件，跳过 M 件，覆盖 K 件
```

`+` 是建，`=` 是已在不动。末行格式固定成那一句，验收表要数它。

#### 退出码

| 码 | 什么时候 |
|---|---|
| `0` | 铺完了，包括「什么都不缺、一件没建」 |
| `2` | 参数冲突（`TARGET` 和 `--here` 同时给） |
| `3` | 靶子不存在，或者不可写 |

靶子不存在时不自己建靶子。理由是打错一个路径就在别人盘上凭空长出一棵树，
而这一步本来就该是人先把宿主仓库准备好。
