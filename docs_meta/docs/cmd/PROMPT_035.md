- 卡上写的命令要照抄进 shell，里面一根管道都不许有，除非那根管道是命令自己的一部分。
- 模式以 `-` 开头要加 `-e`，否则 `grep` 当它是选项。
- **模式里不许出现反引号。** 反引号在双引号和 `$(...)` 里会被当成命令替换，当场炸成
  `unexpected EOF while looking for matching`。下面二十三格里一个反引号都没有，这是有意的。
  单引号里的反引号 shell 不碰，那是安全的；炸的是双引号和 `$(...)` 里的。
  另一半是卡面：反引号是行内代码的界符，写进单反引号里会把那一格截断，要用双反引号包一层。
  第 9 格就是这么写的，照抄的时候把两边最外层那对反引号剥掉。
