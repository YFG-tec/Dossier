## 开工前在盘上量到的

探针落 `.tmp/`，零权威，只作证，**不叫 `check-*.sh`**（`run.sh` 的绊线禁那个名字）。

### 一、两个开关各自钉的是什么，实测

| 取法 | 状态行条数 | `!!` 行条数 |
|---|---|---|
| `git status --porcelain` | 5 | 0 |
| `git status --porcelain -uall` | 5 | 0 |
| `git status --porcelain --ignored` | 5 | 116，目录塌成一行（`!! .tmp/013/`） |
| `git status --porcelain -uall --ignored` | 5 | 164，逐份列出（`!! .tmp/013/above.txt`） |

两个开关都要，缺一个各漏一类：

- 缺 `--ignored`，`.tmp/` 整个看不见。审查那只手连 `.tmp/` 都不许写，所以那一层必须在射程里。
- 缺 `-uall`，已经在报的那个 ignored 目录会塌成一行，**目录里改了什么都不动指纹**。

### 二、`-uall` 那个坑比行上写的更窄，探针必须放对地方

行上写的是「未跟踪的目录塌成一行」。实测下来，**塌不塌要看那个目录在不在报**：

| 探针放哪 | 只有 `--ignored` 时看得见吗 | 加上 `-uall` 呢 |
|---|---|---|
| `.tmp/<新目录>/deep/f.txt`（目录是新的） | 看得见，多出 `!! .tmp/<新目录>/` 这一行 | 看得见，整条路径 |
| `.tmp/013/f.txt`（`013/` 早就在报，塌着） | **看不见，一行都不多** | 看得见 |

所以自检那一段要造两次：先造目录，再往同一个目录里加第二份。
第一次钉 `--ignored`，第二次钉 `-uall`。**只造一次的话，`-uall` 那一格永远绿。**

### 三、今天这张盘上，`-uall` 单独看不出差别

跟踪那一侧 5 条，加不加 `-uall` 都是 5 条——盘上此刻没有未跟踪的目录，
`docs_meta/docs/design/hooks.md` 是一份文件。
`.claude/agents/` 那个例子（行上引的）已经进了仓库，不再是未跟踪的了。
**差别只在 ignored 那一段看得出来**，所以自检的探针只能放 `.tmp/`。

### 四、`.gitignore` 自己是脏的

工作树里 `.gitignore` 带 `M`。ignore 的集合本身在变，指纹会跟着变。
这不是本刀造成的，也不该由本刀去清。记一笔，免得跑出来的读数被误读成越界。

## 交什么

四件。

### 第 1 件 新落 `docs_meta/tests/check-trace.sh`，第十一本

名字取单字，跟现有十本一个样式。`run.sh` 一个字不用改，它那一行是 glob。

三种用法，**空跑那一路是 `run.sh` 走的**：

```text
bash docs_meta/tests/check-trace.sh            空跑：自检取法。run.sh 走这一路
bash docs_meta/tests/check-trace.sh take       印一份指纹到 stdout
bash docs_meta/tests/check-trace.sh diff A B   两份比，不一致退出码 1
```

指纹怎么算，写死：

```text
git -c core.quotepath=false status --porcelain -uall --ignored   状态行，排序
每一条报出来的路径，只要是普通文件，再算一次内容哈希
```

`core.quotepath=false` 是为了非 ASCII 路径不被转义成 `\xxx`。本机 locale 的坑记在 `PROMPT_015`，同一类。

**内容哈希比行上写的宽一点，这是收紧，写明**。行上写的是「未跟踪文件的哈希」。
本刀对状态行报出来的每一份普通文件都算哈希，跟踪的那几份也算。
理由：一份被改过的跟踪文件前后都是 ` M`，只看状态行分不出它被改了两遍。
收紧是测试这只手的本职，不另发一次授权（同 `check-lock.sh` 脚本头那条理由）。

**射程收窄那一支 2026-09-12 摆过，人当场撤回，记下来省得再议。**
那一支是「只看 `src/` 下和生成的规则 / 角色文件，其余不管」。
它会漏掉两处，而那两处恰好是这只手最可能落笔的地方：
`.tmp/`——行上明写审查那只手连这一层都不许写，所以它必须在射程里；
`docs_meta/tests/`——`review.md` 自己写着那只手的 `Bash` 就在这个目录下跑。
**射程照旧是整个工作树。**

空跑那一路要查四格：

| 格 | 做什么 | 红了指什么 |
|---|---|---|
| **A** | 取一次，退出码 0，输出非空 | 取不到。没有 git、命令非零、目录读不到，都算红 |
| **B** | 在 `.tmp/` 下造一个新目录带一份文件，再取，必须和 A 不同 | `--ignored` 掉了，`.tmp/` 整层不在射程 |
| **C** | 往同一个目录里再加一份，再取，必须和 B 不同 | `-uall` 掉了，目录塌着，里面改什么都不动指纹 |
| **D** | 清掉探针目录，再取，必须和 A 逐字相同 | 探针没清干净，或者指纹不可逆 |

四格都是自检取法，不是自检审查那只手。**空跑这一路永远断言不了「这一趟有没有改盘」**，
因为空跑的时候没有「这一趟」。射程写进脚本头。

**取不到就红，不许静默绿。** 取指纹这一步自己失败了算红，不算「这一趟没改」。

**探针要有 trap 清场。** 脚本半路死掉不许把探针留在 `.tmp/` 里。
留下了，后面每一次取指纹都带着它，而且不会有东西红。

**探针目录名现算，不写死。** 带一次 `$$` 或时间戳，免得两次并跑互相撞。

### 第 2 件 脚本头按 `check-lock.sh` 那份的五段格式写

谁加的、为什么要有第十一本、钉的是哪几裁、口径、查不到什么。

「查不到什么」至少这几条：

- 查不到**是哪只手改的**。指纹只答盘变没变。重档下派出去的是子代理，但指纹分不出是它写的还是领班顺手写的。
- **是事后，不是事前**。不阻止那一次写，只保证那一次写藏不住。事前硬拦在本 harness 的工具面拿不到，三条路各自的代价写在 `PROMPT_014` 末节。
- 查不到**内容对不对**。口径是「变没变」，不是「变得对不对」。
- 查不到 `2.6a`、`2.6b` 那两趟有没有越界。**从装上这一刀起算**，追不回去。
- 空跑那一路查不到任何一次真实的派发。它只查取法本身。
- 查不到 `.gitignore` 改了之后指纹为什么会跳。ignore 集合变了指纹就变，那不是越界。

### 第 3 件 先红后绿，同一刀里跑完，红的输出落盘

两条臂各红一次。**都不许靠改产物去红。**

| 臂 | ②怎么红 | ③改什么 | ④绿 |
|---|---|---|---|
| 取法自检 | 脚本第一版只写 `--ignored`，不写 `-uall`。C 格当场红 | 补 `-uall` | C 格绿 |
| diff | 取一份，在 `.tmp/` 下造一次改动，再取，两份 diff | 不改脚本，这一红本来就该红 | 撤掉改动再取，diff 绿 |

第一条臂红的是脚本自己的第一版，和 `2.6b` 那一刀同一个做法。
第二条臂红的是一次真的盘面变化，**造在 `.tmp/`，产物一个字不动**。

**行上那句「故意造一次越界样本」，本刀按上面这个做法算落了，写明是收，不是漏。**
规划席 2026-09-12 审卡认了这一收。理由：审查那只手零写权限，
要让它真越界，就得先给它写权限或者去改产物，两样本刀都不做。
所以第二条臂验的是**「盘变了，指纹能红」**，不是「审查越界了，指纹能红」。
前者是后者的必要条件，也是本刀在不动产物的前提下能验到的全部。
**别事后读成本刀漏做了一格。**

**没红过的检查不算装好。** 两次红的输出各落一份日志，
落 `.tmp/016/` 下，名字带得出是哪条臂（`red-arm1.log` / `red-arm2.log`）。

### 第 4 件 真派一次审查，然后收口

派的是 `.claude/agents/review.md` 那只手，重档下的那一只，零写权限。
不是规划席。规划席那一页可以另来，不替代这一次。

派的前后各取一次指纹，中间隔的就是那一次派发。
两份落 `.tmp/016/fp-before.txt` 和 `.tmp/016/fp-after.txt`，**路径写死，验收那一节要按名字点它们**，不签进仓库。

**中间只许有那一次派发，领班自己不许插一笔。** 规划席 2026-09-12 审卡点出来的。
顺序写死：**取 A → 派 → 立刻取 B → 之后才写日志、才改 `SESSION.md`。**
先取、再写 `SESSION.md` 或日志、再取的话，指纹必红，而红的是领班，不是审查那只手。
**那种红是假红，会把这一件的意义全废掉。**

**派是收口那一步的对象，不是断言格。** 人 2026-09-12 裁的，原话逐字：
「先是收尾对象，如果检测出红，会上报，视严重程度进行补充或退卡，按这个来就行，
后面全自动化之后，就会变成断言对象」。

所以落法是这样，三层分开：

| 层 | 谁做 | 红了怎么办 |
|---|---|---|
| 取指纹、比对 | 脚本 | diff 不一致，脚本退出码 1 |
| 派成没派成、盘干不干净 | 领班在收口那一步读 | **上报，不自己判轻重** |
| 补卡还是退卡 | 人 | —— |

**领班不许自己消化这个红。** 指纹不一致就原样写进 `SESSION.md` 横线以上，
连同那一次派发前后的两份指纹路径。**轻重是人的那一爪**，这只手只负责让它藏不住。

**没派成也照上报。** 没有派，就没有那个时点，diff 那条臂在真实场景下一次都没跑过——
这件事要写在收口里，不许记成「指纹绿、什么都没发生」。

顺带把那句「后面全自动化之后就会变成断言对象」的射程写清，免得下一刀读岔：
**这一本永远断言不了「派过了」。** 它只答盘变没变，答不了中间发生过什么。
要让「派没派」变成机械断言，得另找一个落盘的物证（审查那一页有没有落在横线以下之类），
那是另一本检查的事，不是把这一本喂胖。

收口三件：`todo.md` `2.6c` 行上那个指针从「写卡中，没开工」改成在办、重写 `SESSION.md` 横线以上、日志落盘。
**不勾行、不写日期、不搬已办、不 commit。**

## 这里有一处口径要说清，不许顺手改松

`review.md:61` 写的是「动了 `docs_meta/src/` 就派——只改一个字也算。不动源码的刀不派」。
按这条口径，本刀不动 `src/`，**不该派**。

**这不是死结，产物里自己留了出口。** 规划席 2026-09-12 审卡指出来的：
`review.md:63` 紧接着写「派与不派由卡片那一格写死；`SESSION.md` 里写『免』才跳过」。
**本刀走的就是这条**——卡片抬头那一格写着「派」，那一格说了算。
所以 `:61` 和行上那一句不是两条打架的规矩，是**默认加上卡片写死**。
本卡第一版把它写成了比盘上更大的矛盾，**这一版收回来**。

**人 2026-09-12 给了正身，原话逐字**：「这次特殊，因为我们在做规则蓝图的施工，
而且并不是传统代码的一一对应，每次『运行』都一致，所以要过 review，
不过这个例外规则不好写，可以想想」。

**理由不是「本刀特殊所以破例」，是那条常规口径的边界画错了地方。**
传统代码里，同一份输入跑两次结果一样，机器兜得住回归；
这张桌的产物是给模型读的规则，「运行」是模型每次重读，不保证一致。
**机器红不了的那一块特别大，人读是唯一的哨兵。**

两句因此不矛盾：`review.md:61` 是默认，`:63` 是出口，行上那一句是人对本刀的裁。
**本刀照人点的做，同时一个字都不改 `review.md`。** 改口径要动 `src/`，是另一个许可面。

### 例外规则怎么写，本刀只提案，不裁

人说「不好写，可以想想」。想的结果摆在这里，**是提案不是裁**，落在哪一刀由人点。

**按「这一刀落下的东西，错了会不会有东西红」划，不按目录划。**

| 这一刀落下的 | 有没有哨兵看着 | 派不派 |
|---|---|---|
| `docs_meta/src/` 里的句子 | 只有几本检查盖到，大部分句子没有 | 派 |
| 一本新检查 | **检查自己没有哨兵** | 派 |
| 卡 | `check-cmd` / `check-link` / `check-done` 看着形状 | 不派 |
| `todo.md` 一行 | `check-done` B「不变胖」看着 | 不派 |

这一支解释得了盘上全部三个已发生的案例（`2.6a` 派、`2.6b` 派、写卡不派），
边界也不至于紧到「改一行 todo 就要派」。
**派审查在这个读法下是什么：给没有哨兵的地方临时补一只手。**

**它写不成机械的，这一点要写明。** 脚本算不出「这一处有没有哨兵」。
所以它只能落成卡片那一格由写卡那只手裁、并在卡上给理由，
而理由只认一类：这一刀落下的东西错了不会有东西红。
**这是说明，不是拦截**——同 `review.md` 自己那句自陈，不许吹成机械的。

顺带记一笔，不在本刀解：`2.6b` 也没动 `src/`，也派了，理由是「动了 `tests/` 且判据自写」。
**`review.md:61` 那句默认，比卡片实际在用的窄**；靠 `:63` 那个出口兜着，所以盘上不会红。
兜得住不等于写对了——默认句应不应该跟着实际用法改，那是源码 ↔ 产物的事，本刀不碰，记在缺口里。
