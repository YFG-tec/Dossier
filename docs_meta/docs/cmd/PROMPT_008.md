## 禁令

- **`paradigm.md` §3 一个字不改。**
- **`check-link.sh` 的 A / B / C 一个字不改**，只加 D；**D 不许设放行词**。
- **D 段按「同一行的词 + 日期共现」数，不许数词频**，见交什么第 5 条。
- **红印那一行不许出现 `cmd/PROMPT_NNN.md` 路径**——B 会红，而那不是误报。
- **红印必须逐字记人说的那句原话。** 不许概括，不许在人没说的情况下由实现那只手自己落。
- **红印只许写一个时点：人说「按卡片做」那一刻。** 不许写「审阅完成之后」。
- **评注不许改横线以上，不许改卡。**
- **提前关闭不许写成 ③ 退卡**，也不许顺手去改退卡那一节。
- **改了早退口就得改「早退口只有两个」那一句**，两处必须同时对。
- **正文一个目录都不许提**（提前关闭那份报告落在哪，人没点）。
- **正文只写到「转呈」为止**，行勾不勾、打不打回，不发明。
- **闸间那两件事一律写成「对领班说」**，不许写成人直接找 builder。
- **「领班可打回 / 可润色」只许落在提前关闭那份报告上**，
  不许渗到收口纪律第 3 条那一页审查上去——那一页照抄不改词，一个字不动。
- **`paradigm.md` §5 只加两个词，不许把 `workflow.md` 的细则抄过去**（那就是第二份）。
- **不勾 `todo.md`**，不写结案日期，不移进已办。
