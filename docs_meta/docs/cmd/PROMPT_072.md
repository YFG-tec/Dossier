## 裁定（人原话为源，法条化）

人 2026-10-03：「工牌很好，有"实体"的分工手册，活儿才能分的清楚，干得明白，这个没问题，我们可以把这个特性做入正式化了」

**工牌（badge）的定义**：并行刀里发给每个 subagent 的一份**自含任务文件**，落 `.tmp/<刀>/<块>/brief.md`，四件套：**产品路径**（唯一可写）、**草稿纸**（本块目录）、**读材料**（含卡）、**验收格**（本块专属）。工牌是分工手册的实体：领班写卡时随分块表一并起草，作为发射指令的同时是块任务的唯一许可面。

**三落点法条**：

1. **roles.md · 代理席节内新小节「### 工牌（并行供给）」**：proxy 派 subagent 施工时**必须**发工牌（四件套齐全），工牌落草稿纸目录内（`brief.md`）；subagent 只吃工牌不吃聊天上下文——「读 `<工牌路径>` 并执行其中全部指令」是唯一发射形；工牌由领班署名（agent=领班名）；块间不通信不互读；subagent 回话落草稿纸 `report.md`，领班汇账后才写 SESSION。首演实证（5.14）：发射通道对长内联参数脆弱，工牌文件制同时解决供给与发射两问。
2. **workflow.md · 新节「## 工牌的汇账（并行收口）」**（收口纪律节后）：并行刀的收口在**汇账**：领班串行核三件——块验收格逐块绿、合集=单手（`git diff --stat` 路径级互不重叠且恰为允许集）、草稿纸合规（report 在、shared 不存在）；汇账全绿才可整刀结案，任一块红整刀不结案。subagent 之间无会合点，会合只在领班。
3. **directory.md · 「9 草稿」行尾注记**：`.tmp/` 条目加半句「并行刀的块草稿纸以 `.tmp/<刀>/<块>/` 分目录，工牌 `brief.md` 与回话 `report.md` 落其内；收口即焚（证据摘录进审查页后整目录删）」。
