## 裁定（卡上定死）

1. **取法三样钉死（施工不许自选）**：
   - **span**：`^## <节名>（→ harness）` 标题行起，至下一 `^## ` 前一行（EOF 止）；**标题行计入**（节改名即内容变，该红）；
   - **元数据排除**：节尾「本节共 N 条可转译项（…）」行与豁免声明行**不进 span**（刷计数不 bump 戳）；
   - **EOL**：逐行剥 `\r` 后 `git hash-object --stdin`（不依赖宿主 git 配置）；**key**＝文件 basename＋节名逐字；**序**＝文件字典序×节现序。
2. **`section_stamp.py`**：枚举 17 标记节按上法算哈希，stdout 输出 TSV（`文件名<TAB>节名<TAB>hash`）一行一节；`--selftest` 自带（伪树两节＋元数据行排除＋标题计入三断言）。母本**不存戳表**（现值现算，存表即覆盖表复活）。
3. **豁免＝声明形状，非集中表**：豁免声明长在各节节尾元数据区（计数行旁一行），字面「按桌改写，不配戳」（卡前全库零命中已验）；枚举一律现算，不存清单文件；**不动节标题后缀**（那是 check-sect 的 join key）。**v1 零豁免**：17 节全配戳；哪节豁免属人裁，出现宿主改写需求时逐节声明。
4. **`tests/check-stamp.sh`**：三查——A 17 标记节每节「计数行在」（span 依赖的元数据位在）；B 豁免声明行若在必在计数行邻位且字面恰为「按桌改写，不配戳」；C `section_stamp.py --selftest` 绿＋实跑 17 行且节名集合与 `（→ harness）` 现算 join 全等。run.sh 变 **21 本**。
5. **workflow.md 丁块**（丙块之后）：三句——转译源各节可配 git 内容戳；取法钉死在 `src/tools/section_stamp.py`（span/排除/EOL 三样以卡 PROMPT_082 裁定 1 为正身，工具是执行件）；按桌改写的节在节尾声明「按桌改写，不配戳」，声明形状唯一、枚举现算不存表。
