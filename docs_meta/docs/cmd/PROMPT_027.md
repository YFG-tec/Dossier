## 这一本查什么

书名默认 `docs_meta/tests/check-skel.sh`。名字的那一件摆在「要人裁」第四件。

### 两路

| 怎么跑 | 靶子从哪来 | 写不写 |
|---|---|---|
| `bash docs_meta/tests/check-skel.sh` | 自己现造一棵：`mktemp -d` 到工作树外，跑一趟 `python -B docs_meta/src/init.py <靶子>` | 只写那棵临时树，跑完清掉。工作树一个字节不写 |
| `bash docs_meta/tests/check-skel.sh TARGET` | 就是 `TARGET` | **一个字节都不写。** 不跑 `init`，不建、不改、不删 |

`run.sh` 走的是第一路（它不带参数）。宿主自己跑的是第二路。红证走的也是第二路。

**为什么不给靶子的时候要自己造一棵。** 母本自己不是宿主，盘上没有宿主树。
另两条路都不行，理由写在「要人裁」第一件。

**为什么给了靶子就一个字节不写。** 把关不许改自己的断言对象。
宿主那棵树里装的是宿主的真活，一本检查跑过去顺手铺了两件，那不是把关，那是第二个 `init`。

- 脚本头照十四本的体例写：第一行 `#!/usr/bin/env bash`，头里有「零权威」「只作证」，
  写清楚查什么、查不到什么、谁加的、为什么是收紧。
