## 裁定（卡上定死，照 lean-rows 人裁搬运）

在「## 状态在磁盘，不在聊天（→ harness）」节末（「聊天里点头不算许可」之前或节尾，不拆既有段）加：

```
### 记录层一律只追加（4.4，2026-10-02）

同一条规矩已有三个名字——卡片闸一冻结、已办区冻住、退卡划掉留在原位。收成一句：
**记录只追加，条款就地改。** 划线在「记录 vs 现行条款」：`cmd/`、已办区、横线以下的审阅是记录，只增不改；
`src/`、待办行是现行条款，就地改（现行层不适用本条）。

已办区原裁照抄：「**只准改名称以及和 todo 的链接，具体内容不准动**」——三个名字里最硬的一格。
**冻住的话后来变假不算假**：按写下那天读，日期就是读法（`check-done` B 已钉住结案日期）。

通俗形是审稿意见的处理：不改审稿人的话，后面逐条写回应；
**连续性靠「原话留着＋回应对得上」两件同时在场**，少一件就验不了。
连带：搬运单位是**「原话＋追记」成对**——只搬正文、把回应留下一起删，等于只发修改稿、扔掉回应信。
```
