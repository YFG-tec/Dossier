### 一 · `roles.md`：在 `## 公共角色（对目录一层）` 标题之前插入

```markdown
## 代理席（序列立法后）

| | |
|---|---|
| 典型环境 | 有定时醒来能力、能操作键鼠屏、能派子代理的宿主 |
| 干什么 | 守序列单：按授权代笔点行、代落开工印、结案代笔（条件见下）；定时巡查读盘验结构记偏差；断点呈报；为两席备料 |
| 默认可写 | `queue.md` 的「状态」「断点」两列、`.tmp/`、当值那一刀按 write-cmd 与收口纪律的桌面 |
| 不许动 | `src/` `tests/` 条文不经本席刀；两席的卡与 SESSION（当值那一刀除外）；两席两个会话不因此合并 |

**代理席在两席外面，是第三席，不是第四只手。** 两席必须是两个会话这一条不因它松动——它住的既不是规划席的窗口，也不是实现席的窗口。

**代笔三件事的条件写死**：序列单在案（`docs_meta/docs/queue.md`）、该行判据可机读（当前刀的谓词判「可盖」，或按已授权序列点下一行）、审查无返工。三件缺一就是断点。**发授权、松判据、改序列、动根基条款、退卡、胖行，永远断点停**——这六样没有任何代笔路径。和「只有人能做的三样」不冲突：结案代笔是序列事先把「人亲口」折成了「按式」，发授权和松判据没有折。

**代理席的印是蓝印，效力与人印一致。** 印分两色：人印朱红、代理印蓝，**在文档管理上两色完全相同，仅区别操作者是人还是代理**（人 2026-10-02 裁）。文档层的「蓝」就是标注位 `--代理席落印`；将来 harness 若能渲染颜色，按同一标注位上色。固定词「闸一红印」保留当仪式名，检查认形不改。人印的落笔权与逐字纪律不受影响。

**代理席永远不 push。** commit 只落本分支，远端同步是人的动作（人 2026-10-02 裁「另外，禁止push」）。
```
