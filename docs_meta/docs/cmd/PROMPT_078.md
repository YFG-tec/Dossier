## 裁定（卡上定死）

1. **立法句落 roles.md:51**：六样永禁清单之后、「和『只有人能做的四样』不冲突」之前插——**自治随谓词走，无谓词不扩权**：常设自治权（自动发印、序列代笔、定时巡查、flash 分档）各绑一个可盖谓词（机器可跑、一票否决、超阈自动断点呈人）；谓词红后人仍可裁继续，走松判据那一爪、原话逐字留痕——谓词与人阀，不许有一方形同虚设。**只绑常设权**：一次性代笔与存量日常裁定授权以留痕代谓词，不回溯判刑。
2. **workflow.md:320 轴句尾补镜像**：「谓词红同断点：常设自治权的可盖谓词超阈，与六样同一停法（立法见 roles.md 代理席段）」——维持「一根轴，不拆开卖」句形，不另造形状。
3. **queue.md 六块各绑**（谓词以句落散文块，不改表——卡面记：hardening §三「表已在，缺这一列」与实况不符，常设令是单行散文块）：
   - 日常裁定：只绑 flash 分档半句——谓词＝审查无返工（check-verdict 返工原子），返工即断点；存量裁定授权不回溯；
   - 默认去向：第三停排出口——连续两刀审查带返工 → 整批停星人（影子门槛 v1）；
   - 发布明令：谓词不适用（永禁，无可超阈的自动路径）——显式记格，防「形同虚设」；
   - 硬化批批注：批级谓词 v1——单刀返工由 check-verdict 一票否决（既有）；连续两刀带返工整批停；代理席读断点格审查读数执行，机检化留待数据格积累后收紧；数据源＝断点格＋git log；
   - 派单路由：回落型谓词——Codex 通道探针红 → 回落 subagent、留痕、不停刀；
   - 代印式：印文谓词＝版次形状过 check-gate，形状不过即断点（印文三律即谓词）。
4. **roles.md:45 巡查格绑谓词**：定时巡查读盘验结构记偏差（谓词：记偏差即断点呈人）。
5. **shadow-report.md 追记**：影子报告升门槛件 v1 立法在案（阈值=连续两刀返工整批停；单刀返工既有否决）；样本仅 4 件返工的局限照写；耗时维度仍留白待 5.13 时戳积累。
