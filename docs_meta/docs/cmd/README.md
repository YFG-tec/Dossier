# cmd/ 这一层是什么

**人 2026-09-14 点名建的这一页**，原话逐字：

> cmd下的文件只做备份和查历史时使用，在cmd 下建个readme就行。主要逻辑遵循/src 以及外面的CLAUDE.md, AGENT.md 等

所以本页是**导航**，不是判据。红绿只认 `../../tests/` 那十四本和卡里预先声明的判据。

## 主逻辑不在这里

| 要找什么 | 去哪 |
|---|---|
| 规矩的出处（源码） | `../../src/` |
| 真能生效的那一份（产物） | 仓库根 `CLAUDE.md`、`AGENTS.md`、`.claude/` |
| 现在该做哪一行 | `../todo.md` |
| 当前这一刀跑到哪 | `../SESSION.md` |
| 某一刀当初让干什么 | 本层 `PROMPT_xxx.md` |

**两边对不上，改产物不改出处。** 方向只准源码 → 产物，没有编译器，只有大模型转译。

## 一份卡是什么

一刀一份，**那一份是这一刀唯一的许可面**。卡上没写的，施工时一个字都不许动。

`../SESSION.md` 和它不是两份公式，是一份加一个链接：卡给人粘贴，SESSION 装本刀的运行态，下一刀覆盖。

## 三个时点决定一份卡能不能动

| 时点 | 卡的状态 |
|---|---|
| 闸一之前 | **还没冻**，随便改，也随便删——它还不是任何一刀的许可面 |
| 闸一红印落下 | **冻结。** 要改走补卡那道手续，补卡不松判据 |
| 结案 | **永久。** 只增不删 |

退卡分两种：**闸一之前退的直接删**（`1.7`：闸一冻结，闸二才永久）；
**闸一之后退的留档盖章**（`2.6f`），卡头盖一个「退卡留档」的章，正文一个字不改，
并在 `../todo.md`「退卡留档」那一节登记一行。

## 卡号

三位定长流水，从 `000` 起，**只增不重用，永不改名**。过千自然长成四位，位宽只增不减。

卡号和 `todo.md` 的编号**各干各的**：编号是可重排的管理视图，卡号是身份锚。
两者的对应只存在一处——`todo.md` 每一行同时带编号和卡链接。

**每份 `PROMPT_xxx.md` 在 `../todo.md` 整页恰好出现一次**，多一次少一次都红（`check-done.sh` A 段）。
所以本页不点任何一份卡的名。
