## 可贴指令（以下整段可直接粘进实现席）

把「`cmd/` 是这一层唯一只增不删的历史」这件事写进文档。现在文档只说它是
「SESSION 的第二个读者」，漏掉了它的第一职责。**本卡点名改合同**（`paradigm.md` §10 一句事实错误）。

### 为什么（写进文档时要保留这个「为什么」）

规矩不带理由就会被下一个人当成税删掉。这条的理由是实战：
**开发时没维护 `cmd/`，出错后想翻「当初到底让干什么」，翻不到，代理排查了半天。**
`SESSION.md` 每刀覆盖、`TODO.md` 勾完删行——在办层三份文件里，只有 `cmd/` 留得住。

三种寿命，一层里就有三种：

| 文件 | 寿命 |
|---|---|
| `TODO.md` | 和项目一样长，但会变（勾完删行） |
| `cmd/PROMPT_xx.md` | **只增不删**——这一层唯一的历史 |
| `SESSION.md` | 每刀整篇覆盖 |

### 交什么

1. **`design/paradigm.md` §10**：把「只有 `SESSION.md` / `cmd/` 每刀覆盖」改对。
   `cmd/` 不覆盖。顺带调整后半句「『冲刺』只描述了后两份」的措辞。
   **这让 §10 的论证更强**：三份文件三种寿命，「冲刺」只描述其中一种，
   「在办」描述状态所以三种都装得下。**不重开改名论证本身。**
2. **`directory.md` 四处**：六块表「寿命」栏（现在只写「下一刀覆盖 SESSION」）；
   别混表 `SESSION` vs `cmd/` 那一行；`docs/` 树注里 `cmd/` 那一行；
   `SESSION.md` 那一行的「不是历史」补上历史在哪。
3. **`workflow.md`「状态在磁盘」那一块**：三行注释里点明 `cmd/` 只增不删。
4. **`roles.md` 写卡那一行 + `cursor.md` 写卡口径**：现在写「`PROMPT_*.md` + 覆盖 `SESSION.md`」，
   容易读成两份都覆盖。改成「新增 `PROMPT_xx.md`、覆盖 `SESSION.md`」。
5. **新增 `.tmp/check-cmd.sh`**：见下「验收」。

写到的路径：`docs_meta/docs/design/paradigm.md`、
`docs_meta/src/{directory,workflow,roles,cursor}.md`、`.tmp/check-cmd.sh`。**只此几处。**

### 不交什么

- **不把 `cmd/` 写成归档。** `directory.md` 明写「不设 `docs/archive/`」，
  且「收口后该留的事实进 `design/`」。`cmd/` 是**指令**的流水，不是事实的归档——
  混了就会长出第二个 archive，和「禁止第二真相」撞车。
- **不给 `cmd/` 加轮转 / 清理 / 条数上限。** 没有这个需求，凭空加规矩就是税。
- 不改 `PROMPT_xx.md` 的字段口径（仍与 SESSION 同一套交 / 不交 / 验收）。
- 不动 §10 的改名论证、不动别的层名。
- 出图脚本搬家、首页结构、`CLAUDE.md` —— 各是 TODO 里另一行。
- commit / push —— 除非人本回合点名。

### 禁令

- **不改 §10 的决议**，只改那一句事实和被它带偏的半句。
- 不新增「归档」「历史层」这类概念名词——`cmd/` 已经在七层里，不另开第八层。
- 不勾 `todo.md`。

### 验收

```bash
bash .tmp/check-cmd.sh 2>&1 | tee .tmp/check-cmd.log
```

三条，都能红：

- **A（白名单 lint）**：列出全部「同一行里既提 `cmd` 又提『覆盖』」的行，
  逐行比对白名单。将来谁再写出「cmd 每刀覆盖」，这条就红。
- **B**：`directory.md` 六块表在办那一行的「寿命」栏必须同时含「只增」和「覆盖」。
- **C**：`directory.md` / `workflow.md` / `roles.md` 里「只增不删」各至少出现一次。

**这三条查的是词的共现，不是意思。** 说清楚它们能抓什么、抓不到什么，
是本刀要交的东西之一——见 `SESSION.md`「独立审查」。

## 人在本回合的三处拍板（记在这里，因为 SESSION 下一刀就没了）

1. **「纯文档项目，一个角色 hold 住。」** 撤销了 §9 那条「一旦改 `src/` 实质条款就该分席」。
   更硬的理由：**分席买的是「两只手写两棵树」**（`src/` vs `tests/`），
   母本没有 `tests/`，分席只换来往返，买不到隔离。已落 TODO。
   残余风险仍在一处：**卡片自相矛盾时该不该退卡**——那里执行的手有利害。
   代偿是照实报告 + 人在闸二认或退。
2. **§6 多了第三条候选判据：「做事的人知不知道自己在哪儿」。** 主观，但能失败，
   而且当事人骗不了自己。来源是人的亲历：开发 Xenia 从不慌（代码就是状态），
   做母本却迷糊（实现层是文字，议论和产物同介质）。已落 TODO，待收进 `design/open.md`。
3. **合同层改成正向标定。** 人提的，标了优先，已落 TODO，卡在 `PROMPT_03.md`。
   起点是人对「占位必须写成问句」的质疑：能不能放宽成「尚未确定」这类提法。
   议下来的结论不是放宽，是**翻方向**——

   | | 现在（标不确定） | 反向（标确定） |
   |---|---|---|
   | 默认 | 可引，除非标了 | **不可引**，除非标了 |
   | 标记丢了 | 沉默升格 —— 失效朝危险倒 | 降成参考 —— 失效朝安全倒 |

   **改的不是宽严，是失效方向。** 标记一定会丢（上下文压缩、摘录、复制、手滑），
   设计该假定它会丢，然后让它往安全那边倒。
   顺带解决三个已知的坑：摘录鲁棒性（不再需要——授权不在被引的句子里，在源头标没标）、
   节 vs 句的粒度、以及本回合刚发现的混态节。
   **「占位必须写成问句」由此退休成写作建议**，理由换成「逼作者说清不知道什么」；
   性质变了理由必须跟着换，否则下一个人会发现它不保任何险、当税删掉——那次删得对。

   两条已经议清的边界，写卡时不许丢：
   - **别另立「已定清单」文件**——那是 `directory.md` 明禁的第二真相。正向**行内**标记，索引 `grep` 现算不存盘。
   - **代价照写：丢了「局部自明」。** 问句看一眼就知道不能引，零纪律成本；
     正向标定要回源头查一次。补偿是这个查询能机器做，且只卡在写卡那一个口。
