## 标记的形状，写死

```text
## <节名>（落 harness）
```

**`##` 后面一个空格，和现有标题一模一样。** 后缀整个挂在节名后面，节名前面一个字节不动。
（**这一行原来多打了一个空格**，两空格是在节名前插字符、性质是前缀，会打掉下面量到的那五本。
人 2026-09-12 裁，原话逐字：「只要一个空格」「纯笔误」。见本卡末「闸一之后动过的」。）

- **固定后缀，全角括号，节名在前一字不改。** 检查按后缀剥。
- **只许出现在 `^## ` 行。** 正文里出现算红（见 D 段）。
- **只划二级节。** `###` 不标，`#` 不标。
- **不是 `【定】`。** 那个标记母本停用了（`2.1`），不复活，也不借它的语义。
  这个后缀声明的是「这一节的条款要落进 harness」，**不是「这一句可引」**。两件事，别混。

**为什么不用别的形状，一并记死省得再议**：前缀会打掉五本（上一节量到的）；

**这不是恒真式，写明为什么。** 标记和引用住在源码 ↔ 产物的两侧：
标记是源码自己声明，引用是产物自己声明，检查 join 两侧。

## 缺口，照记不补

- **下界只覆盖根 `CLAUDE.md` 现在引着的那 14 节。** `diagram.md`、`naming.md`、`sources.md`、
  `verify.md` 几份一节都没进，`cursor.md` 只进了「目标文件」。
  **「还有哪些节该落 harness 但现在没落」是判断，不是本刀的活。**
- **三类对不上的引用仍然没有落点保证。** 节内短语、无节名位置、纯口令词，
  取法按构造把它们排除在 join 之外——**排除不等于解决**，它们引的那几句话谁看着，没人看着。
- **后缀只是声明，不保证那一节的条款真的被抄进了 harness 正文。**
  A 段查的是「根锁引了这个节名」，查不到「引的那句话和节里写的是不是一回事」。
  **意思机器读不了**（`paradigm.md` §6：机检是词的共现，不是意思）。这是本刀最大的一条。
- **只到节级，没到条款级。** `2.6b` 那句「`src/` 里每条禁令」，本刀把「每条」收成「每节」。
  节里有几条、哪一条落了哪一条没落，仍然不可枚举。**这是形状的代价，裁的时候就知道。**
- **`quotes.md` 豁免。** 它 9 条裸引号原句，一条都没有落点保证，也没有地方挂标记。
- **`AGENTS.md` 那个 0 是钉住不许长，不是证明它现在对。** 短锁复述不复述，C 段只答「有没有 join 面」。
- **根 `CLAUDE.md` 里 `workflow.md「全程」` 引了两次。** A / B 段都只要求「至少一处」，
  重复引不红也不合并。要不要去重是产物侧的整理，不是本刀。
- **没有哨兵的是「下界以外该不该划」，不是划节本身。** 下界之内多划红 A、少划红 B，两个方向机器都看得见。
  没人看着的是：某一节根锁现在没引、但它本来就该落进 harness——**那是判断，卡已经交给下一刀。**
  **第一版这一条写成「划节这件事本身没有哨兵」，和 B 段互相打死，规划席 2026-09-12 点出来，本版改准。**
- **抽取器写错是全绿的。** A / B 读同一个抽取器：抽漏一条引用，A 不为它红、B 不去查它，两侧一起静默变小。
  这是本刀唯一一处「红不出来」的漏，靠人读那一格的第二次现算兜，兜不硬。
- **冒烟只证跑得动，不证判得对。** 照 `4.8`。
