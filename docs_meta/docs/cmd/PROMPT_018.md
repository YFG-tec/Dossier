## 标记的形状，写死

```text
## <节名>（→ harness）
```

**`##` 后面一个空格，和现有标题一模一样。** 后缀整个挂在节名后面，节名前面一个字节不动。
**全角括号，括号里是 `→` + 一个半角空格 + `harness`，一共就这一种写法。**

- **固定后缀，全角括号，节名在前一字不改。** 检查按后缀剥。
- **只许出现在 `^## ` 行，而且必须在行尾。** 正文里出现算红（见 D 段）。
- **只划二级节。** `###` 不标，`#` 不标。
- **不是 `【定】`。** 那个标记母本停用了（`2.1`），不复活，也不借它的语义。
  这个后缀声明的是「这一节的条款要落进 harness」，**不是「这一句可引」**。两件事，别混。

**为什么不用别的形状，一并记死省得再议**：前缀会打掉五本（第五条量到的）；
字面被正文占了的、正文写得出来的、带正则元字符的，第六条已经逐支否掉；
另起一行写在标题下面不是「标题形态」，而且会被当成正文，行上那一裁不认；
另开一份节名表是已被否的那一支。

- 多划一节，A 段当场红。修红要往根 `CLAUDE.md` 里加一条出处——**那是本刀给自己扩一次许可面**。

**这不是恒真式，写明为什么。** 标记和引用住在源码 ↔ 产物的两侧：

## 交什么

| 段 | 断言 | 红了指什么 |
