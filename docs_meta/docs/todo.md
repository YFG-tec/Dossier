结了案的行搬到这里，**不删**。新的在上。一条只许占两行，格式写死：

```text
- [x] 原措辞不动 → `cmd/PROMPT_xx.md`（YYYY-MM-DD 结案）
- [x] 〔占位·原措辞无法寻回〕简要概括 → `cmd/PROMPT_xx.md`（YYYY-MM-DD 结案）
```
