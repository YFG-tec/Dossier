## 两处人补的现场，改变了这张卡的形状

**一、双 Agent 是地基，不是档位选项。** 两席各背一条方向相反的品质要求：
参谋席要快出结果、快出结论；实现席要产出稳定、准确。一只手同时背，等于一条都不背。
`readme.md` 只写了「能力差异加上权限差异」，没写差异买的是什么，这两句要补进 `roles.md`。

**二、领班写卡是设计，不是偏离。** 卡本体只有领班写得，参谋只在本页横线以下 review，
**两边达成共识这一刀才往下走**。人称之为民主协商制度。
所以 review 不是事后检查，是两席之间唯一的沟通渠道。

第四版正是栽在这里：它把「写卡的手坐错席」列成第一条真偏离，推出「写卡该搬去参谋席」，
和人这一裁正好反向。撤销之后真偏离从三条减到两条。

**这两条一起读，就是自证缺口的另一面**：实现席这只手只看得见自己那半张桌子，
却在写整张桌子的规矩。补上另一半的是参谋席的 review 和人。
六轮改稿是这套协商在跑，不是它失灵——但它也不能证明这只手够格定两席。
