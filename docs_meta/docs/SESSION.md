### 偏离：卡片是闸一冻结的，人在施工中追加了两裁

卡上第 1 条原话要求写「**只回滚 `src/`** 是完备的」，理由是「④ 被跳过」。人两次追加：

1. **`tests/` 也要跟着清账**（「test 是跟着 src 走的」）。**采纳**——原理由是拿**流程的先后**
   当保证，不是拿原则当保证；退卡若从 ④ 发起，只清一半就漏了。
2. **`tests/` 是删还是改，由 `contract-tester` 自行判断**。**采纳**——机械回滚会把
   「试到一半撞出来、暴露原有代码毛病」的红测一起抹掉，那是知识不是残渣。
   已写死只有删 / 改两向，**不许借退卡放宽判据**。

这两条同时补上了一个卡上没看见的矛盾：`tests/` 要清账，可 builder 本来就不许碰 `tests/`。
现在分清了——`src/` 由领班机械回滚，`tests/` 交回测试席判。

**呈闸二定夺的就是这一处**：本刀按追加的两裁落笔，落成的条文比卡上那句**更严**，
但它确实和冻结的卡片不一字一致。要么认这两裁，要么打回重写卡。
