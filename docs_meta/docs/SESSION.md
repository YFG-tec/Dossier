**这一刀在给一条已经生效的已定判据划射程，等于事后收窄一次已发的授权**，

1. **新段落有没有给「已定条目清单」开后门？** 若这条射程说明同样能放行那份清单，**整刀退**。
2. **「不动 `:153`、只追加」这个做法，本身算不算改了那条判据的意思？**
