## 第 2 件有一处偏离了卡面，照实报

**换掉的是那个限定语，不是那条禁的强度**——原来禁到哪，现在还禁到哪。

**这是偏离，不是授权。** 要不要认，人裁；不认就退回按字面改，那条洞一并记进残件。
