### 第一处：相对靶子被解析到了 Dossier 仓库根

原来 `cd "$(dirname "$0")/../.."` 在参数解析之前。给一个**相对**靶子时，
那个相对路径是相对 Dossier 仓库根算的，不是相对调用者当时所在的目录。

盘上原样跑出来的：

```
$ cd /d/project_init_test        # 这棵树用绝对路径扫是 ALL PASS
$ bash /d/00_Works/33_Dossier/docs_meta/tests/check-skel.sh .
   FAIL: docs/TODO.md（文件）不存在
   ... 共 8 条 FAIL
   现有 3 / 11
FAILED
退出码 1
```

那 8 条报的是 Dossier 仓库自己——Dossier 根上正好有 `docs/`、`.tmp/`、`.tmp/README.md` 三件，
和印出来的「现有 3 / 11」逐件对得上。**子模块正是这个调法**：宿主根上
`bash dossier/docs_meta/tests/check-skel.sh .`。所以这是一次假红，而且长得和真红一模一样。
它也破了卡上两路那张表第 2 行写的「靶子从哪来：**就是 `TARGET`**」。

**改法：** `cd` 之前先把调用者的 `PWD` 存下来（`caller_pwd`），相对靶子接到它后面转成绝对，
之后 `cd` 怎么走都不影响。那个 `cd` 留着——`python -B docs_meta/src/init.py` 是相对仓库根写的。
**没有用 `cd "$target" && pwd` 这种解析法**，那样会把「靶子不存在」「靶子不是目录」两条红路弄坏；
现在这两条守卫一个字节没动。

### 第二处：给靶子那一路不印靶子路径——卡上白纸黑字要求了

卡 `:156`：「靶子路径要印出来。印了人才查得动它落在哪。」
原来 `echo "靶子：$temp_tree"` 在 `if [ "$create_tree" = true ]` 分支**里面**，
给靶子那一路一个字不印。那一趟 16 行输出里唯一带「靶子」两个字的是跳过 E 的那句说明。

**第二处正是让第一处肉眼看不出来的原因。** 人拿不到被判的是哪棵树，假红就长得和真红一样。

**改法：** 那一行挪到靶子存在性/类型守卫之后、`== A ==` 之前，两路共用一行，印的是已解析成绝对的那个。
自造那一路仍然只印 1 行，印的仍是 `mktemp -d` 给的那个路径。

### 第三处：小写盘符——这是实现席自己在验收里试出来的，不是谁报的

修完上面两处之后自己挨个盘符写法试了一遍，撞出残留的同类洞：
那个 `case` 只写了 `[A-Z]:*`，所以 `D:/tmp/...` 和 `D:\tmp\...` 都绿，**小写 `d:/tmp/...` 红**，
报「靶子不存在：/d/00_Works/33_Dossier/d:/tmp/...」。

小写盘符在这台机器上是合法绝对路径，三样现算都认：`test -d` 认、`ls` 认、
`python` 的 `pathlib` `exists()` 是 `True`、`resolve()` 得到 `D:\tmp\...`。
**所以这又是一棵好树被判红，同一类毛病，只是窄一点。**

**改法：** 那个分支放宽成 `/* | [A-Z]:* | [a-z]:*`。没用 `[A-Za-z]` 这种区间——
区间在 `case` 里受 locale 影响，两条明写的分支不依赖 locale。**只动了这一处，全文只多 24 字节。**
