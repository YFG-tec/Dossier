## 这一刀跑出来两个卡上没预料到的坑

两个是同一个形状：**射程是整个工作树，所以这只手自己的输出也在射程里。**

**一、取出来的那一份不许落在射程里。**
`take > .tmp/xxx.txt` 的那一瞬间壳先把文件截空，那一份就把「自己是空的」记了进去；
隔一会儿再取第二份，第一份已经写满，哈希对不上。**前后两份必然不一致，而且全是自指。**
第二条臂第一次就是这么假红的——diff 里三行全是我自己刚造的文件，
真正种下去的那个样本反而淹在里面。改成两份都落工作树外之后，
②红只剩**恰好一行**（种的那个样本），④绿**逐字一致**。

**二、同一个坑在 `run.sh` 那一层再咬一次。**
`bash docs_meta/tests/run.sh > .tmp/xxx.log` 会让空跑的 D 格假红——
那份日志一边长一边被算进指纹，红的是重定向，不是探针没清干净。
实测：日志落 `.tmp/` 里 `rc=1`，落工作树外 `rc=0`，两次盘上别的东西一个字没差。

两条都写进脚本头的口径了。**没做成「自动忽略自己的日志」，因为那是放宽射程**，
放宽是人的一爪；宁可留一条会咬人的真射程，也不要一条自己给自己开洞的假射程。
