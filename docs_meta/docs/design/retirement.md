## 尺与分拣闸（草案全文）

**尺**：「模型没有这个缺陷了，这条还要不要」——要，是**桌子**（补协作缺陷：判据先于施工、盖章的手不是干活的手）；不要，是**脚手架**（补模型/工具缺陷：没有手、没有记忆、分不清说了和做成了、环境会咬人）。

**分拣闸**（推荐的第 0 件理由，2026-10-10 讨论稿）：

- 推荐以分拣开头：这条的存在理由是**补模型/工具之不能**（脚手架），还是**补两方信任之需**（桌子）？
- **桌子免疫于一切「能力已补」论证**——分拣为桌子，提名资格当场取消；代理无法借「模型好了」删分权。
- **缠绕条款先拆半，只准提名脚手架半边**（「状态在盘」两半缠着：窗口省上下文＝脚手架，对账读盘＝桌子）。
- **以出生现场对表，不凭感觉**：规矩当初因「模型/工具不能」立的＝脚手架；因「代理越权/自审/忘留痕」立的＝桌子。考不出身世的按桌子处理——**存疑从严**。
- **分拣错＝断点**（把承重墙当脚手架属动根基判断错，呈人；不是格式打回）。

理由四件制：第 0 件分拣（如上）；第 1 件只补哪个缺陷（模型 or 工具环境，实证形态不同）；第 2 件上游已补上什么（模型能力实证 or 环境规范化读数）；第 3 件退役后哪格接手（须带「已接住的读数」，成熟度不低于被退件）。

## 两级与刀面模板（将来开刀时用）

- **降级刀**（轻）：检查 FAIL 降 WARN 或条文加「观察」注；观察 N 刀零复发（N 按影响面定——被多少检查/桌引用）才有资格开移除。
- **移除刀**（重）：真删；实证＝复现实证＋接手件已全覆盖读数（两样都要）；卡面必写 revert 路径；复发重开新号（编号不复用）。
- 档案五件套（学 Linux）：**What／Date（预告日＋实际移除日，两道手续）／Contact（推荐人＝领班、裁行人＝人）／Description（病＋替代）／Users（受影响的桌与席）**。
