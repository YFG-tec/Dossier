## 2 执行形态：`.claude/` 才是执行本

### 机械隔离只兑现了一半

```yaml

numerics-review.md: disallowedTools: Write, Edit    # 审查什么都不写
```

## 3 可抄的五条

**1. 章名自带禁令。** `docs/TODO.md` 的章标题：

```text
## 下一篇（paper 2，本篇不要开）
## 第三篇（paper 3，本篇 / paper 2 都不要开）
## 系列之后（不挡三篇，也不并进）
## 随后（A1 补之后）……不要和 A1 补抢同一份核
```

章的轴是**交付单元**（篇），括号里那句是**拒超售的栅栏**。同一句抄进 `CLAUDE.md` 禁令「本篇边界」，
两处互为对账。写卡时够得着，超售当场看得见——**这是章分法唯一的实测样本。**

**2. 退卡记法。** 那一行不删，划掉留在原位：

```text
- ~~C2补2 边界条件动态调整的精确写入~~（已作废：皮括号过渡路线，
  提交 f59eefa，2026-08-29 回退，存在 archive/c2sup2-skin。
  「只碰鬼格、不整场往返」与动态 user 目标由 C2补3 设备填皮直达）
```

作废原因、被回退的提交号、证据在哪、**谁取代了它**，四样齐。
母本 2026-09-09 定的是「退卡的卡不留、死因写进下一张卡的现状栏」——
**存的是同一批信息，落点不同**（母本存进下一张卡，Xenia 存在原行上）。两条路都记得住死因。

**3. 松判据是照规矩松的。** C2 那刀把源项钉从逐位放宽到 `rtol=1e-12` / `atol=1e-14`：
用户拍板、写明根因（`libdevice` 的 `pow` 差 1 ulp）、留 60 倍余量，
并且当场写下「**禁止以此为先例放宽其它钉**」。
**这句反先例声明是关键**——没有它，一次合法的放宽就变成了一条可援引的规矩。

**4. builder 停下来报告，不自己拍板。** `SESSION.md` 留着痕迹：
「按退路停下报告，用户已拍板改钉」「builder 构建层偏离（已报用户）……均未动版本 / 公式 / 操作码」。
`builder.md` 末段写死了这个动作：「散了或不守恒时先交**四件套定性**
（哪一项 / 时标 / 初值|边界|帽|合同 / `.tmp` 探针），不准在核里『试一刀修法』。」

**5. 落地提交号写进 TODO 行**（`落地 69509f3`、`8cbcaca`、`71ce457`）。
TODO ↔ commit 是第二条对账轴。母本现在只有 TODO ↔ `cmd/` 一条。

## 4 不可抄的五条

**1. `master` 上，20 张卡有 15 张和实现代码同一次提交落盘。**
`PROMPT_A4.md` 就在 `03e9aa8 feat(xmf): add direction-split HD Godunov` 里面。
只有 5 张落在纯 `docs:` 提交。**闸一确实发生过——`SESSION.md` 和用户拍板记录都在——
但仓库历史证不了**：从 `git log` 看，卡和核同时出现，和事后补叙一模一样。
（前一节那条范围限制在这里生效：分支上可能更好看。结论仍是「`master` 上证不了」。）

**2. 卡名跟着任务号走。** `A4` 一裂开就只能加后缀：
`A4_5`、`A4_AD`、`A4_IR`、`A4_RECON`、`A4_RK`，另有 `B1SUP`、`C1_SUP`、`C2SUP`。
母本 2026-09-09 的卡号脱钩治的就是这个，**这是实证**。

**3. `SESSION.md`（62 行）复述了整张卡**：本刀是 TODO 哪一行 / 交什么 / 不交什么 / 禁令 / 验收命令，全在。
更要紧的是，`.claude/skills/write-cmd/SKILL.md` **把它写成了强制**——
「产出必须两份，内容一致」，下一句又写「禁止 SESSION 与 PROMPT 各写一套公式」，自相矛盾。
**抄这份 skill 的时候必须改**，否则等于把母本已经废掉的「两份卡片」再装回去。

**4. 同一条规矩抄了三份。**「模块化单向」和「IR 只追加」同时写在
`builder.md`、`one-slice/SKILL.md`、`write-cmd/SKILL.md` 里，措辞各不相同。
`XmfConfigC` 与 `xmf_config.h` 必须同步——那是合同层的事实，被抄进了角色定义。
`claude-code.md:43` 防的是「课题锁抽进公共角色文件」，是这条口子的另一边：
**公共角色文件也不许把桌的合同抄进来。** 两边都得堵。

**5. `docs/TODO.md` 295 行**，装着框架图、迭代形式、块状态表、带日期的裁决。
`PROMPT_A5.md` 337 行，**比整份 TODO 还长**——超售的形状。
顶层还有 `archive/`，母本明令不设。

## 5 一处更正：Xenia 有没有合同层

母本现有措辞（`workflow.md:88`）：「**Xenia 没有 `docs/design/`**，346 行的 `TODO.md` 里就长出了带日期的裁决。」

**事实更准的说法是：合同层出现了，但它没有名字，也没有标定，所以接不住。**

- `docs/ROADMAP.md` 382 行 + `KERNEL_AND_CHEMISTRY.md` + `APPENDIX.md` —— 事实上的合同层，只是不叫这个名字，也没有已定 / 草案 / 占位的分态。
- `archive/` —— 人 2026-09-09 指出它代偿了 `design/` 的功能。**核过：它很小**，`master` 上只有 `C2_cuda.md` + `README.md`，2806 字节，历史上也只出现过这两个文件。README 自称「收口刀留下的短档」。

所以代偿是真的，但**代偿层长不大**——它没有「未定的东西合法待在这里」这个身份，
只能收留已经收口的短档。未定的东西仍然往 TODO 挤，那份待办才涨到 295 行。

**这加强了 `workflow.md` 那段论证，不是推翻它**：缺的不是一个目录，是**一个被承认的、能装未答问题的位置**。
措辞该改，论点不用改。
