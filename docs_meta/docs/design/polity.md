## 0 为什么会像

不是因为我们喜欢朝廷。是两边解的是同一道题。

多 Agent、多会话、人又不能盯着它想——约束是这一组：

- 单个行动者的注意力有限，要处理的信息永远比它装得下的多。
- 干活的和负责的不是同一个，信息和利害都不对齐。
- 状态必须外部化：记忆跨人、跨时间、跨会话都不可靠。
- 验证比生成贵，所以永远产得比查得多。

四条一条不涉及生物学。
**社会制度是人类在「个体有限、必须协作、且不能完全互信」这组约束下跑了几千年的搜索。**
搜索结果公开、免费。Agent 编排刚撞上同一组约束，答案会重新长出来：档案、分权、闸、审计、废止。

人补了一句，比「约束相同」更硬：**这么多人组成的社会，本身就是个庞大的智能体。**
约束同构只能预测机制撞车；同一类对象，能预测架构也撞车——记录之于记忆，上报之于感知压缩，立法之于改自己，巡查之于主动采样。

所以越做 Agent，越像政体设计。不是取材，是同题。
官名可以对，也可以不对。对齐的是**失效朝哪边倒**。

能抄的是机制和失败日志，不是机构形态。通信成本≈0，照抄层数就是仪式；Agent 的失败是遗忘和过度自信，不是撒谎寻租。

最值钱的不是成功的制度，是带故障的超长运行日志。任何一套 Agent 架构都还没跑过十年。

## 1 历程要点

只记形状，不记年表。后一种形状很少消灭前一种，多半是叠上去。

| 形状 | 要点 | 反复付出的代价 |
|---|---|---|
| **集会与血缘** | 长老会、共识、当场商量。无常设税，无常备军 | 规模一上来就瘫痪。没有档案，决议随人走 |
| **早期国家** | 王权叠神权。文字让命令离开发令的人。税和军是国家的两只手 | 谁握兵谁就逼宫。神权一垮，王权要另找合法性 |
| **封建 / 分封** | 地方自带土地、武力、财权，向中央称臣 | 外重内轻。中央只剩册封，事在藩镇 |
| **郡县 / 官僚** | 中央派官，官不世袭，任满撤回。档案比人长命 | 官只对上负责。手续变税，底下另开快车道 |
| **共和制衡** | 雅典大会与陶片放逐；罗马双执政、元老院、保民官、任期、独裁官有限期 | 派系把手续当武器。限期一破，独裁官就粘住 |
| **帝国化** | 共和头衔还在，权已经不在编制里（屋大维仍用执政官名义） | 花名册骗人。真朝廷是内廷、禁军、秘书班子 |
| **相权的收与散** | 中国主线：分封 → 郡县 → 三省分相 → 宋再分 → 明废相 → 清军机 | 怕权臣就拆相权，拆完皇帝自己当宰相，门下消失 |
| **教权与双头** | 中世纪教权 / 王权并立，谁也灭不掉谁 | 两套终极权威。同一件事两本法 |
| **同意与税** | 大宪章、议会：不经同意不得任意加税、抓人 | 同意一省，税就变成摊派。议会被买通则空转 |
| **成文分权** | 立法 / 行政 / 司法分开。宪法写下来。法院可判法本身违宪 | 司法若能立法，三权并成一权。宪法若不能改，就只能政变 |
| **科层** | 韦伯：非人格、专业、档案、规则高于在场的那个人 | 档案国家忘不掉。没有日落，规则只增不减 |
| **政党** | 纪律穿过正式机关。候选人、议程、人事在党里决定 | 编制是外壳，真权在党鞭。极权是党国合一，中间层被拆掉 |
| **联邦 / 辅助性** | 未授予中央的权留在各邦。能就近办的不上升 | 界面一松，各邦各写各的法，合的时候炸 |
| **紧急状态** | 戒严、战时内阁、罗马独裁官：快，但写着要还 | 事后不还。临时权变成新宪法 |
| **主权之上** | 国际组织多是软法。没有更高的门下 | 违约的代价是名声和退出，不是被驳回 |

唐三省（中书草 → 门下驳 → 尚书办）是「郡县 / 官僚」叠「共和制衡」的一次具体实现。
明废相是「相权的收与散」走到头：六部直达，内阁票拟，皇帝自己批红。
所以细读要比唐，不比明——领班收口更像尚书，不像内阁。

## 2 对 Agent 借鉴什么

同一张表，右栏换成 harness。

| 人类那一条 | 借鉴 |
|---|---|
| 集会撑不住规模 | 聊天里点头当许可，人一多、刀一长就丢。许可必须落盘 |
| 文字让命令离开发令的人 | 卡是离开会话还能执行的命令。没有卡，命令只活在上下文里 |
| 封建：地方自带武力与财 | 代理若同时握写路径、测试、勾选，就是藩镇。卡点名路径，用完收回 |
| 郡县：派官、任满撤回 | 一刀一只手、只开点名的层。刀结束，工具面收回。不要常设「全能会话」 |
| 陶片放逐 / 弹劾 | 人随时杀会话、撤授权。代理不准自己弹劾自己之后接着干 |
| 任期与独裁官限期 | 紧急放权（全工具、跳过闸）必须有截止日期。没有日落，就是新宪法 |
| 帝国化：头衔在、权不在 | 角色文件还在，事已经从改 `CLAUDE.md`、侧信道、人手改核走——花名册骗人 |
| 拆相权、废相 | 怕代理专权就拆角色，拆完人自己兼六部，闸一形同虚设。该留的是门下，不是更多官名 |
| 两套终极权威 | `design/` 思路和卡许可面必须分清。两本都「可引」，就是教派战争 |
| 不加税须经同意 | 加工具、扩路径、松判据 = 加税。闸一是议会同意。代理自加写路径，就是自己征税 |
| 立法 / 行政 / 司法 | 写卡、改核、测。人兼宪法法院（闸一 + 结案）。检查脚本是小吏，不是最高法院 |
| 科层靠档案 | 记忆在盘上：`SESSION` 起居注，`cmd/` 和已办是实录。模型会忘，档案不许忘 |
| 规则只增不减 | 软件没有死亡，退役必须手写。注释当断言删光、例外清单只加不删，都是这个洞 |
| 政党穿过机关 | 一只「总代理」穿过约定、合同、在办、实现，就是党国。席必须是两个会话 |
| 联邦：未授予的不开 | 卡没点名的路径默认关。辅助性：能在本刀信封里办的，不上升到改约定 |
| 紧急权粘住 | `--no-verify`、不写卡先动核、临时 `all` 工具，最容易变成日常。预授权只给信封里的读写 |
| 没有更高的门下 | 多桌、多仓库没有上级驳回。对账、拒超售，仍然是人 |

收成四句，够用：

1. **慢留在门下（人），快留在部里（预授权）。** 把慢也省掉，制度只剩图。
2. **编制内的官可以少，编制外的使不能多。** 多一行若是为了少停一次，多半在绕尚书。
3. **权可以齐，官不必齐。** 封驳是权，不是又一只代理。
4. **档案比会话长，日落比新增难。** 增量在接口上，减法要手工造。

## 3 细读：唐

比唐，不比明。废相、六部直达、内阁票拟，和领班收口对不上。
宰相在唐的正式叫法多是**同中书门下平章事**。领班更像这个，不必死抠「丞相」。

| 你们 | 不太准的官职 | 对齐什么 |
|---|---|---|
| 人 | 皇帝 | 勾选、拒超售、松判据 |
| 规划席（Cursor / `cursor-desk`） | 翰林 / 侍读 | 调研、议事、辅助决策。草的是**议**不是诏。开桌那一段是正事 |
| `write-cmd` | 知制诰 / 中书 | 草诏，写完停 |
| 闸一 | 门下封驳 / 批红 | **人自己当**，没有门下 agent |
| 领班 | 尚书 / 丞相 | 分派、收口、写报告；少办部务 |
| `builder` | 六部里该开的那一部 | 通常是动 `src/` 的那一部 |
| `contract-tester` | 钦差（不入六部） | 持本刀的节，只收紧 `tests/` |
| `review` | 御史（台谏，不入三省） | 无职掌、零写权限、无否决权 |

三省齐、六部不必凑齐——卡点名哪层，才开哪一部。
**门下齐在权上、不齐在官上，是故意的。**
测试不要写成刑部。审查不判人，只判交出来的东西。
收口的落盘就是报告，不必另设一只手。

可以想想、不必现设：谏官（只能提醒人某行不该开）、给事中（门下既已是人就不单设）、史官（寿命已经分开）、刑部（不要为了改口径再造一层）、九寺五监（有活才设）。

千万别设：

- **节度使**：一只代理同时占 `src/`、`tests/`、勾 TODO、改约定。轻档可以兼帽，必须停顿。
- **宦官枢密**：自己改 `CLAUDE.md`、绕过闸一动核。
- **使职漫生**：顺手加角色 / skill 而不进角色表。编制外的快车道一常设，原来的省就只剩花名册。

慢是设计。真人朝廷用使职换速度，付的是藩镇。Agent 更快，绕起来也更快。

## 4 三句更远的

原文在 `later.md` 附，这里只点题。

1. 自我进化的难点不在能力，在改自己而不改坏——那是修宪。
2. 智能的增量长在个体之间的接口上，不在个体里。
3. 这个智能体没有死亡，所以减法必须手工造。

第一句是门下和松判据。第二句是席、卡、指针。第三句是退役和已办只增。
