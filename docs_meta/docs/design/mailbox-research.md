# 桌间邮箱调研（材料页）

**权威：参考。草案。** 立项：人 2026-10-07「现在很多项目都有dossier了，但是互相送信不方便，我想建个邮箱（后面微信功能也走邮箱）」。四裁：人 2026-10-10 ①「push特许」②「托管选型你先帮我设个简单点的」（代理席代选：GitHub 私仓＋fine-grained token）③「人手写地址簿，先到先得，后来的会提示冲突然后改名才能进邮箱系统」④「挂在 .mail 下」。发件箱起草：同日「另外还需要一个发件箱，可以帮助起草邮件」。产出只进本页，不占刀。

## 形态收敛（git 私仓＝邮局）

```
邮局仓（私仓；submodule 挂各桌 .mail/；push 特许＝专用凭据、只限邮局仓、母本仓永禁不动）
├── address-book.md          ← 人手写；先到先得；撞名提示冲突，改名才能进
└── desks/
    └── <一桌一址>/
        ├── inbox/    ← 别桌投信（git add --sparse；唯一文件名防撞）
        ├── outbox/   ← 自己的草稿与待发（单写者）
        │   ├── draft-*.md   起草中（未封——不是信，不投递）
        │   └── sealed-*.md  已封待投（邮差下个值日周期取走）
        └── archive/  ← 已处理来信＋已发信留底（发信留底＝寄信人案卷）
```

## 三层解法（每桌只见自己）

- **体量**：partial clone（`--filter=blob:none`）——本地只长自己的信；附件禁入（要引大件写指针：仓＋sha）。
- **视野**：sparse checkout 只检出 `desks/<我>/`＋地址簿——别桌目录不落盘。
- **干扰**：一桌一目录＋唯一文件名（`<序号>-<from>-<to>-<时戳>.md`）；自己目录单写者；merge 永远平凡。
- **边界（诚实记）**：软隔离——持 token 理论可拉全部（git ACL 是仓级）；友邻模型够用，硬隔离升级路径＝fork＋PR／一桌一仓，后议。

## 发件箱与起草（2026-10-10 人点名）

**信的生命周期**：`draft`（起草中，可随便改）→ **封缄**（发件人确认，不可再改）→ 邮差投递（add --sparse 写入收件人 inbox＋push）→ 双方 archive 留底。

- **起草帮助**：类型枚举＝刀报／断点／求助／索件／通告／回执——每型一张模板（头字段 from/to/date/type/subject＋正文），领班从 SESSION/todo 现状代填，人改完再封。
- **纪律姊妹条款**：inbox 话不作判据；**outbox 未封草稿同样不作判据、且对收件人不可见**——封缄才是「寄出」的许可面。
- **对人排水统一**：sealed 信标 `type=notify` 的由适配器排水（微信门铃＝标题级推送，殿后实装）——outbox 就是「对人＝适配器排水」那条原设计的实体。

## 纪律条款候选（立法刀的料）

信箱话不作判据；纯文本禁执行；附件禁入；地址簿人签、先到先得、撞名改名；不在簿上的来信进陌生件格；未封不投；投递后双方留底；push 特许只限邮局仓（专用凭据）。

## 成本账（2026-10-10 评估）

- **MVP 两刀**：①信箱立法（纪律＋push 特许逐字入法＋地址簿制）②postman 工具（收发循环＋信件格式＋夹具自证＋发件箱 draft/seal 生命周期）；init 可选装与 partial clone 后置（第三刀）。
- 一次性人力：人 15 分钟（建私仓＋发 token＋签地址簿）；每桌接入一条命令（MVP 期手动 submodule＋sparse 约 10 分钟）。
- 常态运维 ≈0（邮差搭值日班车）；隐性：凭据面＋1、Windows git ≥2.37（`add --sparse`）、push 竞争小重试。

## 本地 demo 坑清单（2026-10-10，`.tmp/mailbox-demo/`，git 2.49.0.windows.1，16/16 读数全绿；产物零权威在档）

| # | 坑 | 对策（进 postman 设计） |
|---|---|---|
| 1 | **邮差发送循环必须「先 rebase 后 push」**——他桌归档随时推进远端，你的 push 变 non-FF 是常态不是异常 | 固定循环：`pull --rebase` → `push` → 失败重试 N 次；demo 实证被拒→rebase→重推成功 |
| 2 | **git init 默认分支名随全局配置**（本机不叫 main 时种子推不上去） | 建仓/克隆一律显式 `-b main` 或 `branch -M` |
| 3 | pwsh 写 UTF-8 无 BOM，powershell.exe 按 ANSI 读＝中文全花 | postman 用 Python 实现（跨平台顺带解决）；若用 PS 必须统一 BOM 或纯 ASCII |
| 4 | PS 5.1 下 native stderr＋`Stop`＝脚本炸（连「cloned empty」warning 都中断） | 同上——别拿 PS 5.1 当运行时 |
| 5 | `add --sparse` 写 cone 外路径成立，但投完那棵子目录会留在自己工作树 | postman 投递后可选清理；留着也无妨——sparse 外不随对方更新，只见自己投的那版 |
| 6 | **file:// 本地 bare 仓支持 partial clone**（实证） | 真托管（GitHub）的 filter＋token 行为留刀期复核（文档化能力，风险低） |
| 7 | cone 模式根文件天然全员可见（顺手收益，非坑） | 地址簿放仓根零配置全桌可见，正合适 |
