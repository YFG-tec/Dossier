## 三样各是什么

### 理念（信什么）

Dossier 信三件事，是它立规矩的出发点：

1. **执行规矩的边际成本，智能体近乎为零。** 一刀一卡、收口对账、图必须打开看、「通过」是预先声明的判据才配用——让人来执行一天做不完两件事，让智能体来是顺手。规矩定得细不是聪明，是现在定得起。
2. **核心不是转化，是取信。** 不是把原料变成产品，是让一个结论可以被相信：判据先声明、证据能复现、盖章的手不是干活的手。
3. **提取，不是汇编。** 这套东西是从几个数值项目里提取、统合、抽象出来的，不是把各桌做法汇编进来。旧桌没有义务回改。

### 框架（怎么立）

理念怎么落地成一套能跑的规矩，就是框架：

- **两席**：规划席（读合同、写卡、对账、拒超售）+ 实现席（动核）。两席可以是任何 harness，但**必须是两个会话**。
- **两道闸**：闸一红印（开工），闸二结案。中间卡是唯一许可面。
- **卡是许可面**：一刀一份 `cmd/PROMPT_xx.md`，卡上没写的，施工时一个字都不许动。
- **权威分层**：约定层 → 合同层 → 思路层（design）→ 在办层（docs）→ 把关层（tests）→ 源码层（src）。目录不是配套设施，是「先把权威分开」。
- **状态在磁盘，不在聊天**：`SESSION.md` 每刀覆盖，聊天里点头不算许可。

### 自治（拿自己开刀）

Dossier 的课题是这套范式本身。仓库叫 Dossier，产物是一套给 AI 代理用的开发范式，**它用自己的规矩管自己的开发**——所以每一刀既是实践，也是被这套规矩评估的样本。

这一样是它和一切「指点别人的方法论」最根本的分界：别的范式可以理念很漂亮、框架很完整，但**它没拿自己开过刀**。Dossier 不是拿一个玩具项目演示给你看，是天天在自己身上跑两席、两道闸、16 本把关，每一刀都是活的样本。**自治就是「凭什么信它」的答案：不是它设计得好，是它已经拿自己验过、还在天天验。**

## 为什么第三样叫「自治」而不是「自举」「特色」

这个取舍在人那儿已经定过一轮，本页记下来免得规划席再绕：

| 词 | 为什么不用 |
|---|---|
| 特色 | 软词、带「卖点」味，和「理念」重叠。而且 Dossier 的特色全是取信机器，不是包装出来的卖点，拿「特色」讲反而把它最硬的东西讲软了 |
| 自举 | 稀罕（自举编译器：编译器编译它自己），人一度很喜欢。但它读起来是**动作**（自 + 动词），和「理念」「框架」两个**名词**不搭，三词不协调。且「自举」本义偏 bootstrap（自己把自己编出来），Dossier 干的是「规矩管自己」，不是「编译自己」 |
| 自治 | 读起来是名词（自由、自信、自觉、自治一路），和「理念」「框架」对齐；「自治」= 自己治理自己，正好是「规矩管自己」的精准对应。代价是「自治区」的政治回声，人认了 |

所以定的是 **理念 / 框架 / 自治**。正文里第一句用大白话「拿自己的规矩管自己」，再点出「自治」这个词。
