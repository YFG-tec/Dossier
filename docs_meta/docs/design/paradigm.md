## 1 范围 — 已定

管三件事，和 `readme.md` 首行那句一致：

- **目录怎么长** —— 权威分层，向下依赖禁止向上污染。
- **工作怎么切** —— 一刀、卡片、两道闸、收口对账。
- **证据怎么算数** —— 判据先声明，「通过」只能引可复现入口。

不管：**课题锁、语言栈、具体物理、具体数值方法。**
也不管某个 harness 的 API 细节——那是落地，写在 `claude-code.md` / `cursor.md`，不是范式。

**判据：一条规矩若必须提到某个物理量或某种离散格式才说得清，它就不属于公共层。**
（`roles.md` 末条「课题锁不抽进公共角色表」是这条的一个实例。）

## 2 读者与场景 — 草案

**草案：以下是判断，没验证过。**

主要读者是**用 AI 写数值 / 科研代码、自己当产品负责人的人**。
特征不是「懂物理」，是这三条同时成立：

1. 代码正确性**不能靠编译和红绿判断**——失败是静默的。
2. 判据要自己造，而且常常做到一半才知道该怎么判（见第 7 节）。
3. 人不打算逐行 review，但要为结论负责。

三条缺一，这套的性价比就掉。缺第 1 条最致命：失败很响的项目不需要这么密的闸。

**次要读者**：任何「agent 能写但没人能验」的领域——数据管线、编译器、协议实现。
公共层已按此写（`roles.md` 审查那一节），但**没有一个非数值桌验证过**。

**占位：这份定位要不要写进 `readme.md` 第一屏？写多硬？**
写硬了劝退大半读者，写软了首页说不清「给谁用」。当前首页两头都没占。

## 3 不变量 — 已定

改这几条就不是这套东西了。它们是范式，不是偏好：

1. **目录 = 权威等级。** 向下依赖，禁止向上污染。
2. **一次一刀。** 不发明新阶段，不顺手并刀。
3. **状态在磁盘，不在聊天。** 聊天点头不算许可；许可面是卡片本身。
4. 这一条管的是**哪些事只有人能做**：
   【定】结案、发授权、松判据，都是人的那一爪。
   - **结案**——勾 `todo.md`。**代理不准自己勾 TODO。**
   - **发授权**——给一行加 `【定】`。加一个标记就是发一次授权。
   - **松判据**——放宽验收命令、改宽检查口径、接受偏离合同的折衷。
     「松」只指这一个方向：**收紧判据是测试那只手的本职**，本来就不在这三样里。
   人可以口头下令、由代理落笔：**`▣` 是谁说了算，不是谁敲键盘**（`diagram.md`）。
   分界是**决定权不下放**；代落的记录该长什么样，见 §5 末段第二档。
5. **发现问题的手不是拍板的手。** 写卡的手不接着改核、改核的手不改测试口径、
   写测试的手不修到绿、审查的手不写文件——四句同一条骨架。
6. **判据先声明。**「通过」只能引可复现入口，不能引 `.tmp/`。
7. **`.tmp/` 零权威。** 只作证，不算通过。

对应到具体条款散在 `directory.md` / `workflow.md` / `roles.md` / `verify.md`；
**这一节是那些条款的上位**，它们矛盾时以这七条为准。

## 5 母本自己怎么管（套娃） — 已定

母本是一张桌，课题是「这套范式本身」。`docs_meta/` 因此长成了桌的形状：

```text
docs_meta/
  src/        规范正文 + figures/   ← 实现层：这套东西本身就是文字
  docs/
    design/   合同层  paradigm.md（本页，准）+ open.md（展开）
    todo.md   在办层  清单
    SESSION.md          本刀卡片的链接 + 运行态，覆盖写
    cmd/                历刀指令，结案后只增不删——这一层唯一的历史
```

**规范正文住 `src/` 不是比喻。** 它就是本项目的产品代码，改它等于改产品。
层的对应：

| 桌上的层 | 母本对应 |
|---|---|
| 约定 | `CLAUDE.md` / `AGENTS.md`（**还没落**） |
| 合同 | `docs_meta/docs/design/` ← 本页 |
| 在办 | `docs_meta/docs/todo.md`、`SESSION.md`、`cmd/` |
| 实现 `src/` | `docs_meta/src/*.md` + 仓库根 `readme.md` |
| 把关 `tests/` | **没有。见第 6 节。** |
| 交付 `docs/reports/` | **不适用。** 没有可跑的东西，就没有「通过」可报；发布形态见第 4 节 |
| 演示 `examples/` | **不适用。** 同上 |
| 草稿 `.tmp/` | 有，且只装一样东西——**出图**。见下 |

一处越界要记：仓库根 `readme.md` 是实现层的一部分，却按惯例住在根上。
它是给外人看的门面，挪不进 `src/`。**除它以外，实现层没有第二个例外。**

### 母本坐几席、分几只手

**席是两个，轻的是手。** 这一段是给 `../todo.md` `2.4` / `2.5` 用的：
它们依赖的是「派不派、几席」——**席不必问，是两个**；要问的是手分几只，那是档位的事。

- **席轴：常设两席、两个会话。** 规划席是 Cursor，也是人的主要参谋；
  实现席是 Claude Code，主会话当领班，领班以下所有手都在这一席。
  **这不是档位选项**：双 Agent 是 Dossier 的最基础要求（人 2026-09-09）。
  两席各背一条方向相反的品质要求——规划席要快，实现席要稳准——一只手同时背，等于一条都不背。
- **手轴：走轻档。** 判据是母本没有「编译运行」，没有能机械变红的东西，
  把手拆开买不到保护对象。所以领班兼着实现那只手，不落 agent 文件。
  正文在 `roles.md` 档位那一节。重判的时点是母本长出能机械变红的东西那一天，**重判的是手**。
- **两席怎么接头：这是母本填的那一格。** 通则只写「卡本体由一只手执笔、另一席 review、
  两边共识才推进」，**执笔的是哪一席由桌自己定**（`roles.md` 两席那一节末段）。
  母本填的是：**卡本体归领班，review 归参谋**，落 `SESSION.md` 横线以下。
  **和桌相反，要写明**——`cursor.md` 写着桌上是规划席写卡，那是**对的**，不是待修的错。
  人 2026-09-09 点出这一层：其他项目不一定有这个结构设计。
  连带一件：审查交参谋席兼办，而参谋席要写 `docs/`，所以审查那只手在母本这里**不是零写权限**。
  这是两席的分工本身，不是省下来的一只手，**因此记在这里，不进第 9 节**。
- **偏离在席内，不在席间。** 母本弯的两条都在实现席内部，见第 9 节。

**母本唯一可跑的东西是出图，而它现在是违规的。** 首页那两张 PNG 由 `.tmp/icon/*.sh`
（headless Edge，`--force-device-scale-factor=2`）从 `.svg` 渲出来。
`directory.md` 写着「机出图必须有可重跑入口（`src/` / `tests/` / `examples/`），不准是 `.tmp/run_*.py`」——
**母本正踩自己的第 4 类失败**：交付层（首页）引用了零权威层的构建入口。

`naming.md` 已经记过这条不自洽，理由是「母本没有 `src/`，这几个脚本眼下无处安放」。
**套娃之后这条理由没了**：`docs_meta/src/` 就是它的家，和它渲的 `figures/` 同层。

**占位：搬过去之后，出图算不算母本的把关层？** 它是母本唯一能机械地变红的东西
（SVG 改坏了渲不出来、尺寸对不上）。但它验的是渲染，不是范式对不对——
**能验的和该验的不是同一件事**，别拿它冒充第 6 节。

**合同和实现在母本这里离得很近，这是真实张力。** 第 3 节写「不变量」，
`workflow.md` 写「实现」——后者是前者的展开，一句话可以同时属于两层。
【定】守法：**能被具体条款矛盾掉的，是实现；矛盾时被援引来仲裁的，是合同。**
换句话说，第 3 节那七条不许被 `docs_meta/src/*.md` 的任何一句改写；反过来可以。

已经发生过一次向上污染：上一刀往 `workflow.md` 写了「合同没填完不开刀」，
和 `directory.md`「开刀先读相关 `design` **一节**」互相矛盾，两天后才发现。
**这类矛盾就是母本的「静默降档」**——没有任何东西会变红。

**合同层有两份文件，分工写死。** 套娃之前 `open.md` 干的就是合同层的活，
现在它搬进 `design/`，名正言顺。两份不许互为第二真相：

| | 写什么 | 权威 |
|---|---|---|
| `paradigm.md` | 合同本体。分节、定案（态写在节标题上） | **准**。但母本停用标记之后它不再发引用授权——态只是立案门槛，见下 |
| `open.md` | 同一批未决问题的**展开**：背景、选项、外部对照、已收记录 | 论证材料，**一处都不标** |

**冲突时以 `paradigm.md` 为准。** `open.md` 可以摆三条路、可以有倾向，
但它写出的任何一个像答案的句子都不作数——**因为它没标，也不许标。**

这比旧规矩硬。旧规矩靠「占位只写问句」把展开挡在门外，**要求 `open.md` 的作者克制**；
新规矩不要求任何人克制，它压根**没有发授权的资格**。**展开不是答案**，从此是结构决定的，不是纪律决定的。
一条问题定案了，把本页那一节的态改成已定，`open.md` 那条移进「已收」。
**母本此后不加标记**，理由见下。

**「不许互为第二真相」不等于「不许有第二份记录」。** 分界是一条判据：

【定】能从别处现算出来的，不存；两份独立产生、可互校的，存——并装一条检查逼它们对上。

前半句否掉了「已定条目清单」：它的内容全在本页，`grep` 一跑就有；
**存一份只会腐烂，而且腐烂的时候没有第三方能发现**。
后半句放行了 `todo.md` 的已办区：那句话是**人在立案时写的措辞**，写在卡片存在之前——
它不是 `cmd/` 的影子，是 `cmd/` 的**上游**。
**而且两边的粒度本来就不同：TODO 是概要，`cmd/` 是具体实施细则。**
概要不是把细则压出来的——压掉什么、留下什么是判断；细则也展不回概要。
**两份独立记录能互相校验，一份派生副本只能腐烂。** 这就是「对账」和「第二真相」的分界。

证据是现成的，而且是反面的：`cmd/PROMPT_1.1.md` 和 `PROMPT_1.2.md` 都只写了
「TODO 第 1 行」，**连原措辞都没抄**。要是已办区真能从 `cmd/` 现算，那两刀的行就不会丢——
它们丢了，只能凭标题补抄。**这一栏该存在的理由，是它自己缺席时留下的洞。**

**上面那条判据划的是「存不存」，没划「第二份该长什么样」。** 补一条，带优先级，没有例外：

**第 n 份记录一律写成链接（指针 / 现算命令）；链接做不到的，抄，但开头必须标出处。**

**这不是给上面那条判据开口子，是说清它本来的射程。**「能现算的不存」从来就管不到链接——
**指针就是「现算」的一种**，顺着它走一步就还原成正文。所以那条判据一个字不用改；
这里补的是它下游的形状问题：既然第 n 份要存在，它该长成什么样。

**优先级不是并列。** 链接排第一，因为它**没有第二份内容可腐烂**；
抄排第二，因为有些位置真的做不成链接。标出处是抄的**入场费**——
抄件不标出处，下一个人分不出哪份是原件，两份一起漂移，而且漂的时候没有第三方能发现。

**为什么写成优先级，不写成「某某可以例外」。** 当场看没差别，三个月后差别很大：
例外是一张点名放行的清单，**下一个人只会往上加名字，不会往下删**；
优先级是一条判断，新情况自己落进第一档或第二档，条文不用动。
**减东西没有例外可扩大，加例外会。** 这句话本身就是理由，不是修辞
（第 10 节写过：不带理由的规矩，下一个人会当成税删掉）。

库里两个现成的落点，一条规矩全收，**不为任何一处点名**：

- `SESSION.md` 落第一档。它是**指向本刀那份 `cmd/PROMPT_xx.md` 的动态链接** + 本刀跑
  起来之后才产生的运行态（状态、**闸一红印**、落盘日志、对账、审查那一页、**执行中评注**、闸二记录）。
  **它不是第二份卡片**——卡片的字段一个都不许在它里面复述。
  红印和评注的细则见 `workflow.md`「闸一红印」「横线以下的评注」两节，**这里只列名，不复述**。
- 领班**代抄审查那一页**（`workflow.md` 收口纪律第 3 条）落第二档，**天然合规**。
  审查那只手不写文件，它的结论只存在于发言里，没有可指的东西，所以做不成链接；
  照抄、标出处、不摘要不合并不改措辞——第二档的要求它本来就在满足。

### 母本停用标记

人 2026-09-09 裁，`../todo.md` `2.1`。**母本只有管理类，所以母本自己停用标记。**

理由只有这一个，写下来免得后人当成税删掉（第 10 节）：标记防的是「拿草稿当判据写卡」，
而**母本的合同层全是管理类**——每个项目都要微调的那部分，`design/` 用宽松语言写**思路**，
实现落 `.claude/` 角色文件，记录落 `todo.md`。宽松语言里本来就没有「一条一条定下来」
的东西可引，**标记因此无处落**。

**桌不一样**：业务结论会攒成一大堆，卡片照着它们写，人不会每条都重读——**标记在桌上不冗余**。
管理类 / 业务类那条线是给所有桌的通则，正文在 `workflow.md`「权威：正向标定」。

**别把这条理由写成「闸一已经在人手里，所以标记冗余」。**
**闸一管许不许做，标记管许不许引，不是同一道闸。** 母本语料小、又全是人自己写的，
闸一那一眼实际盖得住，桌盖不住——那是**程度差**，可以当旁注，不能当主干。

**「先抬进本页才能引」这道手续对母本作废，句号。** 不接着推「那剩下的判据是什么」：
一刀的许可面**仍然是那张卡**（`cmd/PROMPT_NNN.md`）。`todo.md` **只负责点行，不负责供引**——
它的行是概要不是条款，「一行只许是编号 + 点名某一节 + 勾选框」那条一个字不松
（`workflow.md`「TODO 只能长，不能变胖」）。

#### 标记撤了，节标题上的「已定」还算不算数

**算，但只算一半。** 态仍然**不承重**（文首那句原封不动）——不承重说的是**不能被卡片当判据引**。
它是**立案门槛，不是判据**：`todo.md` 页末「占位行不放行，先把那一节定成已定」靠的就是它。
**拦而不授权**，两个角色并存。母本停用标记之后这是**唯一的门槛**；
但开了刀之后，判据仍然不是那个态。

第 3 节第 4 条那三样（结案、发授权、松判据，都是人的那一爪）**在母本身上这么读**：

| | 母本此后 |
|---|---|
| **结案** | 照旧。勾 `todo.md`、写结案日期、移进已办 |
| **发授权** | **在母本没有对应动作了**——没有标记可发。**别把「改节标题的态」当成它** |
| **松判据** | 多一个实例：**把节标题的态从占位 / 草案改成已定，是降低立案门槛**，仍是人的那一爪 |

**桌不受影响，三样照旧。**

## 6 把关：这套东西怎么才算错 — 占位

**这是本页最重要的占位。** 母本没有 `tests/`，所以「绿落盘」在母本这里没有对应物。
现在每一刀的验收都靠人读一遍，这正是 `verify.md` 禁止的那种验收。

**占位：这套范式怎么才算被证伪？** 什么样的观测会让我们说「这条规矩是税，该删」？

【定】能机检的是词的共现，不是意思。

能机械保证的：某几个词必须 / 不许出现在同一行；某张表的某一栏必须含某几个词；
某个词在某几份文件里至少各出现一次；某个标记只许出现在指定的节、且不超过几处。
保证不了的：**整段读下来是不是仍然说反了。**
所以这类检查属于「口」，不属于把关层——它拦得住手滑，拦不住误解。

**占位：把关层还缺的那一半是什么？** 上面那条划清了下界，没给出上界。
第 5 节那个例子提示还能查几样：交叉引用的文件名存在、术语首次出现有解释、
图 alt 与正文口径一致——三条都还没写成脚本。
更值钱的是**引用授权比对**：卡片里每一处 `design/` 引用，被引的原文片段
必须出现在带 `【定】` 的行上。这条是精确子串比对，**机器能百分之百做对**，
而且只卡在写卡那一个口。它现在还没装——库里一处新格式引用都没有，
装上就是恒真式，**恒真式连红的机会都没有**。等标记铺开再装。

**占位：Xenia 回放算不算一次真的测？** 拿 Xenia 已有的历史补丁当**种缺陷测**：
逐个问「如果当时按这套走，它会不会在一刀之内暴露」。抓不到的，说明对应的闸是仪式。
这是目前唯一想得到的、能让这套东西**失败**的检验（对应 `sources.md`「两条值得偷」第 1 条）。
问题：回放是事后叙述，容易自证。**怎么做才不是自证？**

在这一节落地之前，**母本的每一刀都只有「人读一遍」这一道验收**，且必须承认这是欠账。

## 7 适用边界 — 草案

**草案：分档判据是「判据外生还是内生」，不是「项目大小」。**

| | 判据外生（有参考实现 / 金标准） | 判据内生（自己造） |
|---|---|---|
| 该怎么跑 | 长跑，稀疏监督 | 短刀，密集闸门 |
| 这套东西 | 是税 | 是本体 |

第二条分野：**失败响不响。** 编译不过、对不上参考输出是响的；
数值上的静默降档（枚举声明三档、内核当默认档、契约测试全绿）是不响的。
**密集闸门买的不是速度，是让静默失败在一刀之内暴露。**

对照全文与 Anthropic 官方那篇的正面冲击见 `sources.md`。

**这条辩护不能是「模型还不够好」。** 只能是「判据内生 + 失败静默」这两条。
哪天这两条不成立了，就该往长跑退，而不是加规矩。

**占位：这条要不要升成 `roles.md` 档位表的第三个维度（轻 / 重之外）？**

## 8 档位与落地顺序 — 占位

**占位：新开一张桌，默认轻档还是重档？**（`open.md` 第 1 条）

**占位：一刀内部的长跑工程**（tmux、计算节点、detach、几小时后回收）一个字没写。
一刀内部可以跑几小时，闸在刀的两端不在中间——这话说了，工程没写。补进哪一层？

**占位：隔离只做到工具层和路径层**（`disallowedTools` + 约定），同一进程同一凭证。
这是已知边界，要不要写明？审查那只手值不值得单开一个会话？（`open.md` 第 5 条）

## 9 母本不遵守自己哪几条 — 已定

**「不完全遵守」不是豁免，是要逐条写明并说清代价。** 藏起来的偏离就是第 6 类失败。

| 不遵守 | 为什么 | 代价 |
|---|---|---|
| 不建 `tests/` `.venv/` | 母本没有代码。实现层是 `docs_meta/src/*.md`，已按桌的形状落 | 没有把关层 → 第 6 节整节是欠账 |
| 不派 `contract-tester` / `review` | 几乎没有可跑的东西可审 | 同上。一致性只靠人读 |
| 不设 `docs/reports/` `examples/` | 没有「通过」可报，也没有算例 | 无。有阶段时补 |
| 在办层不在根 `docs/` | 根 `docs/` 是给桌的骨架，换根带走 | 无。这是正解，见套娃说明 |
| 出图入口住 `.tmp/` | 历史遗留：套娃之前母本没有 `src/`（`naming.md` 已记） | **有代价**：踩自己第 4 类失败——首页两张图的构建入口在零权威层。套娃之后理由已消失，该搬进 `docs_meta/src/` |
| **写卡的手接着改核**（六条原则第一条）。弯的只有「接着改核」这一步——**领班写卡本身不是偏离，是设计**，见第 5 节 | 母本没有「编译运行」，**手**走轻档，领班兼着 `builder`。人 2026-09-09 裁。**不是「阶段还早」，是结构条件** | **有代价**：卡片可能退化成事后叙述。代偿四条一条不省——写完停在闸一；卡交另一席 review；**两边共识才推进，这是推进条件，不是可选的礼节**；人在闸一裁。**残余风险**：卡片自相矛盾时，判断该不该退卡的是有利害的那只手 |
| **改核的手同时动判据**（六条原则第二条） | 同上，轻档里同一只手兼着测试。实例：`PROMPT_008` 那一刀既写 `workflow.md`，又给 `check-link.sh` 加了 D 段 | **有代价**：判据可以被改核那只手挪门槛。代偿三条：**判据只许收紧**，收紧是测试那只手的本职；**松判据是人的那一爪**（第 3 节第 4 条）；照实报告，不粉饰。**末句是翻转条件，不是阶段**：母本哪天长出能机械变红的东西，重判的是**手**的档位；**席不参与重判**，那时也还是两个 |
| 还没落 `CLAUDE.md` | 约定层空着 | **有代价**：母本自己没有禁令，全靠对话里的约束 |
| **母本自己停用标记** | 母本只有管理类，宽松语言里没有可引的条款（第 5 节） | **有代价，两句**：母本没有可机检的引用授权比对（第 6 节那个占位提过的那条检查，母本此后装不上，桌照装）；**且 `check-mark.sh` A / B 一退，连「有没有冒出第六个标记」都没有东西会红了**——5 处冻住此后**只靠文首那一行字拦**，不靠脚本 |

**原来那一行为什么不见了（`PROMPT_009` 追记，2026-09-10）。** 表里曾有一行「单会话，不强制两席」，
理由写着「当前是抽象讨论阶段，产出是文字不是核」。**它是被换掉的，不是被悄悄删掉的。**

两个毛病。一是判据写成了阶段论，说不清哪天失效——实际上它已经悄悄失效两次

`cursor.md` 和 `claude-code.md` 抬头早写着谁坐哪一席。它大概是规划席还没进环之前写下的，此后没跟着动。

## 10 层的命名 — 已定

七层的名字是产品的一部分，改名等于改产品，所以判据写在合同层。**两条：**

1. **不借外部方法论的词**，除非它的原意和这里一致。
2. **要经得起在正文里反复出现。** 层名不是标签，是每一页都要用的普通名词；
   一放进句子就别扭的，再准也不能用。

### 决议：`冲刺` → `在办`

【定】在办层定名 `在办`，`冲刺` 作废。**本节其余段落是论证，不是判据**——
这正是标记要解决的事：一节标着「已定」，里面能引的其实只有一句。

**「冲刺」是七层里唯一的外来词，而且借反了。** 它是 Scrum 的 sprint：
时间盒、一批 story 打包推进、时间到就结束——正是 `readme` 第 1 类失败「超售」的形状。
用它命名反超售的那一层，别扭是必然的。

第二个毛病更实：这一层装三份文件，**两种寿命、三种角色**：

| 文件 | 寿命 | 装什么 |
|---|---|---|
| `TODO.md` | 待办勾完移进「已办」，**只增不删** | **索引**：一刀一行，一个 `cmd/` 指针 |
| `cmd/PROMPT_xx.md` | **结案后只增不删**；退卡的卡不留 | **指令全文**：当初到底让干什么 |
| `SESSION.md` | 每刀整篇覆盖 | 本刀卡片 |

**「冲刺」只描述得了最后那一种**——时间盒到了就清空。
`在办` 描述的是状态不是形态，所以三份都装得下：**案子开着在待办，结了进已办**，
两边都还在这一层里，名字一个字不用改。这正是它比「冲刺」强的地方。

**寿命只有两种，装的东西是三样。** `TODO.md` 的已办区和 `cmd/` 寿命撞了，
但撞的只是寿命：前者是**索引**，后者是**指令全文**；一个答「做过哪些刀」，
一个答「那一刀当初让干什么」。`directory.md` 那张表的「寿命」栏因此要写**两种寿命 + 三种角色**。
（旧写法「三种寿命」记在这里，免得下一个人以为是笔误。）

**`cmd/` 那一行是实战教出来的。** 开发时没维护它，出错后想翻「当初到底让干什么」翻不到，
代理排查了半天——`SESSION.md` 早覆盖了，`TODO.md` 那行早删了。
理由要跟着规矩一起写进正文：**不带理由的规矩，下一个人会当成税删掉。**
它是**指令**的流水，不是事实的归档——收口后该留的事实进 `design/`，
两者混了就长出第二个 `archive/`（`directory.md` 明写不设）。

**`在办` 取自公文三态：待办 / 在办 / 已办。** 它描述的是**状态——案子开着，没结**：

```text
约定 → 合同 → 在办 → 实现 → 把关 → 交付 → 草稿
              ↑未结                  ↑已结
```

- **和 `立案` / `结案` 同源。** 这两个动词本来就在用，「在办」是它们中间缺的那个状态词——
  不是引进新比喻，是把已有比喻补全。
- **装得下整层。** `TODO.md` 未勾的行同样是未结，不像「冲刺」那样名不副实。
- **描述状态，不描述形态**，所以不必替长期清单和覆盖式卡片找一个共同形状。

**不拆成两层**（待办 / 本刀）：这张表的定义是「目录即权限」，
而 `TODO.md` 和 `SESSION.md` 的写权限完全相同（规划席写，人只勾 TODO）。
**权限面不区分，就不该拆层。**

### 落选的，记下来免得重议

| 候选 | 为什么不 |
|---|---|
| `案头` | 形态词。描述「摊在桌上的那几份」，漏掉 TODO 是长期清单 |
| `刀位` | 语义最贴「当前激活的开发位置」，但放进正文就塌：「未定的东西往刀位层挤」读不通。违反判据 2 |
| `在手` | **和「手」撞车**。「手」是专有词（实现 / 测试 / 审查三只手），「在手层」会读成「归某只手的层」 |
| `在役` | live 感最强，但「役」是军工语域，配文件太硬 |
| 拆成 `待办` + `本刀` | 权限面不区分，不该拆层（见上） |

**「同时只能激活一件」不由名字承担。** 那是第 3 节第 2 条不变量（一次一刀），
写在合同里、由闸一执行。**名字不替规矩干活**——它只需说清这一层装什么。
