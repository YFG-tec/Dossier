## 四条骨

1. **两层制**：todo.md＝工作面（开放行＋章语境，只瘦不胖）；archives/＝案卷层（只增不删、永不清理）。5.27「存档/工作面二分」落到 todo 自己头上。
2. **分代＝发布 tag**：时代线天然、可读性好——「这一版交付了什么」一页即答案。
3. **check 随刀改**：check-done A（每卡恰一次）/B（行不变胖）改扫 todo.md＋archives/todo-*.md **并集**；旧口径扫描不动。
4. **范式级机制**：init 骨架加 docs/archives/（含一行 README）；桌桌同享——桌的 TODO 也会胖。

## 三条边界

- 僵尸开放行（6.2/6.3/5.6 睡着的）**不混此刀**——归档只管闭行；清走睡行归退役流程。
- 编号只增不重用，搬页不改号；旧卡/旧 SESSION 里的「todo.md 5.x」是历史记录，不回改。
- 档案页**永不清理**（案卷只追加）；要「清」的那天走退役尺，不走档案页。
