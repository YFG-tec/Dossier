### 11.2 补一条机制：复合命令按段判，重定向不判

| 探针 | 结果 |
|---|---|
| `echo probe-chain-20260914; git stash list` | **拦** |

- **复合命令按段判**，`;` 和 `|` 分出来的每一段都要各自过 `allow` / `deny`。
- **每一段里的重定向被剥掉**，`> 路径` 那个目标不参与判断（10.1 带控制组量过）。

**对 git 墙这是好消息**：拿一条允许的命令开头、后面接一条被拦的，塞不进去。
