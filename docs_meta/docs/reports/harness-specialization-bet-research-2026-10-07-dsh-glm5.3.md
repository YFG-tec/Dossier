## 1. 问题定义：赌什么、在哪一层赌

「选边站」必须先拆成两层，混在一起就会把产品赌死：

- **产品层（不赌）**：Dossier 的产品就是中立编排——`runtime 可替换，法律不可外包`（2026-10-02 选型报告末句）。在产品层特化任何一家宿主，等于取消自己的卖点。
- **工坊层（可赌，且已在赌）**：这张桌自己的开发体验。现状：三席跑在 Codex CLI 上（queue #9 通道复测绿，派单路由已生效），规划席默认 Cursor。所谓「选边站」的真实含义是：**给工坊选一个主力宿主，把它的产物档与仪器面用满**。

特化的合法对象由此确定：**特化产物，不特化源码**。`docs_meta/src/` 的规矩永不指向特定宿主；特化发生在转译层（5.19 转译内容戳 / 5.20 宿主无关层清单 / 5.30 转译基线种子正是这条线的产品化）。这条线同时就是赌注的保险层——见 §7。

## 4. 逐家短评

### DSH — 结构分最高，年龄最短

- **强项**：MIT＋everything-is-a-plugin（cordis 容器）；子代理后端注册表式（in-process / ACP / SDK / **Codex / Claude Code 可并存为插件**）；Windows ACL 原生沙箱＋沙箱拒访诊断；会话持久化 JSONL＋SQLite 可查询投影＋checkpoint；hooks 协议；goal/jobs/subagent/workflow/team 全家。本机 asar 内 `dsh-llm-deepseek`＋`dsh-llm-pi-ai` 并存——模型中立「有架构迹象，无公开承诺」（README 通篇不提模型面）。
- **弱项**：官方 README 原话 **"Developer preview… THERE WILL BE COMPATIBILITY-BREAKING CHANGES"**——破坏性变更是官方预告，不是风险推测；七周岁；issue 通道读数 0（公开 bug 库缺位，健康度无法由 issue 流读取，须以 release 流替代观测）；`0.2.x` 的版本坐标本身说明产品早期。
- **对 Dossier 的仪器面供给**：四条边界（执行不盖章/建议不改许可面/证据不定判据/调度不拥有角色权限）在架构上都有落点（hook 协议、权限预设、会话导出、模型路由），但**未实测**——PoC 前只能记「有通道」。

### Codex — 现任执行席，Windows 是软肋

- **强项**：Apache-2.0；演进极快（日级＋alpha 流）；已是本桌执行席（0.160.1 在机，派单路由生效）；句级锚定与逐字分析实测优（queue 值日首演读数）。
- **弱项**：本桌 Windows 实测两红——默认沙箱只读、`--sandbox workspace-write` 进程退出挂死（需杀残留）；OpenAI 中心；host 能力弱（Codex 是终端回路，不是能宿 Codex/CC 的编排壳）。

### Claude Code — 仪器密度冠军，闭源是硬伤

- **强项**：413 版 changelog 中 hook×413、permission×490、subagent×296、sandbox×184——**治理仪器的迭代密度与持续性全场第一**；`.claude/agents`+`skills` 整套角色文件已在库（2.6a 落地）；子代理、权限模式、沙箱文档齐备。
- **弱项**：闭源、供应商绑定；本机「CC 不装」（人 2026-10-02 裁）——它在本桌是 adapter 候选，不是工坊主力候选。

### Cursor — 现任规划席宿主，但产品形态不合本题

IDE 产品，不是可编排 harness；`getcursor/cursor` 只是反馈板且 2026-05 后停推；仪器面（对自动化治理而言）最弱。特化赌注不该押它——但它继续当规划席没有任何问题（席位与赌注是两回事）。

### 一轮筛掉（备查）

- **opencode**：MIT、212k 星、周级稳节奏——二轮最值得补观察的一家；本轮 Windows 治理仪器证据不足，未深评。
- **Gemini CLI**：nightly 活跃，Google 中心，仪器面以 MCP 为主。
- **OpenHands**：生态位不同（自主代理平台，非治理型 harness），不进本题。

## 7. 下注方案：分层下注，不是全押

- **第一层（工坊主力试运行）**：DSH 升格为「第二执行席＋编排壳」。现有批（#45/#46）不动；批后拿一张极小卡片在 DSH 上端到端试跑（PoC 判据沿用 2026-10-02 报告 §10 的验收门：mock provider、TaskSpec 单向输入、Windows 沙箱探针、不依赖聊天上下文恢复）。
- **第二层（executor 池）**：Codex 保留主力执行件（质量实测占优：句级锚定优）；CC 保留 adapter 地位（不装机，角色文件已备）。
- **第三层（保险）**：5.30 转译基线种子就是「特化后悔药」——特化只落在产物档，源码永不指向特定宿主；换宿主的成本永远锁在转译层。
- **退出触发器**（任一触发即重评）：DSH 连续 8 周无 release；破坏性变更无迁移路径且伤及仪器面；模型中立被证伪（pi-ai 线废弃且只认 DeepSeek 系）；Windows 沙箱质量退化；社区断崖（fork/贡献停滞）。
- **再评估节奏**：季度轻评一次（release notes ＋ 仪器面 diff），不重开全篇。

## 8. 宏观见解（人点名欢迎的部分）

1. **星数第一 vs 讨论缺位的反差**。市面对比文几乎不把 DSH 放进候选——不是它弱，是 discourse 的语言中心偏差。对一张中文、Windows、DeepSeek 账号在机的桌，被英文圈低估的选项恰是主场。
2. **赌 host 层是唯一不排他的赌**。赌 Codex 或 CC 都是零和押注（押一家产品线）；赌 DSH 押的是「槽位架构」——Codex/CC 是它的插件，全部执行件选项保留。同样叫「选边站」，选的位置不同，锁死的程度天差地别。
3. **特化的正确单位是仪器，不是产品**。迁移成本最高、跨宿主最不通用、维护最痛的是仪器面（hook、闸、探针、证据导出）——特化收益最大的也是它。把特化理解为「全押某产品」是错的，理解为「给某家的仪器档做厚」才对。
4. **演进速度要读质量分解**。DSH 七周 25 release 是雷速，但带官方 breaking 警告——快而碎；CC 日级且仪器词条密度持续在线——快而稳。对 Dossier，合同稳定性权重虽只占 5%，但它是退出触发器里最灵敏的一条。
5. **最危险的时刻是特化见效的时刻**。效率收益会让跨宿主肌肉（check-mirror、宿主无关层清单）静默萎缩——6.14 的教训（`@` 导入在另一宿主静默失效，盘上不红）会以更大尺度重演。保险层（5.30）必须在特化见效**之前**建好，不是后悔之后。

## 9. 附记

- **联网 fetch 结论**（人问询项）：harness 自带 web_fetch 在本环境失效——本机代理 TUN/Fake-IP 模式把域名解析到 `198.18.0.0/15` 保留段，web_fetch 的 SSRF 防护判其为非公网 IP 拒收。网络本身通：`Invoke-RestMethod`（schannel 栈）与 `curl.exe` 在沙箱内另有故障，**Python（OpenSSL 栈）＋显式代理 `127.0.0.1:7892` 全通**，本报告全部网络数据即由此取得。若要复活 web_fetch（对子代理联网取件有用），把代理 DNS 从 Fake-IP 切到 real-IP 模式即可——已告知人，未动配置。
- 与 2026-10-02 选型报告的关系：**推进，不推翻**。四条边界（执行不盖章/建议不改许可面/证据不定判据/调度不拥有角色权限）原样有效；本报告把「DSH 做 executor adapter」推进为「adapter＋工坊主力候选」，真相权仍在盘上文件，不在任何 harness 的 session 里。

### 10.2 三个延伸读数

1. **harness 层的开源建制，国内只有 DeepSeek 一家在下注。** 模型派用订阅计划把 GLM/Kimi/MiMo 塞进 CC/Codex/opencode——等于整个国产阵营替「赌 host 层不赌模型」背书：模型供给只会更多元，host 是稀缺位。国际上这个位子的对标者只有闭源的 CC。
2. **Fork 派的天花板是建制不是热情。** Qwen Code 28k 星很热，但它长在 gemini-cli 的生态位里；Kimi 归档旧 CLI 换新栈，说明 fork 路线一年就要面对一次「续还是换」。
3. **DSH 的国内存在感已有旁证**：第三方分发器 `workbuddy2api-hub`（660 星）的兼容列表写着「Codex / Claude Code / DSH」——三个名字并排出现时，市场已经把它当一级公民对待。

### 10.3 对 §7 下注方案的反哺

- 模型派繁荣 → executor 池的模型弹药只增不减 → **赌 host 层的期权价值上调**（前提不变：DSH 模型中立需 PoC 验证）。
- Kimi 换栈样本 → 退出触发器补一条：**DSH 若出现「换栈式重构」（非演进式 breaking），视为红线信号，立即重评**。
