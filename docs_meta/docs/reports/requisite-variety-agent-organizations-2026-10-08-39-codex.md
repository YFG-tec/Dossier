## 一 · 交叉点的命名

人用的三个词，各对应一门想得很深的旧学：

| 口语词 | 学名 | 想得最深的人 |
|---|---|---|
| 管理科学（组织那一半） | 组织控制论 | Stafford Beer《大脑的设计》（1972）；Ashby《控制论导论》（1956） |
| 管理科学（激励那一半） | 代理经济学 | Jensen & Meckling（1976）：代理成本＝监督成本＋约束成本＋剩余损失 |
| 工程自动化（安全面） | 可靠性工程／事故理论 | Perrow《正常事故》（1984）；Weick & Sutcliffe（HRO 五原则）；Reason（瑞士奶酪模型） |
| 工程自动化（质量面） | 过程控制／防呆 | 丰田 poka-yoke（防呆）、安灯绳、自働化；Deming／SPC |

大模型是**新配料**：它不改变这些定律，改变的是**价格结构**——施工的边际成本塌到零。这一塌，整套体系的经济重心从生产挪到**验证**：治理从「流程部门的事」变成「核心工程学科」。这也是一个可观察的心理读数：当写码免费到令人麻木，让人兴奋的东西只剩「凭什么信」。

## 二 · 现存 agent 工作盘点：有邻居，没有住户

| 工作 | 贡献了什么 | 缺什么 |
|---|---|---|
| MetaGPT（Hong 等，2023） | 最接近：把 SOP 编码成流水线，产品经理→架构师→工程师各吐结构化文档 | 角色是提示词：无写权限分离、无判例、无失败取证——SOP 有了，治理没有 |
| Anthropic 多代理研究系统（2025） | 口径很懂：「代理以平凡方式失败」、上下文当资源管、orchestrator-worker 形 | 只有工程经验，未上升为制度；无人的位置 |
| AI Safety via Debate（Irving 等，2018） | 对抗式验证：两个新鲜上下文互相攻击，人当裁判 | 只在论证域，未落到文件系统与工作流 |
| Prover-Verifier Games（2024） | 可读性（legibility）当生产目标：让产出被更弱的验证者可查 | 未接到组织设计——而这恰是卡面／机检判据在做的事 |
| Process supervision（Lightman 等，2023） | 奖过程不奖结果——「判据先于施工」的实证亲戚 | 单人推理域，无多代理 |
| Constitutional AI（2022） | 原则治理的样板 | 自审——同源偏见的天花板，恰是本体系的反例标本 |
| MCP | 工具的语义层——与 36 桌「通道→语义键」同构 | 只做接入，不做信任 |
| Claude Code subagents | 上下文隔离 by construction | 有隔离无治理语义（母本正是补这层） |

结论：**没有一家把三维焊在一起**。最接近的居然是两门旧学（Beer、Perrow）加一个新价格结构。白地在此。

## 三 · 经典地基（与我们盘上概念的对应）

| 思想家 | 原理 | 对应本范式里什么 |
|---|---|---|
| Ashby | **必要变异度**：控制端变异度须覆盖干扰端变异度，系统才可控 | 新鲜上下文审查（§五展开） |
| Beer（VSM） | 组织五系统：操作／协调／审计／情报／政策；System 5 不可被 System 3 吸收 | 手／领班巡查／审查／值日手与退役尺／人在断点 |
| Perrow | 交互复杂度 × 紧耦合 ⇒ 系统级事故；解法是解耦 | 路径互斥→同波；相交→合卡或拆波——从规则升为事故理论 |
| Weick & Sutcliffe（HRO） | 五原则：专注失败、拒绝简化、敏感于现场、韧性、让位于专长 | 活标本纪律／打标不抹平／状态在盘／退卡修缮路径／人在断点 |
| Jensen & Meckling | 代理成本三件套；监督是有价活动 | 流程税的经济学本体；「人在断点」＝剩余损失不可接受处 |
| poka-yoke（丰田） | 把错误做成物理上不可能，不靠叮嘱工人小心 | 「写权限形状 > 宣言」——工业界四十年前完成过同一次范式切换 |

## 四 · 一块地板：一条定律加一条预算

> **必要变异度定律（Ashby）：只有控制端的变异度覆盖干扰端的变异度，系统才可控。**
> **预算轴（Jensen & Meckling）：代理成本＝监督成本＋约束成本＋剩余损失；治理＝在这条预算下做变异度工程。**

每个治理机制按此分四类：**注入**变异度（新鲜上下文、人裁）、**通道化**变异度（权限形状、工牌）、**存储**变异度（案卷、判例）、**以成本换变异度**（谓词自动化：便宜但变异度低，只在词共现够用处用）。

## 五 · 已有概念的变异度重述

| 已有概念 | 变异度语言 |
|---|---|
| 新鲜上下文审查（原理注④） | **变异度注入**——同源审查必然失败：审查器的变异度被生产上下文预削减（共享同一偏见模型），对该模型自产的误差没有互补变异度。由经验观察升为 Ashby 推论 |
| 权限形状 > 宣言（母本规划席的修法） | **变异度通道化**——poka-yoke 的组织版：让错误构不成犯罪要件 |
| 状态在盘／案卷 | **变异度存储**——「当时为什么」跨时间搬运 |
| 公理 vs 判例（本轮论战） | **压缩存储 vs 富存储**：同一资源的两种编码，非敌对；判例摘要层（Restatement）是两种编码间的指针 |
| L4（生成器＋ID 覆盖率）为什么死 | 机械 ID 是极低变异度信号，对语义失败没有 requisite variety——ID 全在场、墙照样丢；39 桌搬迁刀即实验数据 |
| 退役尺（「模型没这缺陷还要不要」） | **变异度折旧审计**：这条规矩当初防的干扰源还在吗 |
| 断点分级（未解题） | 理论入口：谓词够不够＝失败模式的**可词测性**分析——词共现能守的交谓词，需语义判定的永不代笔。分类器有了第一性依据 |
| 人在断点 | **变异度的最后来源**：机械与判例皆不足时，只有持有目的的委托人能补——VSM：System 5 不可被 System 3 吸收，吸了组织失去身份 |

## 六 · 三个可检验预言

1. **同源审查在对抗性失败上必然失效**——可做对照实验：同一刀，A 组单上下文（写卡手自审），B 组工牌隔离＋新鲜审查；预测 A 组漏检率显著高，且漏的恰是「与生产上下文偏见同向」的错。
2. **权限形状化后违规率断崖**——从「事故」档降到「蓄意造假」档（防呆件预言）。
3. **谓词断点的失守模式可分类**——凡失败模式可归约为词共现的，谓词守住；需语义判定的，谓词必漏——给「断点永不代笔」立法提供分类程序而非口号。

## 七 · 诚实的边界与研究纲领

Ashby 定律是控制论定理；把它搬到认知组织（Beer 做过，争议大）与知识验证是**类比不是形式化**。研究纲领一句话：**把「面向代理组织的必要变异度」formalize 出来**——比「六条不变量」高一层的题目。标题即候：*Requisite Variety for Agent Organizations*。39 桌既是论据来源，也是产品化验证场。

## 八 · 仪器时刻：管理科学为何今天变硬（附人的原话）

人（2026-10-08）：「我以前看不太起管理科学，觉得华而不实，现在用上了，觉得自己的知识不够了。」

结构性原因：管理科学长期**没有仪器**——公司不能做对照实验、组织不能复现、幸存者偏差遍地，无硬选择压力则废话活得下来。化学在天平之前是炼丹，医学在随机对照试验之前是经验谈。**agent 组织第一次给了这门学科实验室**：可复现、失败模式可枚举、治理结构可 A/B、标本可带完整取证存档。学科边界正在此处移动。
