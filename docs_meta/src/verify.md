# 验证与排障

不铺进宿主工作区。原则见仓库根 `readme.md`。交付落点见 `directory.md`。

## 验证诚信

主要从 `31` 抽；另两桌的「不能只靠看起来像」是弱形式。目录上的含义：结论写在 `docs/reports/`，数字来自 `src/` / `tests/` 的机器产出，图内嵌在报告里。

- 禁止同义反复：计算值与期望值不能同源。
- 写测试先问：什么样的实现 bug 会让它报错？答不上来就重写。
- 「通过」只用于预先声明的量化判据，且只出现在交付层。`.tmp/` 只写「实测得到 / 预测被否定 / 未定」。
- 未做的写「未实现」，不写「待下一阶段」。
- 收敛至少 3 个网格，给实测阶，不说「残差变小了」。
- 报告数字对回 JSON / 日志，不凭记忆；口径对齐要写明。
- **图是断言。** 必须打开看。坐标 + 单位 + 网格/时间参数。
- 控制组 / 故意的错误实现要画在图上，并在读图里点名。

阶段报告最低结构：

1. 目的与判据
2. 方法与参数
3. 可复制的运行命令（入口在 `src/` 或 `tests/`）
4. 结果：表 + 内嵌图
5. 限制：本结果推不出什么
6. 结论：对照判据逐条 通过 / 未通过 / 未测试

探索要进 `src/` 的门槛预先写在 `docs/design/` 草案里：收益/代价、不破坏旧判据、一条能失败的新判据。不满足就写「实测不划算，不实现」。

## 排障也是开发流程

散了先分类，再改 `src/`。定性书面四件套，缺一件不准动离散：

- 哪一项
- 哪个时标
- 属于哪一类（初值 / 边界 / 稳定帽 / 合同 / 真泄漏）
- 证据在哪个 `.tmp/` 文件

只跑过探针 ≠ 已定性。禁止把拧旋钮当第一修法。
约 3 轮仍无定性：停堆标量，图出到 `.tmp/`，看形态再决定。
要正式留证，进引用它的那份文档所在层的 `figures/`。禁止 `docs/figures/`。

## 引行号前先现算（→ harness）

- 通读页/验收页/结案呈报里凡写「文件:行号」形引用，**写之前对该文件跑一次取行号的命令**（grep -n 形），抄读数不抄记忆。
- 行号引用必须带**取数时点**（commit 哈希或「施工第 N 步后」）；隔了写入动作的旧读数不得复用——6.20「三个时点各现算一次」的同族推广。
- 错了不改数字凑数：发现引用行号过期，重跑取数、更新引用，并在当页注一笔「行号已于 X 重算」。

## 环境只留与复现有关的

- 解释器钉在项目内 `.venv`，命令写进卡片和报告。
- 画图不弹窗。
- 命令从项目根复制即可跑。

语言栈和同步脚本是项目自己的，不进公共范式。

## 本套验不了什么（→ harness）

- 唯一验收入口可能长期红，绿灯因此失去证明力；回链 `todo.md` 6.11。出路：harness 把入口红当阻断态公布，红灯再出现时由人点修复刀。
- 写权限的出处可自相矛盾，机械检查没有唯一判据可对；回链 `todo.md` 6.12/6.13。出路：人先裁哪一份是出处，6.13 收表。
- 设计好的导入或权限通道可在宿主里静默失效，盘上不红；回链 `todo.md` 6.14/6.19。出路：宿主/harness 提供生效探针，母本只记录风险形状。
- 代理守住全部禁令仍可能做错，因为正确行为还缺「谁、哪步、闸」；回链 `todo.md` 6.15/6.17。出路：开卡时由规划席把三件套写全，人闸一验收。
- 权限面不可自省，代理问不出此刻什么真被允许；回链 `todo.md` 6.19。出路：harness 装 PreToolUse/PermissionRequest 仪器，守卫产品化归人裁决。
- 机械绿灯可能不是判据给的，假绿与真绿长得一样；回链 `todo.md` 6.19。出路：验收日志必须对回预先声明判据，权限绿只当环境事实，不当判据结论。
- 结构检查绿不等于条款真被覆盖，缺失不会自己红；回链 `todo.md` 6.22。出路：另开覆盖/完整性检查刀，审查席仍要人读判据。
- 同一命令换平台或干净环境可能跑不起来，本机绿不能外推；回链 `todo.md` 6.25。出路：harness 定解释器、shell 与最小矩阵，运行时契约由人另立刀。
- SESSION 上下两截的寿命两处出处说法不能并存，机械无从判定哪句现行；回链 `todo.md` 6.16。出路：寿命句归一入 directory.md，36 桌升级后复验销账。
- `TODO.md` 在权限表上没有格子，越没越权机械查不出；回链 `todo.md` 6.18。出路：权限表补行并写清两席各自什么，覆盖检查另立刀。
