# 原句

不铺进宿主工作区。设计思维见仓库根 `readme.md`。

- 「状态落在 TODO 和 SESSION，不靠聊天记录。」
- 「聊天点头不算。正式文档只有本刀 PROMPT 和 SESSION。」
- 「任何被报告引用为验证通过的代码，必须位于 `src/` 内。」
- 「`.tmp/` 里的探索性实验一律不得使用『通过』二字。」
- 「不要勾 TODO，留给用户看完再勾。」
- 「只跑过探针不等于已定性。」
- 「图题和注记也是断言。」
- 「没有引用它的正式文档，就没有正式图。」
- 「不准开 `docs/figures/`；重复图就复制。」
- 「调研稿不是草稿箱。」
- 「核错了写红测并回报，不要在测试角色里修到绿。」
- 「四个角色不要同时改同一份核。」
- 「主会话当领班，自己少写核。」
- 「原则上角色要分开；没做这么严，不是可以混岗。」
- 「新桌出自母本；铺出来的是管理骨架，不是物理代码。」
- 「三桌里有的，不自动进公共层。提取、统合、抽象、升级，不是汇编。」
- 「审查不读实现者自评；绿必须落盘，不能只在聊天里报。」
- 「审查只核对结果和标准，不问做法。」
- 「人做这套会累死，智能体不会——所以现在定得起这种规矩。」
- 「这七条防的从来不是人，是不受约束的智能体。」
- 「核心不是转化，是取信：凭什么说它做成了。」
- 「立案、举证、对账、结案——只有结案是人的。」
- 「章不能自己盖给自己：写卡的手不接着改核，改核的手不改测试口径。」
