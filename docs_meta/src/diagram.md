# 框架图

不铺进宿主工作区。原则见仓库根 `readme.md`。图标见 `naming.md`。落点规矩见 `directory.md`。

已落图：`docs_meta/src/figures/dossier-frame.png`，挂在 readme「建制」里。
它不是装饰，是**门面唯一一次把两件事同时说清**的机会：
谁许写哪一层，以及换阶段就是换手。这一页是它的判据：说什么、不说什么、画成什么、放在哪。

**这张图画的是「桌上的一刀」，不是母本自己的目录。** 母本里没有 `src/` `tests/`。
图上出现它们，是因为规矩作用在桌上。这条要在图注里写死，否则第一位读者就会以为 clone 下来带着求解器。

## 一图一论点

图是断言（`verify.md`）。装饰性框架图是最典型的「图没人看」——第七类失败。

> **主：目录即权限。** 谁许写哪一层，一眼数得出来。
> **副：流转跟着权限走。** 换阶段就是换手；人只站两道闸。

主副不能倒过来。第一位读者最该先懂的是权限，一刀怎么走是权限的推论——
先有「规划席打不开 `src/`」，才有「立案之后必须换手」。

这张图值得画，是因为它是**唯一一张既有 ASCII 都没画出来的**：
`directory.md` 的十层说「写到哪」，`roles.md` 的顺序表说「先后」，`workflow.md` 的信息流说「谁到谁」——
三份各说一维，没有一份把「层 × 手」摆成一个面。摆成面之后有四件事自己浮出来：

1. **写权限的实心格一级级往右下走**：约定归人，合同人和规划席共写，在办规划席落笔、人勾一下，再往右整块交给实现席。行按权威从高到低排，这道台阶才看得见——权威沿目录一层层往下交，不是几块地盘平摊。
2. **人的实心止于在办**，最后一格是朱。再往右，交付只读、草稿不碰——人不进 `.tmp/`。
3. **实现列和把关列不是同一只手。** 实现席拆成三行，`src/` 和 `tests/` 各归各的：改核的手在实现列，写测的手在把关列，两格错开不重叠。压成一行就等于说「改核的手可以改测试口径」，`readme` 五条里的第二、三条当场作废。
4. **审查那一行一个实心都没有。** 整表唯一一只全空的手，连 `.tmp/` 都不给（`roles.md`「除审查外都可写」）。审查的手不写文件——这句话本来要靠读，现在数格子就够。

和图标同一个规矩：整套流程里只有一件事需要重音，那件事是结案，而结案是人的。

**▣ 是「谁说了算」，不是「谁敲键盘」。** 这条口径得先钉住，否则这张图没法读：
这个仓库的前提就是人不敲键盘（「干活的是智能体」），照落笔算，人整行都该是空的。

顺带补出一格 `directory.md` 原先没有的：**约定层规划席只读。**
被约定管着的手要是自己就能改约定，约束就是装饰品——
`readme` 说「防的从来不是人，是不受约束的智能体」，这一格是那句话在目录上的落点。
起草 `CLAUDE.md` 仍然是规划席的活，但落槌的是人。和「改核的手不改测试口径」同一条。

## 版式（SVG 蓝本）

横轴是层，纵轴是手——**五行，不是七行**。层排开来图就横过来了，不往下堆。

**行序是权威从高到低**：人 → 规划席 → 实现席那三只手。不是随手排的，台阶要能看出来。
实现席三行左边加一道括弧圈起来：一个会话，三种写权限。

`▣` 写　`○` 只读　`·` 不许碰　**朱**＝只有人能落

| | | 约定 | 合同 | 在办 | 实现 | 把关 | 交付 | 草稿 |
|---|---|---|---|---|---|---|---|---|
| | **人** | ▣ | ▣ | **▣ 朱** | · | · | ○ | · |
| | **规划席**（默认 Cursor） | ○ | ▣ | ▣ | · | · | ▣ | ▣ |
| 实现席<br>（默认<br>Claude Code） | **实现** `builder` | ○ | ○ ※ | ○ | ▣ | · | ○ | ▣ |
| | **测试** `contract-tester` | ○ | ○ | ○ | · | ▣ | ○ | ▣ |
| | **审查** `review` | ○ | ○ | ○ | · | · | ○ | · |

※ 卡片点名才改合同。
两席那几行出自 `directory.md`「一张目录把两席的写权限钉死」＋ `roles.md`「公共角色（对目录一层）」。
人那一行是这张图逼出来的——原表只有两席两列，没有人，也没有约定这一层；现已补进 `directory.md`。
**图上只写「实现 / 测试 / 审查」三个词，不写 agent 文件名**（上表的反引号只是给这一页对账用的）。

**手名从 `roles.md` 取，不从列名取。** 第三行原先写「把关」，是拿层名当手名——
层「把关」是 `tests/` 那一层，手「测试」是 `roles.md` 的**契约测试** `contract-tester`，两者不是一回事，
同名会让人读成「把关这一层有一只叫把关的手」，而右边草稿列它也有一格。
取两字是版面对齐（实现 / 测试 / 审查同宽）；不缩成「单测」，因为 `tests/` 装的是契约 / ABI / 模块三种，
单测只是其中一种（`directory.md` 代码侧对照表），缩窄了这只手的写面。
第二行「实现」和实现列同名不必改：`roles.md` 的手就叫**实现** `builder`，层也叫实现，
同一个词指同一件事，对角线上那一格正是「实现的手写实现层」。

底下压一条流转带，一行高，不抢主体：

```text
  ├── 规划席 ──┤├──── 实现席（三只手串行，不并行改核）────┤├── 人 ──┤
      立案            施工        举证         对账              结案
                      实现        测试         审查
  ┊ 闸一「按卡片做」                                    ┊ 结案「勾 TODO」
```

**两张子图必须接得上**，否则下面那条就是装饰。接法有三处，缺一不可：

1. 中间一行带箭头的桥：「同一批手，摊到时间上——上表说**谁许写**，下带说**什么时候轮到谁**。」
2. 施工 / 举证 / 对账三段各挂一只手（实现 / 测试 / 审查），字号压小、灰色——**就是上表实现席那三行**，一一对上。
3. 两条带的席位名用同一套词：规划席 / 实现席 / 人。

流转带压一块浅灰底、并且左右内缩，是画的时候补的一条：两条带都横着排，
不压底就会被顺着读成矩阵的续行——而「举证」正好落在「实现」那一列底下，是个真会看错的位置。
底色和内缩把它降成另一层：**接得上，但不对齐**。这两件事要同时做到。

两道闸对上 `workflow.md` 说的人每天四件事：闸一是看 SESSION + 拒超售，结案是看红绿 + 勾 TODO。
横轴的词都是现成的：立案 / 举证 / 对账 / 结案出自 `naming.md`，「停」出自 `workflow.md`，
「施工中」「已收口」出自 `roles.md` 的卡片状态字段。

## 不画什么

| 不画 | 为什么 |
|---|---|
| 归档 | 它在结案之后，画进去会把「朱印是终点」的重音往后拖一格。报告入库是 `directory.md` 的事 |
| Cursor / Claude Code 的 **logo** | 名字可以带，但只能是灰色小字、且**必须带「默认」二字**。带了「默认」，读者知道席位是权限结构、harness 可换；不带就成了两家产品的广告 |
| agent 文件名（`write-cmd` 等全套） | 那是重档落地厚度，`roles.md` 的事。图上只写「实现 / 测试 / 审查」三个词 |
| 领班 | 它派角色、跑收口，不占写路径。矩阵按写权限分行，多一行全是圈的手，会把「审查整行全空」那条重音摊薄。它在流转带的「对账」段里 |
| 七类失败 | 图讲正面结构。画出来变成七个红叉，重音就散了 |
| 十层权威全表 | 门面图不做手册的缩略版。`research/` `papers/` 是加厚，不进门面 |
| 母本自己的目录 | 图讲桌上的一刀。母本没有 `src/` |
| 两席画成两个并排方块 | 图标已经因此拒绝画两席（`naming.md`）。这里席位是**纵轴上的行**，不是盒子——而且实现席一席就占三行 |

## 形式与落点

**matplotlib 出图**：脚本 `docs_meta/src/figures/make_frame.py`，出 `dossier-frame.png`（`880 × 512`，实际 `1760 × 1024` 2× 图）。
色板沿用 `naming.md`，笔法按「版式（SVG 蓝本）」这一节。

readme 引的是 PNG。这张图带中文，字体不在读者机器上就是一片豆腐块。
可重跑入口见脚本头注释（依赖：matplotlib 3.9.1.post1, pillow 10.4.0）。

**只出浅底一版。** 深色版是 app-icon 那种容器才需要的东西；正文插图跟着页面走，
GitHub 深色模式下浅底图会亮一块，但代价小于维护两份形状——图标那两份已经证明改一次要改两处。

**只认桌面。** 横版在手机上缩到约 340 宽，最小字号必糊；不另出竖版，也不补等价文字段。
门面图的读者是坐在电脑前决定要不要 clone 的人。

色板沿用 `naming.md`：墨 `#1D1D1F`，朱 `#D9342B`。朱只用在人那一格。

readme 顶部图标维持现状：只挂浅底 `.png`，不上 `<picture>` 双版。

**合规性**：它被 readme 引用，readme 是正式文档，所以是正式图
（`directory.md`「没有引用它的正式文档，就没有正式图」）。
它是**机出图**，有可重跑入口（`make_frame.py`），受 `directory.md:199` 约束。
住 `docs_meta/src/figures/`，不铺进宿主工作区，不进 `docs/`。

建 `.venv/` 装依赖：在仓库根创建虚拟环境，激活后跑脚本。具体版本见 `make_frame.py` 脚本头注释。

插入位置（`3.2` 已裁）：readme「建制」那一章，正文之后。
图就是那句话的注脚——先用目录把权威分开（横轴），再用一刀把范围锁死（流转带），落到磁盘上（方块）。
不放在标题下当门面：门面已经有图标，两张图抢重音。
