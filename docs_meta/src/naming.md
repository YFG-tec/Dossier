# 名字与形态

不铺进宿主工作区。原则见仓库根 `readme.md`。操作步骤见该页 Quick Start。

**Dossier** / 绘卷，仓库 `dossier`。项目中文名是「绘卷」，英文名是 `Dossier`，名词是案卷。都是「卷」：案卷是背上贴着签的一捆（不翻开就知道是哪一件），绘卷是展开给你看的一幅（画的就是那一叠）。动作是现成的两个词——`git submodule add` 把母本挂进宿主，`init` 在宿主上铺骨架。

**中文名是绘卷。** 这套流程的动词——立案、举证、对账、结案、归档——本来就是现成的中文，不靠专名也立得住；单字要跟「手上这一件」抢词，两个字的候选也没一个好看。这一次另起了一个中文名：绘卷名的是「展开给你看」这一层，不是那些动词。

## 立意

名字要能一句话说清这套东西在干什么。案卷这一族的画面是：

> 一叠卷宗，一次抽一份出来办。背上贴着签，不翻开就知道是哪一件。
> 办完盖章，盖了才算数；章不是自己盖给自己的。抽走一份，叠还在。

五句话，对应五条规矩：

| 画面 | 规矩 | 细则 |
|---|---|---|
| 一叠里只抽一份 | **一次一件**：一刀，不并刀，不发明新阶段 | `workflow.md` |
| 背上贴着签 | **卡片在外面**：状态落磁盘，实现席不翻聊天记录 | `workflow.md` |
| 盖章才算数 | **举证**：「通过」只用于预先声明的量化判据 | `verify.md` |
| 章不自己盖给自己 | **分权**：写卡的手不改核，改核的手不改测试口径 | `roles.md` |
| 抽走一份，叠还在 | **母体**：母本只有一份，桌一张张从它出来 | 本文 |

一句话收住：**这套东西的核心不是转化，是取信。**

不是把原料变成产品，是让一个结论**可以被相信**——判据先声明、证据能复现、盖章的手不是干活的手。
所以名字说的不是「怎么把事做完」，是「凭什么说它做成了」。

欧美读者第一眼会把它读成情报档案。**这个读法本质是对的**：就是档案，对象是「做成了」这个结论，不是人。
英文首页必须把对象说开（*a case file for the work, not the worker*），凉意才是取信，不是对人立案。
整版英文另开分支做，不在中文稿上对着译。

## 怎么念，怎么说

`Dossier` 读作 **DOSS-ee-ay**（英 /ˈdɒs.i.eɪ/，美 /ˈdɑː.si.eɪ/）。

词源正好用得上：法语 `dos` = **背**。卷宗是**背上贴着签**的一捆纸——签在外面，不翻开就知道里面是哪一件。
这就是 `docs/SESSION.md` 干的事：卡片贴在外面，实现席不必翻聊天记录去猜本刀是什么。
绘卷的来历是卷宗「展开给你看」——背上的签打开，卷宗展开，就是一幅绘卷。

这套流程能落到磁盘上的动词，全在案卷这一族。绘卷是展开来看的画面，不另起一族动词：

```text
立案   write-cmd / spec-guard 写卡片          →  docs/SESSION.md
举证   验收命令真跑一遍，stdout 落盘          →  .tmp/ 或报告附件
对账   逐条对「交什么」：做到 / 没做到 / 打回  →  workflow.md 领班收口
结案   人看完红绿，勾 TODO                    →  只有人能做
归档   阶段报告入库                           →  docs/reports/
```

三个词各管一层，不要混用：

> **母本只有一份，桌一张张从它出来。**

| 词 | 指什么 | 例 |
|---|---|---|
| **Dossier** | 本仓库。这套规矩本身 | 「把 Dossier 挂成子模块，`init` 铺出 slow-mhd 的骨架。」 |
| **桌** | 课题仓库（新桌 / 旧桌 / 科研桌 / 数值桌） | 「旧桌没有义务回改。」 |
| **刀** | 桌上的一个工作单元 | 「这一刀还没收口。」 |
| **源码 / 产物** | `docs_meta/src/` 是源码；harness（`CLAUDE.md`、`AGENTS.md`、`.claude/`）是编出来、真能生效的那一份 | 「这条禁令在源码里，还没编进产物。」 |

**「源码 / 产物」那一行不是打比方，是这个目录已经在干的事。** `docs_meta/src/` 本来就住实现层
（`directory.md` 那张十层表的第 4 层）。`docs_meta/` 不铺进宿主工作区，所以**宿主那棵树上只有产物**——
这就是「发布端 `docs_meta/` 只是参考」的来历。两个目标：给桌的那份是交叉编译，给母本自己的是自举。

**但没有编译器，只有大模型转译**，所以产物相对源码有损也有增（措辞、顺序、Claude 特有字段），
重编一次不会得到同一份文件。**因此不许拿「两边一不一致」当判据**，方向才是判据：
只准源码 → 产物；产物被手改而源码不动，就是改二进制不改源码。
出了问题直接改 `CLAUDE.md` 永远是最快那条路——**这一层的规矩防的就是它。**

## 它是元项目，不是第三份求解器

课题仓库是**数据**：方程、离散、算例、报告里的数。
Dossier 是**元数据**：目录权威、一刀怎么切、谁许写哪一层、什么叫「通过」。

Dossier 里**没有求解器**。文件分两堆：留在子模块里的，和 `init` 铺到宿主上的。

| 堆 | 是什么 | 举例 |
|---|---|---|
| **留在子模块里** | 原则与规划。不铺进宿主工作区 | `readme.md`；`docs_meta/` |
| **`init` 铺到宿主上** | 给桌的骨架 + harness 规矩 | `docs/`；`CLAUDE.md`、`AGENTS.md`、`.claude/`、`.cursor/` |

`docs/` 是运行时的**数据布局**：卡片空壳和目录本身，不是「代码」——
代码是 `docs_meta/src/`，编出来的产物是 harness（见上面术语表那一行）。
桌长 `src/` / `tests/` / `.venv/`，母本里没有。
`docs_meta/` 是 Dossier 自己怎么写 harness、图标放哪；不铺进宿主工作区。

铺过去的那一堆正好对上设计思维：骨架是智能体的**记忆**，harness 规矩是**约束**。

对桌而言，`.claude/` `.cursor/` 是工具配置，不是项目内容层。
在这里反过来：它们是产品本身，改它们等于改规范。规划先写在 `docs_meta/`，落成文件再进铺过去的那一堆。

铺出来的是**管理骨架**，不是 fork 某份物理代码。
旧桌没有义务回改对齐；**新桌出自母本**。

加厚包（agent 文件、`one-slice`、`cursor-desk`）可以跟着走，也可以课题核变脏后再加——职责一开始就要分开。

本仓库最后长成：一份能 clone 的母本，外加一页 Quick Start。不是只给人看的手册，也不是又一个数值码。

## 图标

`docs_meta/src/figures/dossier-icon.svg`（浅底）与 `docs_meta/src/figures/dossier-icon-dark.svg`（squircle 深底），同一个字形，两个容器。
图标是 Dossier 的品牌，不进 `docs/`，不铺进宿主工作区。
图上画的仍是卷宗，绘卷是这幅画的名字。

三个形状，一个也不多：

| 画的 | 说的 |
|---|---|
| 一册卷宗 | 一次一件。本刀就这一份 |
| 背上一道竖线（签） | `dos` = 背。卡片贴在外面，不翻开就知道是哪一件 |
| 一枚朱爪印，向外转 7° | 盖了爪印才算数。转过来是「盖」，正着贴是「放」 |

全图只有一处颜色，就是那枚爪印——整套流程里只有一件事需要重音。
爪印是**印，不是插画**：实心、无描边、无表情、无胡须，和卷宗同一套笔法。
盖印的手不是干活的手——这枚章由谁盖，图上不解释。

另外三件都在直角系里，活着的形只有这一枚——所以轮廓上留折角，等于把这口气交回去一半。
在大模型跟前，人约等于一只小动物；但章还是人盖的。

色板：墨 `#1D1D1F`，朱 `#D9342B`。画布 256。
外框线宽 14，背签 `14/φ`（≈8.652），圆角 `14φ`（≈22.652）——细:粗 = 1:φ。
深底容器里外框加到 16（抵 `scale(0.78)`），背签仍按 1:φ（≈9.889）。

爪在本地 `0..100` 方框里**正着**画，摆进卷宗时才 `rotate(7)`（背离书脊）。
倾斜是最外层一个 transform，不是画进路径里的——改形不必重画斜的。
落点：框心 `(152,160)`，`scale(0.675)`。

这个 `scale` 是按**内白区四边留白**定的，不是随手挑的。内白区 = 主体框描边内沿加背签右沿，`x 108.3..185`、`y 55..201`（背签按 `14/φ` 收细之后，左沿比原先 111 多开了约 2.7）：

| scale | 左 | 右 | 上 | 下 |
|---|---|---|---|---|
| 0.710 | 13.9 | **4.7** ← 憋着 | 77.8 | 14.1 |
| **0.675** | 15.3 | **6.1** | 79.2 | 15.5 |
| 0.660 | 15.8 | 6.7 | 79.7 | 16.0 |

右边是唯一憋着的一侧。再缩到 0.66 只多买 0.6，小尺寸那头三档爪宽相差不到半个像素——但爪印是全图唯一的重音，缩过头就往右下角掉。`.tmp/icon/margin.py` 量的。

**左右差恒为 9.2，缩放治不了**：`scale` 绕 `(152,160)` 缩，而内白区的横向中点是 `148`。要摆正得挪落点，不是改倍率。眼下先不挪。

四趾照标准爪图测得；掌垫三叶是扫出来的（见下一节）：

| 件 | 坐标 | 形 |
|---|---|---|
| 内趾 ×2 | `cx 38 / 62, cy 27, rx 9.5, ry 13` | 细长胶囊，近乎竖直（±6°） |
| 外趾 ×2 | `cx 21 / 79, cy 45, rx 10, ry 11.5` | 明显外倾（±22°），位置更低 |
| 掌垫源形顶叶 | `cx 50, cy 56.5, rx 17.5, ry 13.5` | 扁宽，上凸 |
| 掌垫源形底叶 ×2 | `cx 42 / 58, cy 71, rx 16, ry 17` | 略立，下凸 |

四个趾垫是四个 `<ellipse>`，直接进 SVG。
**掌垫不是。** 上表那三个椭圆是它的**源形**，不出现在 SVG 里；SVG 里是一条低通之后的 `<path>`（下一节说为什么）。

源形是三个椭圆求并：一个上凸、两个下凸，露出三段外凸弧。
用椭圆不用圆，因为椭圆顶点的曲率半径是 `rx²/ry`，可以和轮廓大小分开调：

| 叶 | 形 | 曲率半径 | 露出的弧 |
|---|---|---|---|
| 顶 | 扁宽 `17.5×13.5` | **22.7** | 短 |
| 底 ×2 | 略立 `16×17` | **15.1** | 长（各自从侧面兜上来） |

顶大底小——这正是「朝上的半径大但弧长小，朝下的两个半径小弧长大」。**顶/底比不许低于 1.5**，低了形制就塌成一个圆头。
圆做不到：一个圆只有一个半径，要顶弧短就得半径小，要底叶兜得开就得半径大，两头对撞。

同色椭圆叠在一个 `<g fill>` 里自动求并，**左右两道腰和底心那道浅凹是接缝，不是画出来的**——不必算路径布尔。

### 这些数是量出来的，不是描出来的

定形有四条判据，互相拉扯，手调调不出来：

| 判据 | 量 | 现值 |
|---|---|---|
| 空隙要匀 | 掌垫到内 / 外趾的最小白缝 | `3.8 / 4.8` |
| 顶大底小 | 顶瓣曲率半径 ÷ 底瓣曲率半径 | `2.69` |
| 底凹看得见 | 底心比最低点高多少 | `1.2` |
| 弧线要顺 | **全轮廓最小曲率半径**（有折角就趋近 0） | `11.7` |

**节奏的基准是趾与趾自己：外趾↔内趾 `3.8`，内趾↔内趾 `4.9`。** 掌垫到趾的空隙对齐这两个数，整枚才读得成一只爪，不是一坨红。

前三条方向相反，这是它非扫不可的原因：

- 顶叶收窄 → 肩膀离外趾远了，但穹顶发尖、顶弧曲率掉
- 顶叶上提 → 补上内趾底下那块空，可肩膀又抬进外趾的高度带
- 底叶挪近 → 底凹变浅，但掌垫变窄，空隙全变
- 底叶加宽 → 补回宽度，底弧曲率涨上来，顶大底小就塌

`.tmp/icon/sweep.py` 把顶叶 `(rx, ry, cy)` 和底叶 `(半间距, rx, ry)` 一起扫（约 42 万种），
先按空隙和曲率比筛掉不合格的再排序。算得快是因为拆开了：
顶叶到趾的距离只跟顶叶有关，底叶的只跟底叶有关，各算一遍再取 `min` 组合。

### 第四条判据得靠低通，挪位置解决不了

三个椭圆求并，接缝处两条弧是**成角相交**的。挪位置只能让折角变浅，消不掉：
调到最好也还剩 63°，全轮廓最小曲率半径是 0——那三处就是尖。

抹平的办法是**傅里叶低通**：把求并后的轮廓写成极径 `r(θ)`，展成级数，砍掉高次项。
折角是高频，三瓣的大形是低频；砍高频＝折角抹圆，大形一点不动。
（这是形状分析里的傅里叶描述子，标准手法。`curve.py` 里 `union_r` + `fourier_trunc`。）

求并后仍是关于内点 `(50,68)` 的星形域——三个椭圆都是凸的、都含这点——所以
沿射线取各椭圆出射距离的最大值就是轮廓，`r(θ)` 单值，没有歧义。

留几次谐波，扫出来是个平台：

| 留 N 次 | 最小曲率半径 | 底凹 | 顶/底曲率 |
|---|---|---|---|
| ≤5 | 13.3 | **0.2** ← 凹被抹没了，掌垫塌成一个蛋 |  0.45 |
| **6 – 8** | **11.6** | **1.2** | **2.7** |
| ≥9 | 6.5 | 1.7 | 1.5 ← 折角开始回来 |

**取 N = 6。** 顺带一个意外收获：低通之后顶/底曲率比从 1.51 涨到 2.69，「顶大底小」反而更清楚了。

SVG 里存的是这条曲线降成的 **24 段三次贝塞尔**（Catmull-Rom 转 Bézier），
最大偏差 0.107 本地单位 ≈ 512 px 图上 0.15 px，看不出来。段数别再减：20 段就到 0.19，16 段 0.35。

**改形的口子只有源形那三个椭圆。** 改完重跑低通重出路径，不要直接编辑 `<path>` 里的控制点。
手调过八版，每次修好一处坏一处。

踩过的坑，别再走一遍：

| 走错 | 结果 |
|---|---|
| 趾垫画成胖椭圆 | 变成通用爪印，不像猫 |
| 掌垫用三个圆 | 顶弧和底叶争同一个半径，做不出「顶大底小」 |
| 掌垫画成三瓣深凹 | 底下像挂了三滴水 |
| 底叶离太开 | 底心那道缝掐成尖 V（夹角 82°、凹深 5.1），像开了个口 |
| 顶叶铺太宽 | 肩膀顶到外趾（白缝只剩 2.4，比趾间还窄），糊成一片 |
| 掌垫写成一条手画 `path` | 每次调形都要重解控制点；源形改数，路径重出 |
| 各块贴太紧、留白不足 | 小尺寸糊成一团红，认不出是爪 |

借现成曲线试过三条，都不对，记下来免得再试：

| 试过 | 为什么不行 |
|---|---|
| 心形曲线 `x=16sin³t, …` | 方向反了：♥ 是上两瓣下一尖，掌垫要上一瓣下两瓣。倒过来下两瓣对了，顶上却是尖不是穹 |
| 三叶玫瑰线 `r=1−k·sin3θ` | 瓣间距锁死 120°，两个下瓣落在 210°/330°——朝斜外不朝下，两侧支棱，宽 66（该是 48） |
| 在底凹里垫一枚相切填角圆 | 底凹本来就只有 2.3 深，塞得进的相切圆半径不到 1，垫完凹也没了，白垫 |

教训是同一条：**成熟曲线得先对得上拓扑**（上一瓣下两瓣、瓣的角位可调），对不上就别硬套。
低通之所以成，是因为它不换形——只把已经调好的那个形去掉高频。

趾垫比参考图肥一圈是有意的：参考那个细长比例在 32 px 会瘦没。

逐档看过：48 px 三段弧还分得开，32 px 糊成一团但仍是爪形，16 px 退化成一枚红点——和原来那枚实心方印退化后同形，重音不丢。
每改一次形都要重看这一排，别只看 256 px。

`.svg` 是源，`.png` 是导出件（512×512 白底）。改形只改 SVG，PNG 重导。

重导靠 `docs_meta/src/figures/render_icon.py`。上面那两次扫描靠 `.tmp/icon/` 里的探针：

| 探针 | 干什么 |
|---|---|
| `render_icon.py` | 无头 Edge 截图出 PNG 与逐档对照条。不依赖 cairosvg / Inkscape / ImageMagick |
| `sweep.py` | 扫源形那三个椭圆的六个参数，前三条判据 |
| `curve.py` | 求并取极径、低通、量曲率、降贝塞尔。上一节那条 `<path>` 从这里出 |
| `fit.py` | 拿玫瑰线去凑趾间节奏，凑不上。留着当否证记录 |
| `variants.py` | 比稿：四列并排，单看 / 整爪 / 摆进卷宗 / 小尺寸 |

**两席没有画进去**，是有意的：两席是权限结构不是画面，硬画出来就是两个方块并排，32 px 下是两坨。
它写在副标题和 `directory.md` 的写权限表里，不写在图上。
