# 一刀

不铺进宿主工作区。原则见仓库根 `readme.md`。目录落点见 `directory.md`。

目录给了落点，一刀给了范围。两件缺一，代理就会在 `src/` 里自由发挥。

## 开桌：先议事，后立案（→ harness）

一刀之前有一段不是一刀的东西：**和规划席把大框架聊透**。
`roles.md` 说规划席的典型环境是「读全树、**议事**、改文档快」——议事就是这一段，但它一直没落成一个阶段。
缺了它，第三刀才发现合同自相矛盾，前两刀白做：那是「退卡」表里「合同没写」那一行的批发版。

这一段的失败模式有两个，方向相反：

- 框架没理顺就开刀 → 合同边做边换，每一刀都在改上一刀的前提。
- 为了「理顺」把细节全定死 → 定的是猜的。**写下来的猜测比「未定」更糟**，因为下一刀会拿它当判据引。

躲开两边靠一条不对称的收口判据：

> **框架要聊全，判据只要够第一刀。**
> 全的是**章节**——这件事分成哪几块、每块要回答什么问题，一个都不能漏。
> 够的是**答案**——只有第一刀要碰的那一**条**得有授权，其余可以还只是问题。

「聊透」聊的是前者。**知道有哪些问题，和知道那些问题的答案，是两件事**；开桌只欠后者。

所以合同层要分开两件事，别塞进同一个标记：

| | 是什么 | 靠什么 |
|---|---|---|
| **权威**——能不能当判据引 | **二元**：已定 / 不已定 | 标记，机械可查 |
| **进度**——想到哪一步 | **三元**：验证过 / 有答案没验证 / 没答案 | 正文叙述，不承重 |

### 权威：正向标定

**机械保险在这里：默认不可引。** 合同层的一条只有带上 `【定】` 才能被卡片当判据引用；
其余一律是**参考**——可查阅、可作规划席提建议的依据，**不可引**。

```text
【定】一次只做未勾的一行。          ← 可引
      退卡的一刀怎么记进已办，没定。 ← 参考，不可引
```

为什么是正向标确定，不是反过来标不确定：

| | 标不确定 | 标确定 |
|---|---|---|
| 默认 | 可引，除非标了 | **不可引**，除非标了 |
| 标记丢了 | 沉默升格——**失效朝危险倒** | 降成参考——**失效朝安全倒** |
| 谁吃亏 | 下游：拿参考当合同做了一刀 | 上游：该标没标，东西没人引，很快发现 |

**改的不是宽严，是失效方向。** 标记一定会丢——上下文压缩会丢、摘录会丢、
复制粘贴会丢、手滑改一行也会丢。设计时就假定它会丢，然后让它往安全那边倒。

三条落地约定，缺一条这机制就漏：

- **行内标记，不另立清单文件。** 一份「已定条目清单」就是第二真相，
  和正文迟早不一致，且不一致时没人知道该信哪个（`directory.md`）。
  要索引就 `grep -n` 现算，**不存盘**。
- **裸的是授权，反引号里和代码块里的是提及。** 描述这个标记的文字不发授权。
  这不是文风：整套机制押在 `grep` 上，分不出「用」和「提」，检查就会自伤。
- **落笔在人。** 加一个标记就是发一次授权，和勾 TODO 同性质。
  人可以口头下令、由代理代抄，但**决定权不下放**。

**代价照写：丢了「局部自明」。** 一个问句看一眼就知道不能引，零纪律成本；
正向标定要回源头查一次。补偿是这个查询**能机器做**——精确子串比对，不是语义判断——
而且只卡在写卡那一个口，那是所有合同引用的必经之路。

#### 标记只落在「业务结论」上

合同层不是一种东西，是两种。**标记只管后一种：**

| | 写什么 | 标记 |
|---|---|---|
| **管理类** | 每个项目都要微调的那部分。`design/` 用宽松语言写**思路**，实现落 `.claude/` 角色文件，记录落 `TODO.md` | **不用** |
| **业务类** | 这套范式以后要落的各种场景，不限物理。定下来的一条一条写 | **照用** |

管理类不用标记，不是开口子：**宽松语言里本来就没有「一条一条定下来」的东西可引**，
标记无处落。它的许可面是卡，不是合同层的某一句。

**同层的讨论 / 分析稿不必另立规矩。** 评估页、开放问题页、外部对照——
正向标定下**没标记就是参考，它天然合规**。要给它们单写一条禁令，等于把默认值抄了一遍。

一张桌只有管理类时，**这张桌可以整个停用标记**，理由跟着写。
母本就是这么办的，见 `docs_meta/docs/design/paradigm.md` 第 5 节「母本停用标记」。

### 进度：三态照写，只是不再承重

| 态 | 长什么样 |
|---|---|
| **已定** | 物理与离散的事实 |
| **草案** | 有答案、没验证；开头标「草案 / 未实现」 |
| **占位** | **只有问题，没有答案** |

这三态给规划席看：这件事想到哪一步、下一刀该啃哪一块。**它不决定能不能引**——
没标记的「已定」照样引不动，标了的照样能引。节的态从此只是摘要，不承重；
**一节里几条已定、几条还是问题，是常态，不是脏。**

**占位建议写成问句**，但这条现在只是**写作建议**。
留着它的理由换了一个：**问句逼你说清到底不知道什么。**
「边界条件用哪一种？」暴露了未知；「边界条件暂定周期」把没想明白的事
伪装成想明白了一半——骗的是写的人自己。既然引不动，它就不再危险，只是可惜。

**这就是 `docs/design/` 作为一个目录存在的主要理由。** 不是「把物理写下来存档」——存档写一页就够。
它是**未定事项的收容层**：有了它，「还没想明白」才有地方合法地待着，而且待在一个不会被当判据引用的位置。

没有它，未定的东西只能往在办层挤。Xenia 没有 `docs/design/`，
346 行的 `TODO.md` 里就长出了带日期的裁决（「用户拍板（锁）：①…⑤」「原文锁死」「会话点头不算。」）——
因为 `SESSION.md` 每刀覆盖，那些话没有别的地方可去。
**在办层留不住话，合同层才留得住。** 把长期的东西放进留不住的那一层，就只能靠一份不断变胖的 TODO 去抗覆盖。

开桌交三样，都很短：

1. `docs/design/` **章节名先立**，内容三态。占位一句话，说清将来要回答什么。
2. `docs/TODO.md` 第一版。**三五行就够。**
3. `CLAUDE.md` 约定：禁令、先读顺序。

`docs/design/` 不必填完——**第一刀要碰的那一条若是业务类，必须标了；其余可以是占位。**
**管理类不在此列**：它本来就没有标记（见「标记只落在业务结论上」），
而一张新桌的第一刀多半正是管理类（落 harness），拿这一条挡它就是开桌当场卡死。
**这是补口径，不是放宽**——业务类那一半一个字不松。
`directory.md` 的先读顺序本来就写着「相关 `design` **一节**」，不是全部。

## TODO 只能长，不能变胖（→ harness）

一开始短是对的。它会长，合法的长法有两种，非法的只有一种：

- **合法一：占位裂成行。** 一个「未分解」的占位条目，随着开发变清楚，裂成两三行可执行的。
- **合法二：勾完的行沉进「已办」。** 勾完**不删**，原措辞不动，加一个 `cmd/PROMPT_xx.md` 指针和结案日期，搬到文件末尾。
- **非法：一行变胖。** 行里长出公式、完成标准、拍板记录——内容爬到了错的层，TODO 就成了第二份路线图（`directory.md`）。

判据一句话：**一行永远只是「点名 `design` 的某一节」加一个勾选框**（已办行多一个指针和一个日期，不多别的）。
细节往 `design` 走，不往 TODO 里塞。
未分解的占位行写明「占位，未分解」——它不是一刀，闸一不放它过。

**已办区是把名字欠的那一格补上，不是新发明。** `在办` 这个层名取自公文三态——
**待办 / 在办 / 已办**——可「已办」在这一层里一直没有落点：**旧规矩勾完就删**，案子结了反而什么都不剩。
`cmd/` 留得住的是**具体实施细则**（当初让干什么），留不住的是**人立案时写的那句话**。
两件事不是一件：**TODO 那行是概要，`cmd/` 是细则**——粒度不同，谁也算不出谁。

**已办区和 `cmd/` 互为对账的两边。** 每一份 `cmd/PROMPT_xx.md` 在 TODO 页上恰好出现一次，
每一条已办恰好点名一份 `cmd/`；对不上就是有一刀没落盘，机器一跑就知道。
**一份 `cmd/` 在那一页只有一个落点，就是它自己那一行**；行外不另起一段讲它，
否则对账就多出一个指针。**别把它写成第二份路线图**：一刀一行、一个指针，
不是「做过什么」的叙述——叙述在 `cmd/`，事实在 `design/`。
为什么这一份存得、而「已定条目清单」存不得，判据见合同层
（母本的落点是 `paradigm.md` §5「能从别处现算出来的，不存」那一条，及其下面「第 n 份记录一律写成链接」几段）。

**老人老办法，新人新办法。** 旧规矩勾完删行，之前那些刀的原措辞捞不回来；
补救格式是**占位 + 简要概括 + 注明「原措辞无法寻回」**，这样的行只占位置、不参与对账。
新的一刀一律严格按格式来，不许再用补救式。

**未定怎么变已定：收口时回填。** 一刀做完，若它顺手回答了某个占位问句，领班在对账里点名：
「本刀回答了 `design/X` 的占位问题 Q，建议升格」。升格和勾选一起，由人在结案定。

**升格就是在那一行前面加一个标记。** 不是一句表态，是一个**能 diff 出来的动作**——
和勾 TODO 完全同性质：人决定，落笔可以代抄，决定权不下放。

所以结案不只做减法（勾 / 不勾），也做加法（**发一次授权**）。
这是「未定的东西逐渐清晰」唯一的落盘出口——不在收口里点名，它就永远只是参考。

## 工作单元 = 一刀（→ harness）

- 待办只有 `docs/TODO.md`。
- **一次只做未勾的一行。** 不发明新阶段，不顺手并刀。
- 代理不准自己勾。勾选是人看完红绿之后的管理动作。
- 没有本刀卡片（`docs/SESSION.md`），不准改 `src/`。

## 状态在磁盘，不在聊天（→ harness）

```text
docs/TODO.md               勾选清单；一次一行；勾完移进页末「已办」，只增不删
                           已办一行 = 原措辞 + 一个 cmd 指针 + 结案日期
docs/cmd/PROMPT_*.md       可贴的一刀指令；**本刀的许可面就是它**，结案之后不再动
                           结案后只增不删；退卡的卡留档盖章——这一层唯一的**指令全文**
docs/SESSION.md            指向本刀那份 cmd 的链接 + 运行态；本页覆盖，被指的那份结案后只增不删
                           不复述卡片字段；实现读链接指的那份，不读这里
```

下一刀覆盖 `SESSION.md`，上一刀聊天可以扔——因为该留的已经在 `docs/cmd/` 里，结案后只增不删。
**别只写一半。** ② 产出的是**一份卡片 + 一个链接**：`PROMPT_xx.md` 新增一份；
`SESSION.md` 整篇覆盖，只装指向它的链接和本刀的运行态。**不是两份卡片。**

**卡每改一稿，上半页跟一稿。** ② 写卡阶段就跟，不是闸一之后才覆盖，也不是审卡指出了再补。
理由：审卡看的是卡和上半页两件东西。上半页停在上一刀，另一席读到的运行态就是假的，
**审卡当场变成审一份对不上的东西**。

**实现读的是链接指的那份，不是 `SESSION.md`**——理由不是规矩好看，是那份改不动：
**许可面定在结案，结案之前退回闸一才改得动，改完要重提**（收口记录只往后追加，结案之后仍是只增不删），
没人能中途悄悄改它，而 `SESSION.md` 整刀都在变。

### 横线以下的评注

`SESSION.md` 分两截，中间一条横线：

- **横线以上**：写卡那只手起草的链接 + 运行态，随施工改。
- **横线以下**：**只追加**——不改上面，不改卡。**形同审稿**：上面是稿，下面是审稿意见。

| | |
|---|---|
| **谁写** | 规划席 |
| **写什么** | 闸一之前的**审卡**；**刀跑起来之后**出了新情况的评注，辅助续推 |
| **不能干什么** | **评注不是第二道闸一，也不能改许可面。** 许可面仍然是那张卡，结案之后不动 |

**评注只解释卡上已有的条。** 要加一条卡上没有的，那就不是评注了。三条路，各走各的：

| 要干什么 | 走哪条 |
|---|---|
| 解释卡上已有的、提意见、逼出回应 | 横线以下的**评注**，就是本节 |
| 加一条卡上没有的，而这一刀走得完 | 走完这一刀，收口对账里点名，**补卡**另开一张 |
| 加一条卡上没有的，而这一刀非它不可 | **退卡** |

后两条见下面「退卡」和「补卡」两节。**这一节只管「刀内程序怎么留痕」，不管许可怎么加。**
写糊了，下一个人就会拿评注当补卡口用。

评注和红印一样是运行态，**随本页整篇覆盖**。

**「不许改」和「不许弃」是两根轴，说的不是一件事；时点同在结案：**

| | 时点 | 意思 |
|---|---|---|
| **冻结** | 结案 | 不许改。改了就是绕过结案，许可面糊掉 |
| **永久** | 结案 | 不许弃。这时 `src/` 才有实质落笔，卡才够格进历史 |

**退卡是「整张弃」，不是「改」**，所以它不碰冻结那一条——**结案之前，卡片可以退回闸一重改重提，但退卡是许可面撤掉**。卡片本身留档盖章，见「退卡」那一节。
只写 SESSION 的代价是排障时翻不到「当初到底让干什么」——那一刀的卡片早没了，TODO 那行也早删了。
「继续推进」只够沿着当前卡片走下一步，不够当扩大范围。
聊天里点头不算许可；许可面就是卡片本身。

## 卡片最低字段

| 字段 | 干什么 |
|---|---|
| 状态 | 等批准 / 施工中 / 已收口 |
| 本刀是 TODO 哪一行 | 原文锁死，不发明 |
| 现状 | 实现会踩的坑，写在开干之前 |
| **交什么** | 3–6 条可验收；写到哪些路径 |
| **不交什么** | 本刀明确不做 |
| 禁令 | 本刀不可破的短列表 |
| 验收命令 | 可复制；工作目录是项目根 |
| 独立审查 | 是 / 免（改了 `src/` 就是；写「免」要说明这一刀为什么不需要） |
| 闸一请示 | 要人点的每一条，带途径附注 |

写卡和改核之间有一个**停**。没说「按卡片做」不开始实现。

### 闸一红印：过闸要留一颗印

**闸一过了，得有个东西能 `grep` 得到**——「状态在磁盘，不在聊天」对这道闸的直接推论。
口头点头本来就不算许可；连「点过头」这件事本身也不能只活在聊天里。

| | |
|---|---|
| **形状** | 固定词 `闸一红印` + 日期 + **人说的那句原话，逐字抄，不概括** |
| **落在哪** | `docs/SESSION.md` **横线以上**。**不改卡**——卡在结案冻结，红印是运行态 |
| **什么时候** | **人说「按卡片做」的那一刻。就这一个时点。** |
| **谁落笔** | 人可以口头下令、由代理代抄，**决定权不下放**；代抄的纪律是逐字 |

**印文里不写卡的路径**，用「本刀」指代：那一页只许有一个指向 `docs/cmd/` 的指针，
上面「许可面」那一格已经占掉了。

**时点只有一个：人说「按卡片做」那一刻。不许写成「审卡完成之后」——审卡完了人可以不放。**
审卡是另一席的一页，闸一是人的一爪，两件事不是同一个时点。
**没有红印，实现不许落第一笔。**

**红印是运行态，随 `SESSION.md` 整篇覆盖，活不过这一刀。** 它是刀内的活锁，不是档案：
要留住的东西在 `docs/cmd/` 那一份里，那份结案之后不改、只增不删。

**这条保证的界限照写，别当它够：机器查得了印在不在、格式对不对，
查不了那句话是不是真有人说过。** 落印的手往往就是等着开工的那只手，形式上就是自证——
**唯一的防线是逐字**。

**全程图里那一格只写一句摘要，细则在这一节，不重复。**

### 序列授权：印可以代落

**印的落笔权默认在人，但人可以一次授权一串。** 人对一串序列说定授权（原话逐字存序列单）之后，
授权原话就是印文——代印的手不发明印文，只搬运。印文照样逐字、照样落 `SESSION.md` 横线以上、
照样过 `check-gate` 的版次形状。

**代印、代点行、结案代笔的边界是一根轴，不拆开卖**：序列单在案且该行判据可机读 → 按式代笔；
发授权、松判据、改序列、动根基条款、退卡、胖行 → 一律停下呈人（断点）。
**阶段性结果或关键性决断才叫人**（人 2026-10-02 裁，原话逐字：「除非有阶段性结果或关键性决断，日常的开发流程人不再参与(自动发印)」）——
一刀结案或一串序列走完是阶段性结果，呈报；断点是关键性决断，停刀呈报。

**代理席落印标蓝色**（标注位 `--代理席落印`），与人印效力一致，仅记操作者；细则见 `roles.md` 代理席一格。

### 闸一之后动过的

**结案之前许退回闸一、重改、重提。** 每改一次，留一条痕：

| 痕 | 落在哪 | 怎么留 |
|---|---|---|
| 一 | 本刀那张卡 | 一节，标题行逐字是 `## 闸一之后动过的`，每改一次一条，只增不删 |
| 二 | `SESSION.md` 横线以上 | 跟着那一稿，卡每改一稿上半页跟一稿（见「状态在磁盘」那一节） |
| 三 | 红印 | 重落一次，且那一行数得出版次 |

**痕一那个标题的形状是判据的一部分。** 它直接决定了检查脚本怎么数改动；细则见把关层的检查。

**三处缺一处当场红，由把关层的检查查。共现能机检，那句话是不是真有人说过，机器查不了**——纪律是逐字对齐，防线不在检查里。

## 人每天只做四件事（→ harness）

1. 看 `docs/SESSION.md`
2. 看验收红绿
3. 决定勾不勾 `docs/TODO.md`
4. 拒超售

人是产品负责人，不是结对程序员。

**四件事是人每天的最小集，不是人爪的全集。** 立案是第五爪：占位行裂成可执行的行，或点的事盘上没有行、要写一行。
谁落笔、走不走闸、原话留哪，见全程图 ⓪ 格。它不计进「四件事」，因为它不是每天都发生；发生时归人。

四件事之外，序列授权之后还有一只住在序列单后面的手：**代理席**（见 `roles.md`）。
点行、代印、结案按式代笔，断点与阶段性结果呈报归它。这不改四件事——四件事是人每天的最小集；
序列跑起来的时候人可以一件都不做，看到呈报再回来。

## 跟人请示：两条途径（→ harness）

人的爪有限。请示递到人之前先过一道审：审的人是发请示那只手自己，判据是形状，不是语感。

**裸 yes/no 定义上就是没营养。** 最典型的是「是否允许执行某个脚本」这一类：
那是 harness 权限表或卡上预声明命令的事，不该拿去问人。
带充实内容的请示（最起码不是 YES/NO）不过审，直接送。

没营养的请示只有两条出口：

- **途径一**：说明为什么不能自动化，指到盘上那条让它归人的条款。
- **途径二**：改写成盘上已经允许的形状——卡上预声明的格、把关层的一本、权限表里的一条。改写完成，请示消失。

人爪的事（点行、结案、发授权、松判据）不算裸 yes/no：每条都带后果和依据，直接送，但注明属哪一爪。

**请示落盘，不在聊天里漂。** 卡上写进「要人点的请示」那一节，施工中的停报写进 `SESSION.md` 横线以上。
每一条带三种附注之一：〔爪：…〕、〔途径一：…〕、〔途径二：…〕。没附注的请示，验收打回（`roles.md`）。

## 收口纪律（领班收口 = 绿落盘 + 对账）

一刀里，**tester（以及需要时的审查）做完之后、请人勾 TODO 之前**，领班做收口。就这一段，两件事一起做（派了审查就是三件）：

1. **绿必须落盘。** 卡片里的验收命令真跑一遍，stdout / pytest 写进 `.tmp/`（或报告附件）。对人说话时指这份文件，禁止只在聊天里说「全绿」。
2. **对账。** 打开 `SESSION.md` 的「交什么」，逐条写：做到 / 没做到 / 打回 TODO。没交的不准写成「待下一阶段」了事，也不准自己勾选。本刀若顺手答了 `design/` 里某个占位问句，在这里点名，建议升格为已定——建议而已，落笔在人。
3. **代抄审查那一页。** 审查不写文件，它的结论只能是发言，落盘只能由领班代劳——**照抄、标出处，不摘要、不合并、不改措辞**。领班派了实现和测试、又要说「建议勾不勾」，是有利害的那只手；这一条防的就是它顺手把结论揉平。理由见 `roles.md`。

然后才告诉人：改了哪些路径、落盘日志在哪、对账表、请人决定勾不勾。审查那一页**和对账表并列呈**，不塞进对账表的某一条；领班的不同意见写自己那栏。

其余：

- 不 commit / 不 push，除非人本回合点名。
- 新文件只能落在 `directory.md` 那张图里；不写到项目外。
- 对用户用简体中文；代码和标识符用英文。
- **改 SESSION 上半页后必跑结构本。** 每次改 `SESSION.md` 横线以上之后，当场跑 `check-link.sh` 与 `check-gate.sh`，两本全绿才往下。红即停，不改完不收口。这一条不是选跑，是硬格——4.10 审查意见 1 上架、3.5 跟稿再踩、6.12 现形两回，三次同形。

## git 状态作判据

判据经常引用 git：「工作区相对基线多了什么」「HEAD 是第 1 步记录值」「index 空」。git 状态却不只由这一刀决定——规则先钉住，判据才许锚它，否则每刀现场重新发明归因。标本两个都在案：`4.10` 格 23 假红（权限系统中途写盘+被杀趟残留）；36 桌与本桌各撞过一回「落印后人再提一笔，卡上那句当场过期」。

- **基线在第 1 步钉死。** 开工台账记一次 `HEAD`（那个哈希），它是这一刀全程的基线锚；卡上「第 1 步记录值」指的就是它。
- **落印后人再 commit，基线不动。** 印锚的是卡，不是 commit；新的 commit 归外部账——不算本刀产物，也不豁免本刀的检查。
- **归因看两件：时间 + 路径。** 盘上一行算本刀的账，须同时满足「文件 mtime 不早于卡落盘」与「路径在许可面内」；否则是旧账/外部账，台账逐行记名，不判红。探针残留、被杀趟的残件同法。
- **三个时点各现算一次。** 盘面与 `HEAD` 在写卡（上半页记录）、施工第 1 步（钉基线）、收口（呈终态）各现算；任何一格不许抄上一个时点的数——中间隔着一段树可能被外部动过的时间。
- **判据锚内容哈希，不锚工作树形。** 要确认「哪一版没变」，用 blob 形（`git hash-object`、`git ls-files --eol`）——autocrlf、mtime、touch 都污染工作树、污染不了库。`6.11` 人裁的 A 案即这一格的默认写法。
- **本节不改谁按 commit 的授权**（见「四个词各管哪一段」与收口纪律）；本节钉的是状态侧：九处「谁按」写满之后，「算哪个版本」这一格补上。

## 四个词各管哪一段（→ harness）

下面那张全程图用这四个词，所以先把它们定死。**病根是「审查」的宾语没写在词里**：
同一个字既能指「看卡」又能指「看交出来的东西」，谁读都能往里填。
药是换成自带宾语的词。

| 词 | 什么时候 | 谁出 | 判什么 |
|---|---|---|---|
| **审卡** | 闸一之前 | 另一席出一页，落 `SESSION.md` 横线以下 | 卡正不正常 |
| **闸一** | 审卡之后 | 人 | 许不许做 |
| **验收** | 交付之后 | 代理出一页，落 `SESSION.md` 横线以下 | 跑验收命令；对照卡逐条核；动过的路径有没有超卡 |
| **结案** | 验收之后 | 人 | 认了就 commit、勾 `TODO`、移进已办 |

四句，一句一件事：

- **验收不含 commit 和勾。** 那两样在结案，是人的那一爪（`roles.md`，及合同层那条
  「结案、发授权、松判据，都是人的那一爪」）。
- **「审查」不是位置名**，是那只零写权限的手的名字（`roles.md` 那一栏），以及日常动词。
- **验收是位置名，不是手名。** 段里出几页由档位定：重档是⑤那一页加⑥的对账表，两页并列；
  轻档一只手兼办就是一页。**并列那一条不许被「出一页」压掉**，理由在 `roles.md`。
- **审卡和验收都落横线以下，两页不合并。** 一个判卡，一个判交出来的东西。

以及人在闸间**要求总结之后停刀**（**提前关闭**，见末尾「闸与闸之间」那一节）。
**后两个不是一回事**：退卡是实现席自己停，提前关闭是人叫停，收摊的手续也不同。

## 退卡：做不到 ≠ 做错了

**退卡有两个发起人，手续只有一套：**

| 谁发起 | 说的是 |
|---|---|
| `builder` | **做不到**——卡片自相矛盾、合同根本没写、只剩要偏离合同的折衷 |
| 人 | **不该做**——这一卡本身不成立，俗称**退稿** |

**退稿就是退卡，不另发明手续。** 差的只有发起人，收摊那三条一模一样。
人发起的那一路**不必等 ③**，闸一之后任何一刻都可以。
本节末句「退卡多半说明闸一放过了一张不该放的卡」讲的本来就是它——
那里说的是别人替人发现；这里补上另一头：**人自己发现放错了，那一爪叫退稿。**

红测、破界、核散是**做错了**——有东西可对，走完 ⑥⑦ 由人打回。
**做不到**是另一类：卡片自相矛盾、合同根本没写、或者只剩下要偏离合同的折衷。这时候继续往下走是空转——测试测什么、审查审什么。所以 builder 当场**停**，退卡，不走 ④⑤⑥。

**什么时候必须退卡**（任一条成立就不许再试）：

- 下一步要动的东西**超出卡片**：碰卡片没点名的路径、要改合同、要放宽验收命令。
- 试满三条路仍不成（和 `verify.md`「约 3 轮仍无定性」同一个止损）。

**退卡交什么**（写进 `.tmp/`——builder 不能写 `docs/`；由领班代抄呈人，和审查那一页同一个机制）：

1. 卡上**哪一条**做不到。引「交什么」的原文，不写「这刀太难」。
2. 试过哪几条路、各自为什么不行、证据在 `.tmp/` 哪个文件。
3. **卡在哪一层**——这一条决定往回退几步：

| 卡在 | 退到 | 谁改 |
|---|---|---|
| 卡片自相矛盾、验收命令不可能通过 | ② 写卡 | 规划席 |
| 合同没写，或两处互相矛盾 | 合同层 `docs/design/` | 人 + 规划席 |
| 合同清楚，但代价大到要折衷 | **人** | 只有人 |
| 合同和口径都清楚，纯粹不会写 | ② 缩小卡片重开 | 规划席 |

4. 要折衷就**摆选项**：每条写偏离合同的哪一句、代价是什么、有没有一条能失败的新判据。

**退卡之后收摊，三条，一条都不许省：**

1. **那张卡留档盖章。** 卡片到结案才够格永久记录，但退卡的卡从没被结案过，仍然留档。
   当初删卡防的是**指令流水拿一张死卡虚报做过几件事**。**现在那条理由由章来守，不必再靠删**。卡号仍是只增不重用的流水；卡还在，那个号从此不是空档。
2. **本刀动过的产品路径都要清账；`.tmp/` 的证据一个字不动。** 退卡按定义发生在动过核之后，
   卡一撤，那堆改动就没有许可面了（**许可面就是卡片本身**）——**产品被动过而没人批准，
   比一张孤儿卡片坏得多。**
   **产品路径是 `src/` 加 `tests/`，两层都要过一遍。** 划界的轴是**产品 / 证据**，不是 `src/` / `tests/`：
   凡是靠这张卡才拿到许可的落笔，卡一撤就都没了依据（`tests/` 跟着卡走，见 `directory.md`
   「打卡义务沿着这张表递减」）。
   **多半没得可清**：退卡发生在 ③，④ 还没跑，`tests/` 一个字没动。
   规矩仍不写成「只管 `src/`」——**那是拿流程的先后当保证，不是拿原则当保证。**
   哪天退卡从 ④ 发起（tester 发现判据根本写不成测试，正是上表第一行那种「做不到」），
   只清一半就漏了。

   **两层清法不同，因为主人不同：**

   - **`src/` 机械回滚，由领班执行**（`git` 回到开刀前，一条命令）。builder 已经当场停了，
     这层暂时没有主人。**也不让 builder 自己动手**——它停了还落笔，就是没有卡片还在写 `src/`。
   - **`tests/` 不做机械回滚，交回 `contract-tester` 自己判：这一条是删，还是改。**
     该删的是**只为那张撤掉的卡而立**的判据——卡没了，它守的承诺也没了。
     该留的是**指得回合同层**的那种：譬如试到一半撞出来的红测，暴露的是原有代码本来就有的毛病，
     和这张卡撤不撤无关。**那是知识，不是这一刀的残渣，机械回滚会把它一起抹掉。**
     **判断只有这两个方向，没有第三个：不许借退卡放宽任何一条判据。**
     松判据是人的那一爪（`roles.md`、`paradigm.md` §3 第 4 条），**退卡不是它的后门。**
     判据一句话：**留下来的每一条，必须指得出它守的是合同层的哪一句，
     而不是那张已撤卡片的「交什么」。**

   **清账撤的是许可面，不是知识**：试出来的东西留在 `.tmp/`，结论走下面第 3 条进下一张卡。
   证据必须活过清账，否则上面第 2 项指向的全是已经被抹掉的文件。
   下一刀的 ④ 照新卡重写测试，它要的输入是第 3 条那段死因，不是上一刀的测试文件本身。
3. **死因写进下一张卡的「现状」栏。** 退卡页住 `.tmp/`（零权威，会被清），
   那张卡又删了——**这是唯一耐久的存档路径**，不是可选的好习惯。

**builder 有提议权，没有采纳权。** 折衷就是偏离合同，而 `directory.md`「4 不能代替 2：代码悄悄偏离设计文档，等于换合同」。摆出来给人选是合法的；自己选了做下去，是第 6 类失败（散了先改数值旋钮）的一般形式。这和审查「有发言权、没有否决权」、测试「写红测、不修到绿」是同一条骨架：**发现问题的手不是拍板的手。**

退卡不算这一刀失败，多半说明**闸一放过了一张不该放的卡**。退卡那一页**必须**反过来喂给 ②：下次这类卡的「现状」栏该写什么。**这一条是硬要求，不是建议**——理由见上面收摊第 3 条：退卡页会被清，不喂过去就真的没了，下一个人会把同一条死路再走一遍。

两道闸就是人每天四件事的位置：闸一 = 看 `SESSION.md` + 拒超售，结案 = 看红绿 + 勾 `TODO.md`。

## 补卡：拿新的一刀去修已经结案的那一刀

和退卡是一族——**两个都是一整刀的进退，不是刀内的动作。**

三句定死，别的都从这三句推：

- 补卡的对象是**已经结案**的那一刀，不是在办的这一张。
- 补卡自己是**完整的一刀**：自己的 TODO 行、自己的卡号、自己的审卡、闸一、验收、结案。
- 闸一之后、结案之前合法改这张卡的办法是**整张退回闸一、重改、重提**；**不许往在办的卡上追加**。想补什么就走完这一刀，另开一张。

**为的是一事一结，整个历史是清晰的。**
往在办的卡上追加，等于让一张卡结两件事——那一行、那一份 `cmd/`、那一次结案，
从此都指着两件东西；翻历史的人看得见「结了」，看不见结的是哪一件。
另开一张，两件各自有行、有卡、有印、有结案日期。

**这句理由是这一节的承重墙，不是修辞。** 它一没，补卡就只剩「多一道手续」，
下一个人第一个想省的就是它。

扣上的是两条已有的规矩：**一份 `cmd/` 在 TODO 页只有一个落点、行外不另起一段**；
**概要和细则是两份独立记录，靠互相校验对账**。**追加会把这两条一起破掉。**

**三种用途**，写清楚免得下一个人当成万能口子：

| 用途 | 什么意思 |
|---|---|
| 纠错 | 上一刀做错了 |
| 完善 | 上一刀做对了，但没做够 |
| 补充 | 上一刀该做没做、或当时不该由它做的那一件 |

**刀内发现要动卡外的东西，分两种，不许混：**

| 情形 | 走哪条 |
|---|---|
| 这一刀非动它不可，不动就走不下去 | **退卡。**「超出卡片」那一条一个字不改 |
| 这一刀走得完，只是顺带看见了别的 | **照走完。** 那件事写进收口对账「没做的」那一栏，人在结案时裁开不开补卡 |

**后一种以前没有落脚点，这是它的出口。** 卡上没地方放「看见了但不该我做」，
就只好在抬头写「已知偏离」——而「偏离」的意思是违反了自己写的规矩。
**把一件正当的后续叫成偏离，是把「偏离」这个词写脏**，真偏离和假偏离混在一栏里，
两边都失去分量。有了补卡这条路，那种事有了名字，不必再借「偏离」二字。

**四条边界，一条都不许省：**

- **立案仍是人的那一爪。** 代理看见了只能报，不能自己开一张补卡。
- **补卡不松判据。** 拿新的一刀去放宽老刀的判据，是**松判据**换了个壳，那是人的那一爪
  （`roles.md`，及合同层「结案、发授权、松判据，都是人的那一爪」）。
  **和退卡那一条对得上**：退卡不是松判据的后门，补卡也不是。
- **补卡不改老卡一个字。** 卡结案之后只增不删。补卡是新的一份，不是老卡的修订版。
- **指针只从新往旧指。** 补卡那一行点名它修的是哪一刀；老行在已办区冻着，不回头改。
  **代价照写**：翻已办区看不出某一行后来被补过，要顺着新行才找得到。

**退卡的卡没有补卡。** 退卡的卡留档，但它没有结案，所以仍然没有补卡的对象；那条路是**缩小卡片重开**，不是补卡。

## 闸与闸之间（→ harness）

**人不是不能伸手，但只许两件，而且两件都对领班说：**

- **查阅。** **专指实现跑起来之后人起了疑**——觉得执行有问题，或者等得太久，
  而 `SESSION.md` 那一页答不了这种事。问的是实现席，所以经领班。
  **它不是「每天看 `SESSION.md`」**：看页是人每天四件事的第一件，人自己看，不必喊一声，
  **不算这里的一件**。两处别混，混了就是把看页也收成要经人转发。
- **要求总结之后停刀**，即**提前关闭**——中途就发现有问题，不必耗到结案。

**其余仍然不许**：改卡、改核、扩大卡的射程。
**规划席的评注是另一只手**，走横线以下那条路（见「横线以下的评注」），不算这两件里的任何一件。

**人不直接操作 builder。领班是双向的唯一通道**：问下去、停下去由它转发，报上来由它审。
这就是「为什么要过一次领班」——**不是回程多加一道审，是 builder 两头都不直接对人。**
和「人每天只做四件事」对得上：那四件里没有一件是指挥实现席。

### 提前关闭

> 人要求总结停刀 → **领班转发** → builder 梳理完毕 → 报告交领班 →
> 领班审（说不清**打回重写**，小疵**直接润色**）→ **转呈**人 → **代码退不退，等人裁。**

**它不是退卡。** 退卡是 `src/` 机械回滚、由领班一条命令做掉；这里代码动不动是**人的判断**，
在人裁之前谁都不许先回滚。两个早退口的手续不通用。

**领班那一道是质量闸，不是传声筒。** 原因分析说不清，**打回让 builder 重写**；
小疵**直接润色**。**打回还是润色，尺度由领班自己裁**——这一层的判断本来就是它的本职。

**和收口纪律第 3 条不冲突，那两份东西不是一件：**

| | 谁写的 | 领班能不能动 |
|---|---|---|
| 审查那一页（⑤） | review：无职掌、零写权限、无否决权 | **不能。** 照抄、标出处、不摘要不改词——领班派了实现又要说「建议勾不勾」，是**有利害的那只手** |
| 提前关闭报告（③） | builder：领班自己派的那只手 | **能。** 打回重写 / 润色小疵——报告讲的是**活干得怎么样**，不是**该不该判它过** |

领班自己的意见仍写自己那栏。**代码退不退不归它。**

**转呈之后是两条出路，不是一条：**

| 出路 | 走什么 | 落到哪 |
|---|---|---|
| **修缮** | 这一刀继续。改动往上加 commit，一条一条递进；意见走横线以下的评注；每条评注要有对得上的回应 | 卡不动；`SESSION.md` 横线以下只追加 |
| **退稿** | 这一刀撤掉。退稿就是退卡，走收摊那三条 | 卡留档盖章，号从此不是空档 |

一张对照表，记下来免得下一个人另造一套：

| 这里 | PR 那边 |
|---|---|
| 一刀 | 一个 PR |
| 递进修改 | 往上加 commit |
| 横线以下 | comment |
| 结案 | merge |
| 退稿 | close |
| 补卡 | 另开一个 PR，修前一个已合的 |

**评注因此不是名存实亡的。** 它掉的是「加卡上没有的东西」那半边，那半边归补卡（另一刀）；
留下的是「对已有的提意见、逼出回应」，**那正是 PR comment**，也正是这套东西里它该干的活。

**仍然没定的缩到两件**：修缮走完之后那一行勾不勾，仍是结案那一爪，**本节不发明**；
报告落在哪个目录，同样**没定**，本节不点。

角色顺序见 `roles.md`。验证条款见 `verify.md`。写权限那一面（层 × 手）见 `diagram.md`。
